Q2> What will be the output of the following program:

class A
{
   public:
      A () { cout << "In constructor\n";}
      A (A &a) { cout << "In copy constructor\n";}
      ~A () { cout << "In destructor\n";}
};

A Func(A a)
{
   return a;
}

void main()
{
   A ObjA, ObjB;
   A *Aptr= new A;
   ObjA=Func(ObjA);
   Aptr=&ObjB;
   delete Aptr;
}

"Note from me": Hey I don't remember if there was a "public:" in the class. If it is not there, the program will obviously not compile. Well assuming the public was there, here is the output:
In constructor
In constructor
In constructor
In copy constructor
In copy constructor
In destructor
In destructor
In destructor
In destructor
In destructor
In either case, this is a nasty program. It has a memory leak and it calls the destructor of "ObjB twice"! BTW, you are expected to write all this!
