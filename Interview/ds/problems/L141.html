Find if there is a cycle/loop in the given Single Linked List?
Method 1: Using Hashing;
            
Take an empty hash table;
current = head;
while(current != null) {
    Get the address of the current node;
    If hash table is having that node address,
        then there is a cycle, return true;
    else 
        current = current.next;
}
return false; // Indicates end of list is reached!
Complexity: It takes O(N) time and it requires O(N) space for hash table;
Method 2: Floyd’s Cycle-Finding Algorithm;
  • Traverse linked list using two pointers
  • Move one pointer(slow_p) by one and another pointer(fast_p) by two;
  • If these pointers meet at a node, then there is a loop; Else there is no loop;
Complexity: It takes O(N) time and it requires O(1) space;
