What is a Priority Queue?

It is a Queue of elements, in which each element will have a Priority associated with it;
An element with high priority is served before the element with lower priority;

In some implementations, if two elements have the same priority, they are served according to the order in which they were enqueued;
While in other implementations, ordering of elements with the same priority is undefined;

Operations

insert(PQ, x, p) - insert an element x with priority p into priority queue PQ;
peek(PQ) - It returns the highest priority element from priority queue PQ;
delete(PQ) - It deletes the highest priority element from priority queue PQ, before returning it;

Implementations

It can be implemented using a Unsorted Array, Sorted Array, Heap;

Unsorted Array
insert(PQ, x, p) -> It adds the element to next empty location in array; Time Complexity: O(1)
delete(PQ) -> It searches the entire array for finding the element with high priority; Time Complexity: O(N)

Sorted Array - Sorted as per the element's priority;
insert(PQ, x, p) -> It inserts the element in the right position in the array, as per priority; Time Complexity: O(N)
delete(PQ) -> First element in the array is the element with high priority; Time Complexity: O(1)

Heap - Heap construction takes O(N logN) time, if you take empty array and do N insertions; But, it takes O(N) time to convert an array into heap;
insert(PQ, x, p) -> Time Complexity: O(log N)
delete(PQ) -> Time Complexity: O(log N)

Applications

  1. Job Scheduling - C EACPU scheduling of processes
  2. Dijkstra's single source shortest part algorithm
  3. Huffman's prefix coding algorithm
  4. selection problem. see section 6.4.1 of Mark Allen weiss. i/p: set of n intergers and an integer K O/P: k th largest integer
