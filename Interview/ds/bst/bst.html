What is Binary Search Tree?

Complete Binary Tree is a Binary Tree in which every level, except possibly the last, is completely filled and all nodes are as far left as possible;

Advantage of Complete Binary Tree over Binary Tree: It's height is always O(log N), it's never O(N);

What is a Heap?

There are 2 types of heaps: Min-Heap, Max-Heap;

Min-Heap:
It is a Complete Binary Tree, in which each node is less than or equal to it's children;
It is useful in sorting the list in ascending order;

Max-Heap:
It is a Complete Binary Tree, in which each node is greater than or equal to it's children;
It is useful in sorting the list in descending order;

Heap Represenation

You can use an array to represent a heap;

In the array, the first index contains the root element. The next two indices of the array contain the root's children;
The next four indices contain the four children of the root's two child nodes, and so on;
Therefore, given a node at index i, its children are at indices 2i + 1 and 2i + 2, and its parent is at index floor((i-1)/2);

Current node index -> i; index of left child -> 2i + 1; index of right child -> 2i + 2; index of parent -> floor((i-1) / 2);

How to convert an array into a Heap?

General approach:
Heapifying a single node takes O(log N) time; To heapify the entire array, it takes N heapify operations. So, total time complexity is O(N*logN);
Optimized approach:
The above approach can be optimized by observing the fact that the leaf nodes need not to be heapified, as they already follow the heap property;
So the idea is to find the position of the last non-leaf node and perform the heapify operation of each non-leaf node in reverse level order;
Last non-leaf node = parent of last-node;
= parent of node at (n-1)th index;
= Node at index ((n-1) - 1)/2;
= (n/2) - 1;

build-min-heap(A) - It takes an array of elements and converts it into a heap; Time Complexity: O(N);
for i = A.length/2 to 1
min-heapify-up(A, i);

                package com.cmr.iview;

                import java.util.ArrayList;
                import java.util.Collections;
                
                public class MaxHeap {
                
                    private ArrayList data;
                
                    public MaxHeap() {
                        this.data = new ArrayList();
                    }
                
                    public MaxHeap(ArrayList data) {
                        this.data = data;
                        build_max_heap();
                    }
                
                    // It takes an array of elements and converts it into a heap;
                    // Time Complexity: O(N);
                    private void build_max_heap() {
                        for (int i = (getLastElementIndex() - 1) / 2; i >= 0; i--) {
                            max_heapify_down(i);
                        }
                    }
                
                    // Add new element to the heap;
                    // Time Complexity: O(log N);
                    public void insert(int i) {
                        data.add(i); // Add new el at the end of the array!
                        max_heapify_up(data.size() - 1); // heapify-up the last el!
                    }
                
                    // It re-arranges last element and the elements in parent chain to satisfy heap
                    // property;
                    // Time Complexity: O(log N);
                    private void max_heapify_up(int elIndex) {
                        int parentIndex = (elIndex - 1) / 2;
                        if (data.get(parentIndex) < data.get(elIndex)) {
                            Collections.swap(data, elIndex, parentIndex);
                            max_heapify_up(parentIndex);
                        }
                    }
                
                    // It is used to delete root from the heap; Time Complexity: O(logN);
                    // Swap the root element with last element, delete last element,
                    // min-heapify-down(root);
                    public void delete_max() {
                        // root is always at index 0; swap the root element and last element!
                        Collections.swap(data, 0, getLastElementIndex());
                        int lastEl = data.remove(getLastElementIndex()); // remove the last el!
                        System.out.println(lastEl);
                        max_heapify_down(0); // heapify the root and it's subtrees!
                    }
                
                    // It re-arranges node i and it's subtrees to satisfy the heap property; Time
                    // Complexity: O(log N);
                    private void max_heapify_down(int elIndex) {
                        int l = 2 * elIndex + 1;
                        int r = 2 * elIndex + 2;
                
                        int largest;
                        // Check if parent is less than it's left child
                        if (l < data.size() && data.get(elIndex) < data.get(l)) {
                            largest = l;
                        } else {
                            largest = elIndex;
                        }
                
                        // Check if largest is smaller than right child
                        if (r < data.size() && data.get(largest) < data.get(r)) {
                            largest = r;
                        }
                
                        // If current is not the largest
                        if (elIndex != largest) {
                            Collections.swap(data, elIndex, largest);
                            max_heapify_down(largest);
                        }
                    }
                
                    public boolean isEmpty() {
                        return data.isEmpty();
                    }
                
                    public int getLastElementIndex() {
                        return data.size() - 1;
                    }
                }
