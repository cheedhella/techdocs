Double ended q is one in which you can insert and delete from both ends. To implement a deque, we use a doubly linked list.

To insert at head, just create a new node. point it to current head and make the new node as head.
To insert at tail, same as insertion in queue.
To remove from head, same as insertion in queue.
To remove from tail, just save the link to last node and link the second last node to null.


Input Resticted Deque
Operations allowed: Deletion at head, insertion and deletion at tail.

Output Resticted Deque
Operations allowed: insertion and Deletion at head, deletion at tail.


Deletions at the tail of a singly linked list cannot be done in constant time

A node of a doubly linked list has a next and a prev link
Then, all the methods of a deque have a constant (that is, O(1)) running time.
