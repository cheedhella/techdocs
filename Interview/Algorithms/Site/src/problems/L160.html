Find the Intersection of Two Linked Lists?
Given 2 single linked lists, l1 and l2, find the node at which the intersection of lists begins? It is also called Merge Point;
Method 1: Brute Force
For each node in l1, compare it with every node l2; Once you find a match, it is the merge point;

Complexity: O(n1*n2), where n1 is the length of l1 and n2 is the length of l2;
Method 2: Using difference between length of lists;
  • Get the length of l1, say it is c1;
  • Get the length of l2, say it is c2;
  • Caculate the difference b/w length of 2 lists, d = abs(c1 - c2);
  • Traverse the bigger list from the 1st node till d nodes, so that from here onwards both the lists have equal no of nodes;
  • Now, we can traverse both the lists in parallel till we come across a common node;

Complexity: Time Complexity: O(n1 + n2); Space Complexity: O(1);
Method 3: Using 2-pointer technique;
  • Initialize two pointers ptr1 and ptr2 at the head1 and head2;
  • Traverse through the lists, one node at a time;
  • When ptr1 reaches the end of a list, then redirect it to the head2;
  • Once both of them go through reassigning, they will be equidistant from the collision point;
  • If at any node ptr1 meets ptr2, then it is the intersection node;
  • After second iteration if there is no intersection node it returns NULL;

Complexity: Time Complexity: O(n1 + n2); Space Complexity: O(1);
