Calculate the Height of a Binary Tree?
Height is the number of edges along the longest path from the root node down to the farthest leaf node; 
            
    public static int height(Node root) {
        if(root == null) {
            return -1;
        }
        if(root.left == null && root.right == null){
            return 0;
        }
        else{
            int l = height(root.left);
            int r = height(root.right);
            return Math.max(l, r);          
        }
    }
Complexity:
In order to compute depth, we end up visiting each node recursively, therefore the time complexity is T O(N);
Space complexity is O(n), the space cost incurred on the stack size because of recursion calls;
