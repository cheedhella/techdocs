Find the K th node from the end of a Single Linked List?
Method 1: K th node from last will be (n-k+1)th node from the beginning;
  • Find the length of list, say it is n;
  • Return n-k+1 th node from beginning;
Method 2: Using 2 pointers;
  • Take 2 pointers, p1 and p2; Intialize them to head;
  • Move p2 by K nodes from head;
  • Now, move both pointers one by one, until p2 reaches end;
  • In the end, p1 points k th node from the end;
