Find the Length of the cycle/loop in the given Single Linked List?
Method 1: Using Floyd’s Cycle-Finding Algorithm;
  • Find the common point, using floyd's cycle finding algorithm;
  • Take a temp pointer, initialize it to temp; Take a counter, initialize it to 0;
  • Keep traversing the linked list one by one using temp pointer and increase the count, until common point is reached again'
  • Now, count contains the number of nodes in the loop;
