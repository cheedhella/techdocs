If the input array is unsorted,

Method 1: Native approach;

// Requires running two loops;
For each element in the input,
Check if it has already occurred or not;
If already seen, then
Ignore it;
Else
add it to the array;

Time Complexity: O(N^2); Space Complexity: O(N), extra array needed to store unique elements;

Method 2: Using Sorting;

Sort the array and use any of the approaches described below;

Method 3: Using a Set, internally uses hashing;

Take an empty Set, iterate the given array and put each entry into the Set;
This will store all unique entries into the Set;
Now, iterate the set and put the entries back into the array starting from index 0;

Time Complexity: O(N); Space Complexity: O(N), we are taking extra set;

If the input array is already sorted,

Method 1:

Take a counter of unique elements, C, initialize it to 0;
Iteate the array, if the current element is not same as next element, store the current element at index C and increment it;
Eg:
Input: [1, 1, 2, 3, 3, 4, 4, 5, 5, 5, 5, 6]
Output: [1, 2, 3, 4, 5, 6]

Time Complexity: O(N); Space Complexity: O(1);
