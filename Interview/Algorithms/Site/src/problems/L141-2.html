How to Detect and Remove the cycle/loop in a Single Linked List?
Method 1:
  • Identify the common point(a node where slow and fast pointers meet), using Floyd's cycle finding algorithm, name it as cptr;
    Note that, common point can be any of the loop nodes; It need not be a loop starting node;
    Let's identify the loop starting node as follows:
  • Start from the head and check for each node, if it is reachable from cptr;
  • Whenever we find a node that is reachable, it is the starting node of the loop;
  • From there, we can easily get the pointer to the node that is previous to loop starting node and make next of it as NULL;
Method 2: Better solution;
  • Identify the common point, name it as cptr;
  • Count the number of nodes in the loop, let the count be k;
  • Take one pointer to the head and another to the k th node from the head;
  • Move both pointers at the same pace, they will meet at loop starting node;
  • From there, we can easily get the pointer to the node that is previous to loop starting node and make next of it as NULL;
Method 3: Even better solution, no need to identify the loop size;
  • Identify the common point, name it as cptr;
  • Take one pointer to the head and another to cptpr;
  • Move both pointers at the same pace, they will meet at loop starting node;
