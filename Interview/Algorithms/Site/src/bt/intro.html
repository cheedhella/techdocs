What is a Binary Tree?
A tree in which every node has atmost 2 children, left child and right child;
Properties of a Binary Tree
  • Height of a tree is the number of levels in it;
  • Each level l can have a maximum of 2^l nodes;
  • Maximum number nodes is 2^(h+1)-1, where h is the height of the tree;
    n = Sum of max nodes at each level;
      = 2^0 + 2^1 + ... + 2^(h-2) + 2^(h-1);
      = (2^h)-1;
  • Maximum number of leaf nodes is the number of nodes in last level, 2^(h-1);
  • Minimum number of levels in a binary tree with n nodes is log(n+1) base 2;
  • Minimum height of a binary tree with n nodes is log(n+1) base 2;
Binary Tree Represenations
Array Representation

Root is always stored at index 0;
Left Child's Index = 2 * Parent’s Index + 1;
Right Child's Index = 2 * Parent’s Index + 2;
Parent’s Index = (Child’s Index - 1) / 2;


Representation using a Java Class
