What is a Graph?
    Graph is a collection of Vertices/Nodes and Edges; Edge can be directed or non-directed;
    
What is a Null Graph?
    A Graph without any edges(all vertices are isolated) is called Null Graph;

What is a Trivial Graph?
    A Graph with only vertex is called Trivial Graph;

What is a Directed Graph?
    A Graph whose edges are directed is called Directed Graph; Otherwise, it called Non-directed Graph;

What is a Simple Graph?
    A Graph with no loops and no parallel edges is called a Simple Graph;
    The maximum number of edges possible in a Simple Graph is n C 2;

What is a Weighted Graph?
    A Graph in which each edge is associated with a label/weight/data is called Weighted Graph;

What is a Connected Graph?
    A Graph is Connected if there is a Path between every 2 vertices in the Graph;

What is a Completed Graph?
    A Graph is Completed if there is an Edge between every 2 vertices in the Graph;

What is a Regualar Graph?
    A Graph is Regular if all vertices have same degree;

What is a Biparite Graph?
    Bipartite Graphs – A simple graph G is said to be bipartite if its vertex set V can be divided into two disjoint sets such that every edge in G has its initial vertex in the first set and the terminal vertex in the second set. Total number of edges are (n*m) with (n+m) vertices in bipartite graph.
    A simple graph is bipartite if and only if it is possible to assign one of two
    different colors to each vertex of the graph so that no two adjacent are assigned the same color.

What is a Complete Biparite Graph?
    A bipartite graph with m and n vertices in its two disjoint subsets is said to be complete if there is an edge from every vertex in the first set to every vertex in the second set, for a total of mn edges.

What is a Multi Graph?
    A graph which contain some parallel edges but doesn’t contain any self-loop is called Multi Graph;

    Adjacency – In a graph G two vertices u and v are said to be adjacent if they are the endpoints of an edge. The edge \{u, v\} -  e is said to be incident with the vertices.
    In case the edge is directed, u is said to be adjacent to v and v is said to be adjacent from u. Here, u is said to be the intitial vertex and v is said to the terminal vertex.

What is Degree of a Vertex?
    Degree – The degree of a vertex is the number of edges incident with it, except the self-loop which contributes twice to the degree of the vertex.
    In case of directed graphs, the degree is further classified as in-degree and out-degree. The in-degree of a vertex is the number of edges with the given vertex as the terminal vertex. The out-degree of a vertex is the number of edges with the given vertex as the initial vertex.

What is Isolated Vertex?
If a vertex has zero degree, it is called isolated. If the degree is one then it’s called pendant.
