What is Feign?

  • When a service wants to call another service, you could use Spring RestTemplate; But, you need to write lot of code!
  • With Fiegn, we don't have write any code, other than an interface definition;
  • Spring Cloud OpenFeign, spring-cloud-starter-openfeign - a declarative REST client for Spring Boot apps;
  • Annotate the main class with: @EnableFeignClients; It scans for the components/feign clients that are annotated with @FeignClient;
  • Feign also supports lot of customizable configuration, such as timeout etc;
  • Feign also allows you customize things, wherever needed;

Feign talks to the naming server(eureka), to get list of instances of a service and load balances the request; If you use Eureka and Feign, load balancing comes as free! This is called client-side load balancing, b/c it happens on the caller side; Feign has a dependency on spring-cloud-loadbalancer; Earlier version of spring use Ribbon as load balancer;
