What are Switch Expressions?
Finalized in Java 14, Switch Expressions allow the switch statement to be used as an expression (meaning it evaluates to a single value) or as a statement. They introduce a new arrow (->) syntax and remove the need for break statements, eliminating fall-through bugs.
Why use Switch Expressions?
  • No Fall-Through: The arrow syntax (->) only executes the code to its right. No break needed!
  • Concise Code: Multiple case labels can be combined on a single line.
  • Value Return: Directly assign the result of the switch block to a variable without mutating external state.
  • Exhaustiveness: The compiler ensures all possible cases are covered (especially useful with Enums and Sealed Classes).
What is the yield keyword?
If a case block requires multiple lines of logic before returning a value, the yield keyword is used to return a value from the switch expression.
Can you show a simple Switch Expression example?
// Traditional Switch Statement
int numLetters;
switch (day) {
    case MONDAY:
    case FRIDAY:
    case SUNDAY:
        numLetters = 6;
        break;
    case TUESDAY:
        numLetters = 7;
        break;
    default:
        numLetters = 0;
}

// Switch Expression
int numLetters = switch (day) {
    case MONDAY, FRIDAY, SUNDAY -> 6;
    case TUESDAY                -> 7;
    case THURSDAY, SATURDAY     -> 8;
    case WEDNESDAY              -> 9;
    default                     -> {
        System.out.println("Invalid day");
        yield 0; // Using yield for multi-line block
    }
};
When should you use Switch Expressions?
Use them whenever you are writing a switch block, especially when mapping an input value to an output value. They provide safer, cleaner, and more robust code than traditional switch statements.
