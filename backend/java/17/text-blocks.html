What are Text Blocks?
Finalized in Java 15, a Text Block is a multi-line string literal that avoids the need for most escape sequences. It automatically formats the string in a predictable way, and gives developers control over the format when desired.
Why use Text Blocks?
  • Readability: Huge improvement for writing embedded JSON, XML, HTML, or SQL queries directly in Java code.
  • No Escaping Quotes: Double quotes inside a text block do not need to be escaped (\").
  • Automatic Indentation Management: The compiler automatically strips away the incidental indentation (whitespace) added to align the text block with the surrounding Java code.
How do you write a Text Block?
A text block is opened with three double quotes (""") followed by a newline, and closed with three double quotes.
Can you show a simple example?
// Before Text Blocks
String json = "{\n" +
              "  \"name\": \"John Doe\",\n" +
              "  \"age\": 30\n" +
              "}";

// With Text Blocks
String jsonBlock = """
        {
          "name": "John Doe",
          "age": 30
        }
        """; // Notice quotes are not escaped!

// Using with formatted()
String query = """
        SELECT id, name
        FROM users
        WHERE status = '%s'
        """.formatted("ACTIVE");
When should you use Text Blocks?
Use text blocks anytime you have string literals spanning more than one line, particularly when representing code or data from other languages (like JSON or SQL).
