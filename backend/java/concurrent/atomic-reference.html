What is AtomicReference?
  • AtomicReference = lock-free, thread-safe updates to object references using CAS
  • Why use AtomicReference?
    • ✅ Thread-safe without locks
    • No blocking
    • Better performance under contention
    • ✅ Fine-grained control
    • You control when updates happen
    • ✅ Useful for immutable objects
  • 
        | Feature        | `volatile` | `AtomicReference` |
        | -------------- | ---------- | ----------------- |
        | Visibility     | ✅          | ✅              |
        | Atomic updates | ❌          | ✅              |
        | CAS support    | ❌          | ✅              |
Can you show a simple CountDownLatch example?

            import java.util.concurrent.atomic.AtomicReference;

public class Example {
    public static void main(String[] args) {
        AtomicReference ref = new AtomicReference<>("Hello");

        boolean updated = ref.compareAndSet("Hello", "World");

        System.out.println(updated); // true
        System.out.println(ref.get()); // World
    }
}
