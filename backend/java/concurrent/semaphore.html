What is Semaphore?
A Semaphore is a synchronization tool that maintains a set of permits. It is used to restrict the number of threads than can access some (physical or logical) resource.
How does Semaphore work?
  • It is initialized with a given number of permits.
  • A thread must call acquire() to get a permit. If no permit is available, it blocks until one is released.
  • When the thread is done with the resource, it calls release(), which returns the permit to the semaphore and potentially unblocks a waiting thread.
  • A semaphore with exactly one permit is often called a binary semaphore and can be used as a mutually exclusive lock (mutex).
What is Fairness in Semaphore?
The constructor accepts an optional fairness parameter. When set to true, the semaphore guarantees that threads invoking acquire() are granted permits in the order in which they requested them (FIFO). If false (default), barge-in is permitted, which can be more efficient but risks thread starvation.
Can you show a simple Semaphore example?
import java.util.concurrent.Semaphore;

public class Example {
    public static void main(String[] args) {
        // Only 2 permits available
        Semaphore semaphore = new Semaphore(2);

        for (int i = 0; i < 5; i++) {
            new Thread(() -> {
                try {
                    System.out.println(Thread.currentThread().getName() + " attempting to acquire permit.");
                    semaphore.acquire();
                    System.out.println(Thread.currentThread().getName() + " acquired permit!");
                    
                    // Simulate work with resource
                    Thread.sleep(2000); 
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    System.out.println(Thread.currentThread().getName() + " releasing permit.");
                    semaphore.release();
                }
            }, "Thread-" + i).start();
        }
    }
}
When should you use Semaphore?
Semaphores are highly useful for resource pooling scenarios, such as connection pools, restricting the number of concurrent database connections, or rate limiting incoming requests in an application.
