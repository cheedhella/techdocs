1. What Is GraphQL?
  • Definition
    • GraphQL is a query language for APIs and a runtime for executing those queries;
    • Developed by Facebook in 2012, open-sourced in 2015;
    • Allows clients to request exactly the data they need, nothing more, nothing less;
  • Key Characteristics
    • Strongly typed schema that defines the API contract;
    • Single endpoint instead of multiple REST endpoints;
    • Client-driven queries - clients specify their data requirements;
2. Core Components
  • Schema - Defines types and relationships in your API;
  • Queries - Read operations to fetch data;
  • Mutations - Write operations to modify data;
  • Subscriptions - Real-time data updates via WebSocket;
3. Why GraphQL?
  • Eliminates over-fetching and under-fetching of data;
  • Reduces number of API calls - get all needed data in one request;
  • Self-documenting through introspection;
  • Strong typing catches errors at development time;
