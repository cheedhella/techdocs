1. Nodes
  • What Are Nodes?
    • Represent entities in your domain (users, products, locations);
    • Similar to rows in relational databases;
    • Can have zero or more labels;
  • Node Syntax
    • (variable:Label {property: value});
    • Example: (u:User {name: "Alice", email: "alice@example.com"});
  • Multiple Labels
    • (p:Person:Employee {name: "Bob"});
    • Bob is both a Person and an Employee;
2. Relationships
  • What Are Relationships?
    • Named, directed connections between nodes;
    • Always have a type (written in UPPER_CASE);
    • Can have properties like nodes;
  • Relationship Syntax
    • -[:TYPE {property: value}]->
    • Example: (alice)-[:KNOWS {since: 2020}]->(bob);
  • Characteristics
    • Must have exactly one type;
    • Must connect exactly two nodes;
    • Direction matters but can be traversed both ways;
3. Properties
  • What Are Properties?
    • Key-value pairs attached to nodes or relationships;
    • Store actual data about entities and connections;
  • Supported Types
    • String, Integer, Float, Boolean;
    • Date, DateTime, Time;
    • Lists of any type;
    • Point (spatial data);
  • Best Practices
    • Use properties for attributes of entities;
    • Use relationships for connections between entities;
    • Don't store relationships as properties (use actual relationships);
