1. What Is the Property Graph Model?
  • Definition
    • Data model used by Neo4j and other graph databases;
    • Consists of nodes, relationships, and properties;
    • Both nodes and relationships can have properties;
  • Core Components
    • Nodes - Entities or objects (Person, Product, City);
    • Relationships - Named, directed connections between nodes;
    • Properties - Key-value pairs storing data;
2. Key Characteristics
  • Relationships Are First-Class
    • Not just foreign keys - they have identity and properties;
    • Can store metadata about connections (since, weight, type);
  • Directed Relationships
    • Every relationship has a direction (from source to target);
    • Can traverse in either direction;
  • Labeled and Typed
    • Nodes have labels (Person, Product);
    • Relationships have types (FRIENDS_WITH, PURCHASED);
3. Example
  • Nodes
    • (alice:Person {name: "Alice", age: 30});
    • (bob:Person {name: "Bob", age: 25});
  • Relationship
    • (alice)-[:FRIENDS_WITH {since: 2020}]->(bob);
    • Alice is friends with Bob since 2020;
  • Benefits
    • Intuitive - matches how we think about connected data;
    • Flexible - easy to add new properties and relationships;
    • Performant - fast traversals without JOINs;
