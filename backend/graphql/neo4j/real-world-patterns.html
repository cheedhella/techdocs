1. Social Network APIs
  • Key Features
    • User profiles, friendships, posts, comments;
    • News feed generation;
    • Friend suggestions;
  • Graph Model
    • (User)-[:FRIENDS_WITH]->(User);
    • (User)-[:POSTED]->(Post)-[:HAS_COMMENT]->(Comment);
    • (User)-[:LIKES]->(Post);
  • Queries
    • Friends of friends;
    • Mutual friends;
    • Activity feed from friends;
2. Recommendation Engines
  • Collaborative Filtering
    • Users who liked X also liked Y;
    • (User)-[:PURCHASED]->(Product)<-[:PURCHASED]-(OtherUser)-[:PURCHASED]->(Recommendation);
  • Content-Based
    • Similar items based on properties;
    • (Product)-[:IN_CATEGORY]->(Category)<-[:IN_CATEGORY]-(Similar);
  • Hybrid
    • Combine multiple signals;
    • User behavior + item similarity + social connections;
3. Knowledge Graph APIs
  • Structure
    • Entities (people, places, concepts);
    • Relationships (born_in, works_for, related_to);
    • Properties (dates, descriptions);
  • Queries
    • Find all related entities;
    • Shortest path between concepts;
    • Semantic search;
4. Event Graphs
  • Model
    • Events as nodes with timestamps;
    • (Event)-[:CAUSED_BY]->(PreviousEvent);
    • (User)-[:PERFORMED]->(Event);
  • Use Cases
    • Audit logs;
    • Event sourcing;
    • Workflow tracking;
    • Root cause analysis;
5. GraphQL Federation
  • Microservices Pattern
    • Split graph across multiple services;
    • Each service owns part of schema;
    • Gateway composes into single API;
  • Benefits
    • Team autonomy;
    • Independent deployment;
    • Scale services independently;
