1. Object Types
  • Definition
    • Most common type in GraphQL schema;
    • Represents an entity with fields;
    • Example: type Post { id: ID!, title: String!, author: User! }
  • Characteristics
    • Can have scalar fields (String, Int, etc);
    • Can reference other object types;
    • Can have arguments on fields;
2. Fields
  • Field Types
    • Scalar fields - primitive values (id, name, age);
    • Object fields - references to other types (author, posts);
    • List fields - arrays of values ([String], [User]);
  • Field Arguments
    • posts(limit: Int, offset: Int): [Post];
    • Allow filtering, pagination, sorting;
3. Relationships
  • One-to-One
    • type User { profile: Profile };
    • Each user has exactly one profile;
  • One-to-Many
    • type User { posts: [Post] };
    • User can have multiple posts;
  • Many-to-Many
    • type User { friends: [User] };
    • Users can have multiple friends;
  • Bidirectional
    • type Post { author: User } and type User { posts: [Post] };
    • Navigate relationship from either side;
