1. What Is Cypher?
  • Definition
    • Neo4j's query language for graph databases;
    • Declarative, pattern-matching language;
    • Inspired by SQL but designed for graphs;
  • Key Features
    • ASCII-art syntax - visually represents graph patterns;
    • Readable and intuitive;
    • Expressive for complex graph traversals;
2. Basic Syntax
  • Nodes
    • (n) - any node;
    • (p:Person) - node with Person label;
    • (u:User {name: "Alice"}) - node with label and property;
  • Relationships
    • --> - outgoing relationship;
    • <-- - incoming relationship;
    • -[r:KNOWS]-> - typed relationship with variable;
    • -[:KNOWS {since: 2020}]-> - relationship with properties;
  • Patterns
    • (a)-[:KNOWS]->(b) - a knows b;
    • (a)-[:KNOWS*1..3]->(b) - a knows b within 1-3 hops;
3. Common Clauses
  • MATCH - Find patterns in the graph;
  • WHERE - Filter results;
  • RETURN - Specify what to return;
  • CREATE - Create nodes and relationships;
  • MERGE - Create if doesn't exist, match if exists;
  • DELETE - Remove nodes and relationships;
  • SET - Update properties;
  • ORDER BY - Sort results;
  • LIMIT - Limit number of results;
4. Simple Examples
  • Find All Users
    • MATCH (u:User) RETURN u.name;
  • Find Friends
    • MATCH (u:User {name: "Alice"})-[:FRIENDS_WITH]->(friend) RETURN friend.name;
  • Create Node
    • CREATE (u:User {name: "Bob", age: 25}) RETURN u;
