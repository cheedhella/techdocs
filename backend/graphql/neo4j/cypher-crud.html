1. Create (C)
  • Create Node
    • CREATE (u:User {name: "Alice", email: "alice@example.com"}) RETURN u;
    • Creates a new User node with properties;
  • Create Relationship
    • MATCH (a:User {name: "Alice"}), (b:User {name: "Bob"});
    • CREATE (a)-[r:FRIENDS_WITH {since: 2020}]->(b) RETURN r;
  • Create Multiple
    • CREATE (a:User {name: "Alice"}), (b:User {name: "Bob"}), (a)-[:KNOWS]->(b);
    • Create nodes and relationship in one statement;
2. Read (R)
  • Find All Nodes
    • MATCH (u:User) RETURN u;
    • Returns all User nodes;
  • Find by Property
    • MATCH (u:User {name: "Alice"}) RETURN u;
    • Or: MATCH (u:User) WHERE u.name = "Alice" RETURN u;
  • Find with Relationships
    • MATCH (u:User)-[:FRIENDS_WITH]->(friend) RETURN u.name, friend.name;
    • Find users and their friends;
3. Update (U)
  • Update Property
    • MATCH (u:User {name: "Alice"}) SET u.age = 31 RETURN u;
    • Updates Alice's age;
  • Add Property
    • MATCH (u:User {name: "Alice"}) SET u.city = "New York" RETURN u;
    • Adds new property to existing node;
  • Add Label
    • MATCH (u:User {name: "Alice"}) SET u:VIP RETURN u;
    • Adds VIP label to Alice;
4. Delete (D)
  • Delete Node
    • MATCH (u:User {name: "Alice"}) DELETE u;
    • Fails if node has relationships;
  • Delete Node and Relationships
    • MATCH (u:User {name: "Alice"}) DETACH DELETE u;
    • Deletes node and all its relationships;
  • Delete Relationship
    • MATCH (a:User)-[r:FRIENDS_WITH]->(b:User) WHERE a.name = "Alice" DELETE r;
    • Removes specific relationship;
