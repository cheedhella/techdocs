1. Count Queries
  • Simple Count
    • query { usersCount };
    • Returns total number of User nodes;
    • Auto-generated for each type;
  • Count with Filter
    • query { usersCount(where: {age_GT: 18}) };
    • Count only matching nodes;
  • Relationship Count
    • type User { postCount: Int @cypher(statement: "MATCH (this)-[:POSTED]->(p) RETURN count(p)") };
    • Count related nodes;
2. Aggregation Functions
  • Built-in Aggregations
    • count() - count items;
    • sum() - sum numeric values;
    • avg() - average of values;
    • min() - minimum value;
    • max() - maximum value;
  • Using in @cypher
    • type Product {
    • avgRating: Float @cypher(statement: "MATCH (this)<-[r:RATED]-() RETURN avg(r.score)")
    • totalSales: Int @cypher(statement: "MATCH (this)<-[:CONTAINS]-(o:Order) RETURN sum(o.quantity)")
    • };
3. Connection Aggregations
  • Aggregate Field
    • type User { postsAggregate: PostAggregateSelection };
    • Auto-generated aggregate type;
  • Query Example
    • query {
    • users {
    • name
    • postsAggregate {
    • count
    • node { title { longest, shortest } }
    • }
    • }
    • };
4. Complex Aggregations
  • Group By Pattern
    • Use @cypher for complex grouping;
    • type Query {
    • usersByCountry: [CountryStats] @cypher(statement: """
    • MATCH (u:User)-[:LIVES_IN]->(c:Country)
    • RETURN c.name as country, count(u) as userCount
    • """)
    • };
  • Statistical Queries
    • Percentiles, standard deviation;
    • Use Cypher's statistical functions;
    • Return as computed fields;
