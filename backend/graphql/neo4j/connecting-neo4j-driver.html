1. Neo4j Driver Overview
  • What Is the Driver?
    • Official client library for connecting to Neo4j;
    • Handles connection pooling, transactions;
    • Executes Cypher queries;
  • Installation
    • npm install neo4j-driver;
2. Connection Configuration
  • Connection URI
    • bolt://localhost:7687 - local instance;
    • neo4j://localhost:7687 - routing driver;
    • neo4j+s://xxx.databases.neo4j.io - AuraDB (encrypted);
  • Authentication
    • Basic auth: username and password;
    • Default: neo4j / neo4j (change on first login);
  • Driver Options
    • maxConnectionPoolSize - connection pool size;
    • connectionTimeout - timeout in milliseconds;
    • encrypted - enable/disable encryption;
3. Basic Usage
  • Create Driver
    • const driver = neo4j.driver(uri, neo4j.auth.basic(user, password));
  • Verify Connectivity
    • await driver.verifyConnectivity();
    • Throws error if can't connect;
  • Execute Query
    • const session = driver.session();
    • const result = await session.run('MATCH (n) RETURN count(n)');
    • await session.close();
  • Close Driver
    • await driver.close();
    • Call on application shutdown;
4. Best Practices
  • Single Driver Instance
    • Create driver once, reuse throughout app;
    • Driver manages connection pool;
    • Don't create driver per request;
  • Always Close Sessions
    • Use try-finally or async/await with proper cleanup;
    • Prevents connection leaks;
  • Handle Errors
    • Catch connection errors;
    • Retry logic for transient failures;
    • Log errors for debugging;
  • Environment-Specific Config
    • Different URIs for dev, staging, production;
    • Use environment variables;
