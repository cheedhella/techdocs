1. What Is @cypher Directive?
  • Purpose
    • Execute custom Cypher queries for field resolution;
    • Handle complex logic not covered by auto-generation;
    • Compute derived fields;
  • When to Use
    • Complex aggregations;
    • Multi-hop traversals;
    • Business logic in database;
    • Performance optimizations;
2. Basic Usage
  • Computed Field
    • type User {
    • name: String!
    • postCount: Int @cypher(statement: "MATCH (this)-[:POSTED]->(p:Post) RETURN count(p)")
    • };
  • The 'this' Variable
    • Refers to current node being resolved;
    • Available in all @cypher statements;
    • Use to traverse from current context;
3. With Arguments
  • Parameterized Queries
    • type User {
    • friendsOfFriends(limit: Int = 10): [User]
    • @cypher(statement: """
    • MATCH (this)-[:FRIENDS_WITH]-()-[:FRIENDS_WITH]->(fof)
    • WHERE fof <> this
    • RETURN DISTINCT fof LIMIT $limit
    • """)
    • };
  • Accessing Arguments
    • Use $argumentName in Cypher;
    • Arguments automatically bound;
4. Advanced Patterns
  • Aggregations
    • avgRating: Float @cypher(statement: "MATCH (this)<-[r:RATED]-() RETURN avg(r.score)");
  • Recommendations
    • recommended: [Product] @cypher(statement: """
    • MATCH (this)-[:PURCHASED]->(p:Product)<-[:PURCHASED]-(other)
    • MATCH (other)-[:PURCHASED]->(rec:Product)
    • WHERE NOT (this)-[:PURCHASED]->(rec)
    • RETURN rec, count(*) as score ORDER BY score DESC LIMIT 10
    • """);
  • Performance Tips
    • Use indexes for starting points;
    • Limit results in Cypher;
    • Profile queries to optimize;
    • Consider caching for expensive computations;
