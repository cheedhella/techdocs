1. Enums
  • Definition
    • Special scalar type with predefined set of values;
    • Ensures field can only be one of allowed values;
  • Example
    • enum Role { ADMIN, USER, GUEST }
    • type User { name: String!, role: Role! }
  • Benefits
    • Type safety - prevents invalid values;
    • Self-documenting - clear what values are allowed;
    • Better IDE autocomplete;
2. Interfaces
  • Definition
    • Abstract type that defines common fields;
    • Other types can implement the interface;
  • Example
    • interface Node { id: ID!, createdAt: DateTime! }
    • type User implements Node { id: ID!, createdAt: DateTime!, name: String! }
    • type Post implements Node { id: ID!, createdAt: DateTime!, title: String! }
  • Use Cases
    • Polymorphic queries - query multiple types at once;
    • Enforce consistent fields across types;
    • Support for pagination patterns (Relay);
3. Unions
  • Definition
    • Type that can be one of several object types;
    • No common fields required (unlike interfaces);
  • Example
    • union SearchResult = User | Post | Comment;
    • type Query { search(term: String!): [SearchResult] }
  • Querying Unions
    • Use inline fragments to access type-specific fields;
    • { search(term: "hello") { ... on User { name } ... on Post { title } } }
