1. What Are Temporal Graphs?
  • Definition
    • Graphs that track changes over time;
    • Store historical states;
    • Query data as it was at specific time;
  • Use Cases
    • Audit trails;
    • Historical analysis;
    • Compliance requirements;
    • Time-travel queries;
2. Modeling Time in Graphs
  • Timestamps on Properties
    • Add createdAt, updatedAt to nodes;
    • Simple but loses history;
  • Valid Time on Relationships
    • (a)-[:WORKED_FOR {from: date("2020-01-01"), to: date("2022-12-31")}]->(company);
    • Track when relationship was valid;
  • Event Sourcing
    • Store all changes as events;
    • (user)-[:CREATED]->(event:Event {type: "USER_CREATED", timestamp: ...});
    • Rebuild state from events;
3. Querying Temporal Data
  • Point-in-Time Queries
    • MATCH (a)-[r:WORKED_FOR]->(c) WHERE $date >= r.from AND $date <= r.to;
    • Find relationships valid at specific date;
  • Time Range Queries
    • Find all changes in date range;
    • Useful for reports, analytics;
  • GraphQL Integration
    • Add date arguments to queries;
    • users(asOf: "2022-01-01") { name, company };
    • Implement with @cypher directive;
4. Best Practices
  • Choose Granularity - Day, hour, or second precision?;
  • Index Temporal Properties - Speed up time-based queries;
  • Archive Old Data - Move historical data to separate storage;
  • Consider Performance - Temporal queries can be expensive;
