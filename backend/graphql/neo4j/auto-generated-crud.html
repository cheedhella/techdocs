1. What Gets Auto-Generated?
  • Queries
    • users - get all users;
    • users(where: {...}) - filter users;
    • users(options: {limit, offset, sort}) - pagination and sorting;
  • Mutations
    • createUsers - create one or more users;
    • updateUsers - update existing users;
    • deleteUsers - delete users;
  • Relationship Operations
    • Connect and disconnect nodes;
    • Create nested data in one mutation;
2. Query Examples
  • Get All
    • query { users { id, name, email } };
  • Filter
    • query { users(where: {name: "Alice"}) { id, name } };
    • Supports: equals, contains, starts/ends with, gt/lt, etc;
  • Pagination
    • query { users(options: {limit: 10, offset: 20}) { name } };
  • Sorting
    • query { users(options: {sort: [{name: ASC}]}) { name } };
3. Mutation Examples
  • Create
    • mutation { createUsers(input: [{name: "Alice", email: "alice@example.com"}]) { users { id } } };
  • Update
    • mutation { updateUsers(where: {id: "123"}, update: {name: "Alice Smith"}) { users { name } } };
  • Delete
    • mutation { deleteUsers(where: {id: "123"}) { nodesDeleted } };
4. Benefits
  • Zero Code - No resolver implementation needed;
  • Consistent API - Same patterns across all types;
  • Type Safety - Generated input types ensure valid operations;
  • Performance - Optimized Cypher queries;
  • Extensible - Can add custom resolvers alongside auto-generated ones;
