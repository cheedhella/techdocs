1. What Is Neo4j GraphQL Library?
  • Definition
    • Official library for building GraphQL APIs with Neo4j;
    • Automatically generates resolvers from schema;
    • Handles CRUD operations, filtering, pagination, and more;
  • Key Features
    • Schema-first development;
    • Auto-generated queries and mutations;
    • Built-in relationship handling;
    • Custom Cypher integration;
2. Why Use It?
  • Reduces Boilerplate
    • No need to write resolvers for basic operations;
    • Automatically handles graph traversals;
    • Saves development time;
  • Best Practices Built-In
    • Optimized Cypher query generation;
    • Proper relationship handling;
    • Security features (auth directives);
  • Flexibility
    • Can override auto-generated resolvers;
    • Mix with custom logic;
    • Use @cypher directive for complex queries;
3. Basic Setup
  • Installation
    • npm install @neo4j/graphql neo4j-driver;
  • Simple Example
    • Define schema with type definitions;
    • Create Neo4jGraphQL instance;
    • Generate executable schema;
    • Use with Apollo Server or similar;
4. Core Concepts
  • Directives - Special annotations in schema (@relationship, @cypher, @auth);
  • Auto-Generated Types - Input types, filter types, connection types;
  • Cypher Generation - Library translates GraphQL to Cypher;
  • Driver Integration - Uses official Neo4j driver for database access;
