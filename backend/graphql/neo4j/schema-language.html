1. What Is SDL?
  • Schema Definition Language
    • Human-readable syntax for defining GraphQL schemas;
    • Describes types, fields, and relationships in your API;
    • Forms the contract between client and server;
  • Purpose
    • Define what data can be queried;
    • Specify types and their relationships;
    • Enable validation and introspection;
2. Basic SDL Syntax
  • Type Definition
    • type User { id: ID!, name: String!, email: String! }
    • Defines a User type with three fields;
  • Scalar Types
    • Int, Float, String, Boolean, ID;
    • Custom scalars: DateTime, JSON, etc;
  • Exclamation Mark (!)
    • Indicates non-nullable field;
    • Field must always return a value;
3. Schema Structure
  • Root Types
    • Query - entry point for read operations;
    • Mutation - entry point for write operations;
    • Subscription - entry point for real-time updates;
  • Example Schema
    • type Query { user(id: ID!): User }
    • type Mutation { createUser(name: String!): User }
