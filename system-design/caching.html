1. What is Caching?
  • Caching is the process of storing copies of data in a temporary storage location (cache) so that future requests for that data can be served faster;
  • It reduces the need to access the slower underlying storage layer (like a database or disk);
  • Caches can exist at various levels: Client-side, CDN, Web Server, or Database;
2. Caching Strategies
  • Cache-Aside: The application first checks the cache. If data is missing (cache miss), it fetches it from the database and updates the cache;
  • Write-Through: Data is written to both the cache and the database simultaneously;
  • Write-Behind (Write-Back): Data is written to the cache first, and the database is updated later asynchronously;
3. Cache Eviction Policies
  • LRU (Least Recently Used): Discards the least recently accessed items first;
  • LFU (Least Frequently Used): Discards items that are accessed the least often;
  • FIFO (First In, First Out): Discards the oldest items first;
