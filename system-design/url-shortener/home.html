1. What is a URL Shortener?
  • A service that creates short aliases for long URLs (e.g., bit.ly/3abc);
  • When a user clicks the short link, the service redirects them to the original long URL;
2. Key Requirements
  • Shortening: Generate a unique short key for a given URL;
  • Redirection: Redirect users to the original URL with minimal latency;
  • High Availability: The service must be always available for redirection;
3. High-Level Design
  • API: POST /shorten (long_url) -> short_url; GET /{short_key} -> Redirect;
  • Storage: A NoSQL database (like MongoDB or Cassandra) or a relational database with a mapping of short_key to long_url;
  • Hashing: Use Base62 encoding (a-z, A-Z, 0-9) to generate short keys;
