1. What is YouTube System Design?
  • Designing a video-sharing platform that supports video uploads, processing, and streaming;
  • Must handle massive amounts of data and provide smooth playback globally;
2. Key Features
  • Video Upload: Handling large file transfers;
  • Transcoding: Converting videos into multiple formats and resolutions (e.g., 1080p, 720p, 360p);
  • Streaming: Delivering video content via Adaptive Bitrate Streaming (DASH/HLS);
  • Search & Recommendations: Helping users find relevant content;
3. Architecture Components
  • CDN (Content Delivery Network): Storing and serving video files from locations close to the user;
  • Object Storage: Storing raw and processed video files (e.g., S3 or GCS);
  • Metadata Store: Storing video info, user comments, and view counts (e.g., MySQL with Vitess);
