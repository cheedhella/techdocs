1. What is Uber System Design?
  • Designing a ride-hailing service that matches riders with nearby drivers in real-time;
  • Involves complex geospatial indexing and real-time location tracking;
2. Key Features
  • Location Tracking: Drivers send frequent GPS updates to the server;
  • Matching: Finding the nearest available drivers for a rider's request;
  • Routing & ETA: Calculating the best path and estimated time of arrival;
  • Payments: Handling transactions after the ride;
3. Geospatial Indexing
  • Quadtrees: Dividing the map into quadrants to efficiently find nearby points;
  • Google S2: A library for mapping the earth's surface into a hierarchy of cells;
  • Redis Geo: Using Redis's built-in geospatial features for fast lookups;
