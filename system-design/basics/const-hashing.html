1. What is Consistent Hashing?
  • Consistent hashing is a technique used in distributed systems to evenly distribute data across multiple nodes in a way that minimizes disruption, when nodes are added or removed;
  • The goal of consistent hashing is to map a key to same server, even if the number of servers change;
  • With consistent hashing, when a new node is added/removed, only a fraction of keys, k/n, needs to be remapped, where k=number of keys, n = number of servers;

  • It places all the nodes in virtual ring structure, called hash-ring, by using hash function on node name OR IP address;
  • Theoretically, each node owns a range of the hash-ring, and any requests mapped to that range, will be served by the underlying node;

  • How to map a request to a Node?
    • We hash each request, using the same hash function that we used to hash nodes and map it to the same range of values;
    • Identify that location on the ring and go clockwise from that location until a server is found;
2. How is Consistent Hashing different from Mod function?
  • With mod function, when a new server is added/removed, you need to rehash all the keys, but that's a time consuming operation;
  • With consistent hashing, when a new server is added/removed, only a fraction of keys, k/n, needs to be remapped, where k=number of keys, n = number of servers;
  • With consistent hashing, when a server is removed, only the keys that were mapped to the removed server need to be remapped, while the rest of the keys remain unchanged;
3. Example of Consistent Hashing
  • Imagine a ring with 3 servers:
    • A at position 10
    • B at position 50
    • C at position 80
  • Key hashed to:
    • 45 → goes to B
    • 70 → goes to C
    • 90 → wraps around → goes to A
  • If you add a new server at 60:
    • Only keys between 50 and 60 move to the new server.
4. Where is Consistent Hashing used?
  • Distributed caches (e.g., Memcached, Redis clusters)
  • Distributed databases (e.g., Cassandra, DynamoDB)
  • Load balancing systems
  • Content delivery networks (CDNs)
