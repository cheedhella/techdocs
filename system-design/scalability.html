1. What is Scalability?
  • Scalability is the ability of a system to handle an increasing amount of work by adding resources;
  • A scalable system can maintain its performance levels as the load increases;
2. Vertical vs. Horizontal Scaling
  • Vertical Scaling (Scaling Up): Adding more power (CPU, RAM) to an existing server. It has a physical limit and often requires downtime;
  • Horizontal Scaling (Scaling Out): Adding more servers to the pool. It is more flexible and provides better fault tolerance;
3. Key Considerations
  • Statelessness: Horizontal scaling is easier if services do not store session state locally;
  • Database Scaling: Techniques like Sharding and Replication are used to scale the data layer;
  • Load Balancing: Essential for distributing traffic across multiple scaled instances;
