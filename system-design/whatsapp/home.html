1. What is WhatsApp System Design?
  • Designing a real-time messaging service that supports one-on-one and group chats;
  • Must handle billions of messages daily with low latency and high reliability;
2. Key Features
  • Real-time Messaging: Using WebSockets or XMPP for persistent connections;
  • Message Status: Sent, Delivered, Read notifications;
  • Media Sharing: Handling images, videos, and documents via object storage (S3);
  • End-to-End Encryption: Ensuring privacy for all messages;
3. Architecture Components
  • Chat Service: Manages active connections and message delivery;
  • Presence Service: Tracks online/offline status of users;
  • Message Store: Storing messages for offline users (e.g., Cassandra or HBase);
