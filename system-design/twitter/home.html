1. What is Twitter System Design?
  • Designing a social media platform where users can post short messages (tweets) and follow others;
  • The core challenge is the "Fan-out" problem: delivering a tweet to all followers in real-time;
2. Key Features
  • Tweeting: Posting a new tweet;
  • Timeline: Home timeline (tweets from people you follow) and User timeline;
  • Following: Managing relationships between users;
  • Search: Real-time search for hashtags and keywords;
3. Technical Challenges
  • Fan-out: For celebrities with millions of followers, pushing tweets to every timeline is resource-intensive;
  • Caching: Heavily relying on Redis to store pre-computed timelines for active users;
  • Consistency: Eventual consistency is usually acceptable for timelines;
