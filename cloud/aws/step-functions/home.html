1. What are AWS Step Functions?
  • AWS Step Functions is a serverless visual workflow service that lets you coordinate multiple AWS services into serverless workflows.
  • You can build and update apps quickly by using a visual interface to design workflows (state machines).
2. Use Cases?
  • Orchestrating microservices.
  • Automating IT and security tasks.
  • Building machine learning pipelines.
  • Coordinating long-running tasks (up to 1 year).
