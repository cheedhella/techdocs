1. What is Amazon EBS?
  • Amazon Elastic Block Store (EBS) provides block level storage volumes for use with EC2 instances.
  • EBS volumes behave like raw, unformatted block devices. You can mount these volumes as devices on your instances.
2. S3 vs EBS?
  • S3: Object storage, accessed via API/HTTP, good for static assets, backups, and data lakes.
  • EBS: Block storage, attached to a single EC2 instance, good for databases, file systems, and boot volumes.
