1. What is AWS Secrets Manager?
  • AWS Secrets Manager helps you protect secrets needed to access your applications, services, and IT resources.
  • The service enables you to easily rotate, manage, and retrieve database credentials, API keys, and other secrets throughout their lifecycle.
2. Secrets Manager vs Systems Manager Parameter Store?
  • Secrets Manager: Costs money per secret, supports automatic secret rotation (especially for RDS databases), and integrates with KMS for encryption.
  • Parameter Store: Mostly free (for standard parameters), does not support automatic rotation out-of-the-box, but can also store secure strings using KMS.
