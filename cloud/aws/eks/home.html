1. What is Amazon EKS?
  • Amazon Elastic Kubernetes Service (EKS) is a managed service that makes it easy for you to run Kubernetes on AWS without needing to stand up or maintain your own Kubernetes control plane.
2. Why use EKS over ECS?
  • EKS is ideal if you are already using Kubernetes, want to avoid vendor lock-in, or need the extensive ecosystem of Kubernetes tools and plugins.
  • ECS is simpler and more deeply integrated with other AWS services.
