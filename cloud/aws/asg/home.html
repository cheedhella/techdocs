1. What is an Auto Scaling Group?
  • An Auto Scaling Group (ASG) contains a collection of EC2 instances that are treated as a logical grouping for the purposes of automatic scaling and management.
  • It ensures you have the correct number of EC2 instances available to handle the load for your application.
2. What are the key components?
  • Launch Template/Configuration: Specifies the instance type, AMI, security groups, and key pairs to use when launching new instances.
  • Scaling Policies: Rules that determine when to scale out (add instances) or scale in (remove instances), usually based on CloudWatch metrics like CPU utilization.
  • Desired, Min, and Max Capacity: You can set the minimum, maximum, and desired number of instances in the group.
