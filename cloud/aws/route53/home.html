1. What is Amazon Route 53?
  • Route 53 is a highly available and scalable cloud Domain Name System (DNS) web service.
  • It translates domain names (like www.example.com) into IP addresses.
2. What are the common routing policies in Route 53?
  • Simple Routing: Used for a single resource that performs a given function for your domain.
  • Weighted Routing: Used to route traffic to multiple resources in proportions that you specify.
  • Latency Routing: Used when you have resources in multiple AWS Regions and you want to route traffic to the region that provides the best latency.
  • Failover Routing: Used when you want to configure active-passive failover.
  • Geolocation Routing: Used to route traffic based on the location of your users.
