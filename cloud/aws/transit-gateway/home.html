1. What is AWS Transit Gateway?
  • AWS Transit Gateway connects VPCs and on-premises networks through a central hub.
  • This simplifies your network and puts an end to complex peering relationships. It acts as a cloud router – each new connection is only made once.
2. Why use Transit Gateway?
  • Without Transit Gateway, connecting multiple VPCs requires VPC Peering, which creates a complex mesh network (n*(n-1)/2 connections).
  • Transit Gateway uses a hub-and-spoke model, drastically reducing the number of connections needed and simplifying network management.
