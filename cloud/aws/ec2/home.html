1. What is EC2?
  • EC2 provides scalable computing capacity in the AWS cloud.
  • It allows you to rent virtual computers (instances) on which to run your own computer applications.
2. What are the different EC2 pricing models?
  • On-Demand: Pay by the hour or second, no long-term commitments.
  • Reserved Instances: Discounted rate for a 1 or 3-year commitment.
  • Spot Instances: Bid on unused EC2 capacity, highly discounted but can be terminated with a 2-minute warning.
  • Dedicated Hosts: Physical EC2 server dedicated for your use, useful for compliance and licensing.
3. What is an AMI?
  • Amazon Machine Image (AMI) provides the information required to launch an instance.
  • It includes the operating system, application server, and applications.
