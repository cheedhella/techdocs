1. What is Amazon RDS?
  • RDS is a managed relational database service that makes it easy to set up, operate, and scale a relational database in the cloud.
  • Supports engines like MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon Aurora.
2. Multi-AZ vs. Read Replicas?
  • Multi-AZ: Used for high availability and disaster recovery. Synchronous replication to a standby instance in a different Availability Zone.
  • Read Replicas: Used for scalability (read-heavy workloads). Asynchronous replication to one or more read-only instances.
