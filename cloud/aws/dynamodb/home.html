1. What is Amazon DynamoDB?
  • DynamoDB is a fully managed NoSQL database service that provides fast and predictable performance with seamless scalability.
  • It is a key-value and document database.
2. What are the key features of DynamoDB?
  • Serverless: No servers to provision, patch, or manage.
  • Performance: Single-digit millisecond latency at any scale.
  • DAX (DynamoDB Accelerator): An in-memory cache that delivers microsecond response times.
  • Global Tables: Fully managed, multi-region, and multi-active database.
