1. What is Amazon S3?
  • S3 is an object storage service offering industry-leading scalability, data availability, security, and performance.
  • Data is stored as objects within resources called "buckets".
2. What are the S3 storage classes?
  • S3 Standard: General purpose, frequently accessed data.
  • S3 Intelligent-Tiering: Automatically moves data to the most cost-effective tier based on access patterns.
  • S3 Standard-IA (Infrequent Access): For data accessed less frequently but requires rapid access when needed.
  • S3 One Zone-IA: Lower cost, stores data in a single Availability Zone.
  • S3 Glacier: Low-cost storage for data archiving.
  • S3 Glacier Deep Archive: Lowest cost storage class for long-term retention.
