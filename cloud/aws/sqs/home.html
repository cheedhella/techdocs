1. What is Amazon SQS?
  • Simple Queue Service (SQS) is a fully managed message queuing service that enables you to decouple and scale microservices, distributed systems, and serverless applications.
  • It uses a pull-based (polling) mechanism.
2. Standard vs FIFO Queues?
  • Standard Queues: Maximum throughput, best-effort ordering, at-least-once delivery (duplicates can occur).
  • FIFO Queues: First-In-First-Out delivery, exactly-once processing, limited throughput compared to standard queues.
