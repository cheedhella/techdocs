1. What is Amazon Kinesis?
  • Amazon Kinesis makes it easy to collect, process, and analyze real-time, streaming data so you can get timely insights and react quickly to new information.
2. What are the Kinesis Services?
  • Kinesis Data Streams: Capture, process, and store data streams. Requires provisioning shards.
  • Kinesis Data Firehose: Load data streams into AWS data stores (S3, Redshift, Elasticsearch). Fully managed, no shards to manage.
  • Kinesis Data Analytics: Analyze data streams with SQL or Apache Flink.
  • Kinesis Video Streams: Capture, process, and store video streams.
