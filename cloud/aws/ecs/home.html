1. What is Amazon ECS?
  • Amazon Elastic Container Service (ECS) is a highly scalable, fast, container management service that makes it easy to run, stop, and manage Docker containers on a cluster.
2. Fargate vs EC2 Launch Types?
  • Fargate: Serverless compute for containers. You don't have to provision, configure, or scale clusters of virtual machines to run containers.
  • EC2: You manage the EC2 instances that run the containers. Provides more control over the underlying infrastructure.
