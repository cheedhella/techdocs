1. What is Amazon CloudFront?
  • CloudFront is a fast content delivery network (CDN) service that securely delivers data, videos, applications, and APIs to customers globally with low latency and high transfer speeds.
2. How does CloudFront work?
  • It caches copies of your static and dynamic content at Edge Locations around the world.
  • When a user requests content, CloudFront routes the request to the edge location that provides the lowest latency.
