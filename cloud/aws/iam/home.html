1. What is IAM?
  • IAM stands for Identity and Access Management.
  • It allows you to manage access to AWS services and resources securely.
  • IAM is global, meaning it applies across all AWS regions.
2. What are the core components of IAM?
  • Users: End users (people or services).
  • Groups: A collection of users. Each user in the group will inherit the permissions of the group.
  • Roles: You create roles and can then assign them to AWS resources (like EC2 instances).
  • Policies: Documents that define permissions (JSON format) and are attached to users, groups, or roles.
3. What is the Principle of Least Privilege?
  • It means giving a user only the minimum permissions necessary to perform their job.
  • This is a security best practice in AWS.
