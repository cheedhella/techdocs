1. What is AWS CloudFormation?
  • AWS CloudFormation gives you an easy way to model a collection of related AWS and third-party resources, provision them quickly and consistently, and manage them throughout their lifecycles.
  • It is an Infrastructure as Code (IaC) service.
2. How does it work?
  • You write a template (in JSON or YAML) that describes your desired resources and their dependencies.
  • CloudFormation reads the template and provisions the resources in a "stack".
  • If a resource fails to create, CloudFormation rolls back the entire stack to its previous state.
