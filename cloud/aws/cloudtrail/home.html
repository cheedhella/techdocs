1. What is AWS CloudTrail?
  • CloudTrail is a service that enables governance, compliance, operational auditing, and risk auditing of your AWS account.
  • It records API calls and user activity across your AWS infrastructure (answers "Who did what, when, and from where?").
2. CloudWatch vs CloudTrail?
  • CloudWatch: Focuses on performance monitoring and metrics (What is happening?).
  • CloudTrail: Focuses on auditing and API logging (Who did it?).
