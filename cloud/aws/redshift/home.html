1. What is Amazon Redshift?
  • Amazon Redshift is a fast, scalable data warehouse that makes it simple and cost-effective to analyze all your data across your data warehouse and data lake.
  • It uses columnar storage and massively parallel processing (MPP) to deliver fast query performance.
2. What are the key features?
  • Columnar Data Storage: Stores data by column rather than by row, reducing the amount of data read from disk.
  • Advanced Compression: Columnar data can be compressed heavily, saving storage space.
  • Redshift Spectrum: Allows you to query data directly from files on Amazon S3 without having to load the data into Redshift tables.
