1. What is Elastic Load Balancing?
  • ELB automatically distributes incoming application traffic across multiple targets, such as Amazon EC2 instances, containers, IP addresses, and Lambda functions.
2. What are the types of Load Balancers?
  • Application Load Balancer (ALB): Operates at Layer 7 (HTTP/HTTPS). Ideal for advanced routing based on content (e.g., path-based routing).
  • Network Load Balancer (NLB): Operates at Layer 4 (TCP/UDP). Ideal for high performance, ultra-low latency, and static IP addresses.
  • Gateway Load Balancer (GLWB): Used to deploy, scale, and run third-party virtual networking appliances (like firewalls).
  • Classic Load Balancer (CLB): Legacy load balancer, not recommended for new applications.
