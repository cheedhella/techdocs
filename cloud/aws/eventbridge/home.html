1. What is Amazon EventBridge?
  • Amazon EventBridge is a serverless event bus that makes it easier to build event-driven applications at scale using events generated from your applications, integrated Software-as-a-Service (SaaS) applications, and AWS services.
  • It is the evolution of Amazon CloudWatch Events.
2. Features of EventBridge?
  • Event Buses: A router that receives events and delivers them to zero or more destinations, or targets.
  • Rules: Match incoming events and route them to targets for processing.
  • Schema Registry: Stores event schemas in a registry that other developers can easily search and access.
