1. What is Amazon API Gateway?
  • API Gateway is a fully managed service that makes it easy for developers to create, publish, maintain, monitor, and secure APIs at any scale.
  • It acts as a "front door" for applications to access data, business logic, or functionality from your backend services.
2. What are the key features of API Gateway?
  • Supports RESTful APIs and WebSocket APIs.
  • Handles traffic management, CORS support, authorization and access control, throttling, monitoring, and API version management.
  • Integrates seamlessly with AWS Lambda for serverless architectures.
