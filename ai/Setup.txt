What is virtual environment?
    What Is a Virtual Environment?
    A virtual environment is an isolated Python environment. It lets you:

    Install project-specific dependencies without affecting system-wide Python.

    Avoid conflicts between different project requirements.

    Keep your global Python installation clean.

    📁 What Gets Created in .venv?
    Inside the .venv folder, you'll find:

    A copy of the Python interpreter.

    A local Scripts/ directory with:

    python.exe

    pip.exe

    An isolated environment to install packages with pip.

    ▶️ How to Activate the Virtual Environment (Windows)
    Once it's created, activate it with:

    bash
    Copy
    Edit
    .venv\Scripts\activate
