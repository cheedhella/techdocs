What is the UndoEngine?
The UndoEngine provides undo/redo functionality for graph modifications, allowing users to revert and replay changes.
How do you enable undo/redo?
const graph = graphComponent.graph;

// Enable undo engine
graph.undoEngineEnabled = true;

// Perform operations (automatically tracked)
const node = graph.createNode();
graph.addLabel(node, 'Test');

// Undo
graph.undoEngine.undo();

// Redo
graph.undoEngine.redo();

// Check if undo/redo available
console.log('Can undo:', graph.undoEngine.canUndo());
console.log('Can redo:', graph.undoEngine.canRedo());
How do you add keyboard shortcuts for undo/redo?
const inputMode = new GraphEditorInputMode();

// Ctrl+Z for undo
inputMode.keyboardInputMode.addCommandBinding(
    ICommand.UNDO,
    () => {
        if (graph.undoEngine.canUndo()) {
            graph.undoEngine.undo();
        }
        return true;
    }
);

// Ctrl+Y for redo
inputMode.keyboardInputMode.addCommandBinding(
    ICommand.REDO,
    () => {
        if (graph.undoEngine.canRedo()) {
            graph.undoEngine.redo();
        }
        return true;
    }
);

graphComponent.inputMode = inputMode;
