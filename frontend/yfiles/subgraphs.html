What are Subgraphs?
Subgraphs are partial views of a graph, allowing you to work with specific subsets of nodes and edges. They're useful for focusing on relevant parts of large graphs.
How do you create subgraphs?
// Get subset of nodes
const selectedNodes = graphComponent.selection.selectedNodes.toArray();

// Create subgraph with selected nodes and their edges
const subgraphNodes = new Set(selectedNodes);
const subgraphEdges = graph.edges
    .filter(e => 
        subgraphNodes.has(e.sourceNode) && 
        subgraphNodes.has(e.targetNode)
    )
    .toArray();

// Apply layout to subgraph only
const layoutData = new HierarchicLayoutData();
layoutData.affectedNodes.items = selectedNodes;
await graphComponent.morphLayout(
    new HierarchicLayout(),
    layoutData
);
