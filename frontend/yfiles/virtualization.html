What is Virtualization?
Virtualization is a technique where only visible elements in the viewport are rendered, dramatically improving performance for large graphs. Elements outside the viewport are not rendered until they come into view.
How does yFiles handle virtualization?
yFiles automatically virtualizes rendering by default. The GraphComponent only renders elements that are visible or near the viewport. You can optimize further by: 
// Disable rendering during bulk updates
graphComponent.updateContentRect();

// Batch multiple changes
graph.beginEdit();
try {
    // Make multiple changes
    for (let i = 0; i < 1000; i++) {
        const node = graph.createNode();
        graph.addLabel(node, `Node ${i}`);
    }
} finally {
    graph.endEdit();
}

// Invalidate and redraw
graphComponent.invalidate();
