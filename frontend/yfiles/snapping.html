What is Snapping?
Snapping provides alignment assistance when moving or resizing nodes, helping users create neat, aligned layouts by automatically snapping to grid lines or other nodes.
How do you enable snapping?
const inputMode = new GraphEditorInputMode();

// Enable snapping
inputMode.snapContext = new GraphSnapContext({
    enabled: true,
    snapDistance: 10,
    snapToGridEnabled: true,
    gridSnapType: GridSnapTypes.ALL
});

// Configure grid snapping
inputMode.snapContext.gridSpacing = 20;

// Enable node-to-node snapping
inputMode.snapContext.nodeToNodeDistance = 20;
inputMode.snapContext.nodeToEdgeDistance = 15;

graphComponent.inputMode = inputMode;
