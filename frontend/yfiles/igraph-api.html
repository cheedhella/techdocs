What is the IGraph API?
IGraph is the main interface in yFiles for creating, modifying, and querying graph structures. It serves as the core programming entry point for all graph operations and provides a comprehensive set of methods to work with nodes, edges, labels, and ports.
How do you access the IGraph instance?
The IGraph instance is typically accessed through the GraphComponent: 
// From a GraphComponent
const graph = graphComponent.graph;

// Or create a standalone graph
const graph = new DefaultGraph();
What are the main node operations in IGraph?
IGraph provides these essential node operations:
  • createNode(layout?) - Create a new node
  • createNodeAt(location) - Create node at specific position
  • remove(node) - Delete a node
  • setNodeLayout(node, layout) - Change node position/size
  • setStyle(node, style) - Change node appearance
  • nodes - Get all nodes (IEnumerable)
  • contains(node) - Check if node exists
What are the main edge operations in IGraph?
IGraph provides these edge operations:
  • createEdge(source, target) - Create edge between nodes
  • createEdge(sourcePort, targetPort) - Create edge using ports
  • remove(edge) - Delete an edge
  • setStyle(edge, style) - Change edge appearance
  • edges - Get all edges
  • edgesAt(node) - Get edges connected to a node
  • inDegree(node) - Count incoming edges
  • outDegree(node) - Count outgoing edges
How do you work with labels using IGraph?
Label operations in IGraph:
  • addLabel(owner, text) - Add label to node/edge
  • addLabel(owner, text, parameter) - Add with specific placement
  • remove(label) - Delete a label
  • setLabelText(label, text) - Change label text
  • setStyle(label, style) - Change label appearance
  • setLabelLayoutParameter(label, parameter) - Reposition label
How do you work with ports in IGraph?
Port operations in IGraph:
  • addPort(node) - Add port to node
  • addPort(node, locationParameter) - Add port at specific location
  • remove(port) - Delete a port
  • setPortLocationParameter(port, parameter) - Move port
  • ports - Get all ports
  • degree(port) - Count edges at port
What are grouping operations in IGraph?
IGraph supports hierarchical grouping:
  • groupNodes(parent, children) - Create group hierarchy
  • setParent(node, parent) - Move node into group
  • getParent(node) - Get parent group
  • getChildren(node) - Get child nodes
  • isGroupNode(node) - Check if node is a group
How do you query graph structure with IGraph?
IGraph provides powerful query methods: 
// Get all nodes
for (const node of graph.nodes) {
    console.log(node);
}

// Get neighbors
const neighbors = graph.neighbors(node);

// Get predecessors (nodes with edges to this node)
const predecessors = graph.predecessors(node);

// Get successors (nodes this node has edges to)
const successors = graph.successors(node);

// Check connectivity
const isConnected = graph.contains(
    graph.getEdge(source, target)
);

// Get degree
const inDegree = graph.inDegree(node);
const outDegree = graph.outDegree(node);
What are IGraph decorators and how are they used?
Decorators allow you to attach additional data or behavior to graph elements: 
// Create a decorator for node data
const nodeDataDecorator = graph.decorator.nodeDecorator;

// Set custom data
nodeDataDecorator.dataProviderDecorator.setImplementation(
    node => ({ customData: "value" })
);

// Access the data later
const data = nodeDataDecorator.dataProviderDecorator
    .getImplementation(node);
Can you show a complete example using IGraph API?
Here's a comprehensive example: 
// Get the graph
const graph = graphComponent.graph;

// Create nodes with custom layout
const node1 = graph.createNode(
    new Rect(0, 0, 100, 60)
);
const node2 = graph.createNode(
    new Rect(200, 100, 100, 60)
);
const node3 = graph.createNode(
    new Rect(400, 0, 100, 60)
);

// Add labels
graph.addLabel(node1, "Input");
graph.addLabel(node2, "Process");
graph.addLabel(node3, "Output");

// Create edges
const edge1 = graph.createEdge(node1, node2);
const edge2 = graph.createEdge(node2, node3);

// Add edge labels
graph.addLabel(edge1, "Step 1");
graph.addLabel(edge2, "Step 2");

// Query the graph
console.log(`Nodes: ${graph.nodes.size}`);
console.log(`Edges: ${graph.edges.size}`);
console.log(`Node2 in-degree: ${graph.inDegree(node2)}`);
console.log(`Node2 out-degree: ${graph.outDegree(node2)}`);

// Modify the graph
graph.setNodeLayout(
    node2, 
    new Rect(200, 50, 120, 80)
);

// Remove an element
graph.remove(edge1);
