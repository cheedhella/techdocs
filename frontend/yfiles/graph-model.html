What is the Graph Model in yFiles?
The Graph Model is the fundamental data structure in yFiles that represents graphs through four main components:
  • Nodes: The vertices or points in the graph
  • Edges: The connections between nodes
  • Labels: Text annotations attached to nodes or edges
  • Ports: Specific connection points on nodes where edges attach
This model provides the foundation for all graph visualization and manipulation in yFiles.
Why is understanding the Graph Model important?
The Graph Model is crucial because:
  • It's the core abstraction for all graph operations
  • Every feature in yFiles builds upon this model
  • Understanding it enables you to create, modify, and query graphs effectively
  • It provides a consistent API across different yFiles platforms
What are the key properties of nodes in the Graph Model?
Nodes in yFiles have several important properties:
  • Layout: Position (x, y) and size (width, height)
  • Style: Visual appearance (shape, color, etc.)
  • Labels: Associated text annotations
  • Ports: Connection points for edges
  • Tag: Custom data object for business logic
  • Parent: Optional parent node for grouping
What are the key properties of edges in the Graph Model?
Edges connect nodes and have these properties:
  • Source Node: The node where the edge starts
  • Target Node: The node where the edge ends
  • Source Port: Specific connection point on source node
  • Target Port: Specific connection point on target node
  • Style: Visual appearance (line type, arrows, etc.)
  • Bends: Points that define the edge path
  • Labels: Text annotations on the edge
  • Tag: Custom data object
How do labels work in the Graph Model?
Labels are text elements that can be attached to both nodes and edges:
  • Each node or edge can have multiple labels
  • Labels have their own position, size, and style
  • Label placement is controlled by Label Models
  • Labels can be interactive (editable, selectable)
  • They improve readability and provide context
What role do ports play in the Graph Model?
Ports are connection points on nodes that provide precise control over edge routing:
  • They define exactly where edges connect to nodes
  • Multiple edges can share the same port
  • Ports can be positioned anywhere on or around a node
  • They enable cleaner, more organized graph layouts
  • Port constraints can restrict which edges can connect
How is the Graph Model accessed and modified?
The Graph Model is accessed through the IGraph interface:
  • Create nodes: graph.createNode()
  • Create edges: graph.createEdge(source, target)
  • Add labels: graph.addLabel(node, "text")
  • Remove elements: graph.remove(node)
  • Query elements: graph.nodes, graph.edges
  • Modify layout: graph.setNodeLayout(node, rect)
Can you provide a simple example of creating a graph?
Here's a basic example of creating a simple graph: 
// Get the graph from the GraphComponent
const graph = graphComponent.graph;

// Create two nodes
const node1 = graph.createNode(new Rect(0, 0, 100, 60));
const node2 = graph.createNode(new Rect(200, 0, 100, 60));

// Add labels to the nodes
graph.addLabel(node1, "Start");
graph.addLabel(node2, "End");

// Create an edge connecting the nodes
const edge = graph.createEdge(node1, node2);

// Add a label to the edge
graph.addLabel(edge, "connects to");

// Apply a layout
graphComponent.fitGraphBounds();
