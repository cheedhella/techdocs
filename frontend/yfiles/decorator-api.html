What is the Decorator API?
The Decorator API allows you to extend and customize graph element behavior without modifying the core graph structure. It's used for adding custom visuals, handles, and interaction logic.
How do you use decorators?
// Access decorator
const decorator = graph.decorator.nodeDecorator;

// Add custom highlight
decorator.highlightDecorator.setImplementation(
    new NodeStyleDecorationInstaller({
        nodeStyle: new ShapeNodeStyle({
            stroke: '3px yellow',
            fill: 'transparent'
        })
    })
);

// Add custom selection indicator
decorator.selectionDecorator.setImplementation(
    new NodeStyleDecorationInstaller({
        nodeStyle: new ShapeNodeStyle({
            stroke: '3px blue',
            fill: 'rgba(0, 0, 255, 0.1)'
        })
    })
);
