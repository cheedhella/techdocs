What is a Minimum Spanning Tree?
A Minimum Spanning Tree (MST) is a subset of edges that connects all nodes with the minimum total edge weight, without forming cycles. It's useful for network design and optimization problems.
How do you find the MST?
// Find minimum spanning tree
const mstAlgorithm = new SpanningTree({
    costs: edge => edge.tag?.weight || 1
});

const result = mstAlgorithm.run(graph);

console.log(`MST has ${result.edges.size} edges`);

// Highlight MST edges
const highlightManager = graphComponent.highlightIndicatorManager;
result.edges.forEach(edge => {
    highlightManager.addHighlight(edge);
    graph.setStyle(edge, new PolylineEdgeStyle({
        stroke: '4px green',
        targetArrow: IArrow.NONE
    }));
});

// Calculate total MST cost
let totalCost = 0;
result.edges.forEach(edge => {
    totalCost += edge.tag?.weight || 1;
});
console.log(`Total MST cost: ${totalCost}`);
