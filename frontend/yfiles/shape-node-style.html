What is ShapeNodeStyle?
ShapeNodeStyle is the most commonly used node style in yFiles, providing a variety of predefined shapes with customizable appearance. It supports shapes like rectangles, ellipses, diamonds, hexagons, and more.
What shapes are available?
// Available shapes:
- 'rectangle'
- 'round-rectangle'
- 'ellipse'
- 'hexagon'
- 'hexagon2'
- 'octagon'
- 'diamond'
- 'triangle'
- 'triangle2'
- 'pill'
- 'fat-arrow'
- 'fat-arrow2'
- 'star5'
- 'star6'
- 'star8'
How do you configure ShapeNodeStyle?
// Basic configuration
const style = new ShapeNodeStyle({
    shape: 'round-rectangle',
    fill: 'lightblue',
    stroke: '2px darkblue'
});

// With gradient fill
const gradientStyle = new ShapeNodeStyle({
    shape: 'ellipse',
    fill: new LinearGradient({
        startPoint: [0, 0],
        endPoint: [0, 1],
        colorStops: [
            { color: 'lightblue', offset: 0 },
            { color: 'darkblue', offset: 1 }
        ]
    }),
    stroke: '2px navy'
});

// With corner radius
const roundedStyle = new ShapeNodeStyle({
    shape: 'round-rectangle',
    fill: 'lightgreen',
    stroke: '2px darkgreen'
});

graph.setStyle(node, style);
Can you show examples of different shapes?
const graph = graphComponent.graph;

// Rectangle
const rect = graph.createNode(new Rect(0, 0, 100, 60));
graph.setStyle(rect, new ShapeNodeStyle({
    shape: 'rectangle',
    fill: 'lightblue'
}));

// Ellipse
const ellipse = graph.createNode(new Rect(150, 0, 100, 60));
graph.setStyle(ellipse, new ShapeNodeStyle({
    shape: 'ellipse',
    fill: 'lightgreen'
}));

// Diamond
const diamond = graph.createNode(new Rect(300, 0, 100, 60));
graph.setStyle(diamond, new ShapeNodeStyle({
    shape: 'diamond',
    fill: 'lightyellow'
}));

// Hexagon
const hexagon = graph.createNode(new Rect(450, 0, 100, 60));
graph.setStyle(hexagon, new ShapeNodeStyle({
    shape: 'hexagon',
    fill: 'lightcoral'
}));
