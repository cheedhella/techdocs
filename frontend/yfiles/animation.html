What is Animation in yFiles?
Animation provides smooth visual transitions when graph elements change position, size, or appearance. It improves user experience by making changes easier to follow.
How do you animate layout changes?
// Animated layout with default duration (1 second)
await graphComponent.morphLayout(new HierarchicLayout());

// Custom duration
await graphComponent.morphLayout(new HierarchicLayout(), '2s');

// With easing
await graphComponent.morphLayout({
    layout: new HierarchicLayout(),
    morphDuration: '1.5s',
    easedAnimation: true
});

// Animate viewport changes
graphComponent.zoomToAnimated(new Rect(0, 0, 500, 500));
graphComponent.fitGraphBounds(new Insets(20), true);
How do you create custom animations?
// Custom animation using IAnimation
const animator = new Animator(graphComponent);

// Animate node movement
const animation = IAnimation.createNodeAnimation(
    graph,
    node,
    node.layout.toRect(),
    new Rect(200, 200, 100, 60),
    '1s'
);

animator.animate(animation);
