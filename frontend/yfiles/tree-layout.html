What is TreeLayout?
TreeLayout arranges graphs in tree structures with a clear root-to-leaf hierarchy. It's perfect for:
  • Organization charts
  • File system hierarchies
  • Decision trees
  • Taxonomies
  • Any tree-structured data
How do you apply TreeLayout?
// Basic tree layout
const layout = new TreeLayout();
await graphComponent.morphLayout(layout);

// With configuration
const layout = new TreeLayout({
    layoutOrientation: LayoutOrientation.TOP_TO_BOTTOM,
    minimumNodeDistance: 40,
    minimumLayerDistance: 60
});

await graphComponent.morphLayout(layout);
What are the key configuration options?
const layout = new TreeLayout({
    // Orientation
    layoutOrientation: LayoutOrientation.TOP_TO_BOTTOM,
    // or LEFT_TO_RIGHT, BOTTOM_TO_TOP, RIGHT_TO_LEFT
    
    // Spacing
    minimumNodeDistance: 30,
    minimumLayerDistance: 50,
    
    // Node placer (how children are arranged)
    defaultNodePlacer: new DefaultNodePlacer({
        routingStyle: TreeLayoutEdgeRoutingStyle.ORTHOGONAL
    }),
    
    // Consider node sizes
    considerNodeSizes: true
});
How do you specify the root node?
const layout = new TreeLayout();
const layoutData = new TreeLayoutData();

// Specify root node
layoutData.treeRoot.item = rootNode;

await graphComponent.morphLayout(layout, layoutData);
Can you show an example?
// Create an organization chart
const graph = graphComponent.graph;

// Create CEO node
const ceo = graph.createNode();
graph.addLabel(ceo, 'CEO');

// Create department heads
const cto = graph.createNode();
graph.addLabel(cto, 'CTO');
const cfo = graph.createNode();
graph.addLabel(cfo, 'CFO');
const cmo = graph.createNode();
graph.addLabel(cmo, 'CMO');

// Create team members
const dev1 = graph.createNode();
graph.addLabel(dev1, 'Dev 1');
const dev2 = graph.createNode();
graph.addLabel(dev2, 'Dev 2');

// Create hierarchy
graph.createEdge(ceo, cto);
graph.createEdge(ceo, cfo);
graph.createEdge(ceo, cmo);
graph.createEdge(cto, dev1);
graph.createEdge(cto, dev2);

// Apply tree layout
const layout = new TreeLayout({
    layoutOrientation: LayoutOrientation.TOP_TO_BOTTOM,
    minimumNodeDistance: 50,
    minimumLayerDistance: 80
});

const layoutData = new TreeLayoutData();
layoutData.treeRoot.item = ceo;

await graphComponent.morphLayout(layout, layoutData);
graphComponent.fitGraphBounds(new Insets(20));
