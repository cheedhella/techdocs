What are Nodes in yFiles?
Nodes are the fundamental vertices or points in a graph. They represent entities in your data model and can be:
  • Positioned anywhere in 2D space
  • Sized with custom width and height
  • Styled with various visual appearances
  • Connected to other nodes via edges
  • Grouped into hierarchical structures
  • Associated with custom business data via tags
How do you create nodes?
There are several ways to create nodes: 
const graph = graphComponent.graph;

// Create node with default size at origin
const node1 = graph.createNode();

// Create node with specific layout (position and size)
const node2 = graph.createNode(
    new Rect(100, 50, 80, 60)
);

// Create node at specific location with default size
const node3 = graph.createNodeAt(
    new Point(200, 100)
);

// Create node with custom style
const node4 = graph.createNode({
    layout: new Rect(300, 0, 100, 80),
    style: new ShapeNodeStyle({
        fill: 'lightblue',
        stroke: 'darkblue'
    })
});
What are Edges in yFiles?
Edges are connections between nodes that represent relationships. They have:
  • A source node (where the edge starts)
  • A target node (where the edge ends)
  • Optional source and target ports
  • Bends that define the edge path
  • Styles for visual appearance
  • Labels for annotations
  • Direction (can be directed or undirected)
How do you create edges?
Edges can be created in multiple ways: 
const graph = graphComponent.graph;

// Create edge between two nodes
const edge1 = graph.createEdge(sourceNode, targetNode);

// Create edge with specific ports
const sourcePort = graph.addPort(sourceNode);
const targetPort = graph.addPort(targetNode);
const edge2 = graph.createEdge(sourcePort, targetPort);

// Create edge with custom style
const edge3 = graph.createEdge({
    source: sourceNode,
    target: targetNode,
    style: new PolylineEdgeStyle({
        stroke: '2px red',
        targetArrow: IArrow.TRIANGLE
    })
});

// Create self-loop (edge from node to itself)
const selfLoop = graph.createEdge(node1, node1);
How do you modify node properties?
Node properties can be modified after creation: 
const graph = graphComponent.graph;

// Change node position and size
graph.setNodeLayout(
    node, 
    new Rect(150, 200, 120, 80)
);

// Change node style
graph.setStyle(
    node,
    new ShapeNodeStyle({
        shape: 'ellipse',
        fill: 'lightgreen'
    })
);

// Attach custom data
node.tag = {
    id: 'node-1',
    type: 'process',
    data: { value: 42 }
};

// Move node relative to current position
const currentLayout = node.layout;
graph.setNodeLayout(
    node,
    new Rect(
        currentLayout.x + 50,
        currentLayout.y + 30,
        currentLayout.width,
        currentLayout.height
    )
);
How do you work with edge bends?
Edge bends define the path an edge takes: 
const graph = graphComponent.graph;

// Add bends to an edge
graph.addBend(edge, new Point(150, 100));
graph.addBend(edge, new Point(200, 150));

// Clear all bends
graph.clearBends(edge);

// Get edge bends
const bends = edge.bends;
for (const bend of bends) {
    console.log(bend.location);
}

// Set multiple bends at once
graph.setBends(edge, [
    new Point(100, 50),
    new Point(150, 100),
    new Point(200, 50)
]);
How do you query nodes and edges?
yFiles provides powerful query methods: 
const graph = graphComponent.graph;

// Get all nodes
const allNodes = graph.nodes.toArray();

// Get all edges
const allEdges = graph.edges.toArray();

// Get edges connected to a node
const connectedEdges = graph.edgesAt(node);

// Get incoming edges
const incomingEdges = graph.inEdgesAt(node);

// Get outgoing edges
const outgoingEdges = graph.outEdgesAt(node);

// Get neighbor nodes
const neighbors = graph.neighbors(node).toArray();

// Check if edge exists
const edgeExists = graph.contains(
    graph.getEdge(sourceNode, targetNode)
);

// Get node degree
const totalDegree = graph.degree(node);
const inDegree = graph.inDegree(node);
const outDegree = graph.outDegree(node);
How do you remove nodes and edges?
Removing elements is straightforward: 
const graph = graphComponent.graph;

// Remove a single edge
graph.remove(edge);

// Remove a node (also removes connected edges)
graph.remove(node);

// Remove multiple nodes
const nodesToRemove = graph.nodes
    .filter(n => n.tag?.type === 'temporary')
    .toArray();
nodesToRemove.forEach(n => graph.remove(n));

// Clear entire graph
graph.clear();

// Remove all edges but keep nodes
const edgesToRemove = graph.edges.toArray();
edgesToRemove.forEach(e => graph.remove(e));
Can you show a practical example with nodes and edges?
Here's a complete example creating a simple workflow: 
const graph = graphComponent.graph;

// Create nodes for a workflow
const start = graph.createNode(new Rect(0, 0, 100, 60));
start.tag = { type: 'start', name: 'Begin' };

const process1 = graph.createNode(new Rect(150, 0, 100, 60));
process1.tag = { type: 'process', name: 'Validate' };

const decision = graph.createNode(new Rect(300, 0, 100, 60));
decision.tag = { type: 'decision', name: 'Valid?' };

const process2 = graph.createNode(new Rect(450, -50, 100, 60));
process2.tag = { type: 'process', name: 'Process' };

const error = graph.createNode(new Rect(450, 50, 100, 60));
error.tag = { type: 'error', name: 'Error' };

const end = graph.createNode(new Rect(600, 0, 100, 60));
end.tag = { type: 'end', name: 'Complete' };

// Create edges with labels
const e1 = graph.createEdge(start, process1);
const e2 = graph.createEdge(process1, decision);
const e3 = graph.createEdge(decision, process2);
graph.addLabel(e3, 'Yes');
const e4 = graph.createEdge(decision, error);
graph.addLabel(e4, 'No');
const e5 = graph.createEdge(process2, end);
const e6 = graph.createEdge(error, end);

// Add labels to nodes
graph.nodes.forEach(node => {
    graph.addLabel(node, node.tag.name);
});

// Apply layout
graphComponent.fitGraphBounds();
