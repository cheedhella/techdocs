What is DataItem binding?
DataItem binding connects business objects to graph elements, allowing you to associate custom data with nodes, edges, and labels.
How do you bind data to graph elements?
// Business data
const personData = {
    id: 1,
    name: 'John Doe',
    age: 30,
    role: 'Developer',
    email: 'john@example.com'
};

// Create node and attach data via tag
const node = graph.createNode();
node.tag = personData;

// Add label from data
graph.addLabel(node, personData.name);

// Later, access the data
const data = node.tag;
console.log(`Name: ${data.name}, Role: ${data.role}`);
How do you use data for conditional styling?
// Apply styles based on data
graph.nodes.forEach(node => {
    const data = node.tag;
    
    let style;
    if (data.role === 'Manager') {
        style = new ShapeNodeStyle({
            fill: 'lightblue',
            shape: 'hexagon'
        });
    } else if (data.role === 'Developer') {
        style = new ShapeNodeStyle({
            fill: 'lightgreen',
            shape: 'round-rectangle'
        });
    } else {
        style = new ShapeNodeStyle({
            fill: 'lightgray',
            shape: 'ellipse'
        });
    }
    
    graph.setStyle(node, style);
});
