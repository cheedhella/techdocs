What are Incremental Updates?
Incremental updates allow you to modify parts of the graph and re-layout only the affected areas, preserving the overall structure and improving performance.
How do you perform incremental updates?
// Configure incremental layout
const layout = new HierarchicLayout({
    layoutMode: LayoutMode.INCREMENTAL
});

const layoutData = new HierarchicLayoutData();

// Mark new nodes
const newNodes = [];
newNodes.forEach(node => {
    node.tag = { ...node.tag, isNew: true };
});

layoutData.incrementalHints.mapper = node => {
    if (node.tag?.isNew) {
        return HierarchicLayoutIncrementalHints.NEW;
    }
    return HierarchicLayoutIncrementalHints.NONE;
};

// Apply incremental layout
await graphComponent.morphLayout(layout, layoutData);

// Clear new flags
newNodes.forEach(node => {
    node.tag.isNew = false;
});
