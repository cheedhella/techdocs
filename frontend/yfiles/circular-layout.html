What is CircularLayout?
CircularLayout arranges nodes in circular or ring patterns. It's ideal for:
  • Cyclic processes
  • Ring topologies
  • Circular dependencies
  • Highlighting central nodes
  • Periodic or cyclical data
How do you apply CircularLayout?
// Basic circular layout
const layout = new CircularLayout();
await graphComponent.morphLayout(layout);

// With configuration
const layout = new CircularLayout({
    layoutStyle: CircularLayoutStyle.SINGLE_CYCLE,
    minimumNodeDistance: 50
});

await graphComponent.morphLayout(layout);
What are the layout styles?
const layout = new CircularLayout({
    // Single circle
    layoutStyle: CircularLayoutStyle.SINGLE_CYCLE,
    
    // Or multiple concentric circles
    // layoutStyle: CircularLayoutStyle.BCC_COMPACT,
    
    // Minimum distance between nodes
    minimumNodeDistance: 40,
    
    // Partition style
    partitionStyle: PartitionStyle.CYCLE
});
Can you show an example?
// Create a circular process
const graph = graphComponent.graph;

const steps = ['Plan', 'Design', 'Develop', 'Test', 'Deploy', 'Monitor'];
const nodes = [];

for (const step of steps) {
    const node = graph.createNode();
    graph.addLabel(node, step);
    nodes.push(node);
}

// Create circular connections
for (let i = 0; i < nodes.length; i++) {
    const source = nodes[i];
    const target = nodes[(i + 1) % nodes.length];
    graph.createEdge(source, target);
}

// Apply circular layout
const layout = new CircularLayout({
    layoutStyle: CircularLayoutStyle.SINGLE_CYCLE,
    minimumNodeDistance: 80
});

await graphComponent.morphLayout(layout);
graphComponent.fitGraphBounds(new Insets(50));
