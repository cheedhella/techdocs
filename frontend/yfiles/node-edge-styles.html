What are NodeStyle and EdgeStyle?
NodeStyle and EdgeStyle are the fundamental styling interfaces in yFiles that control the visual appearance of nodes and edges. They determine:
  • Shape and geometry
  • Colors (fill and stroke)
  • Size and dimensions
  • Visual effects (shadows, gradients)
  • Custom rendering logic
How do you set default styles?
const graph = graphComponent.graph;

// Set default node style
graph.nodeDefaults.style = new ShapeNodeStyle({
    fill: 'lightblue',
    stroke: '2px darkblue',
    shape: 'round-rectangle'
});

// Set default edge style
graph.edgeDefaults.style = new PolylineEdgeStyle({
    stroke: '2px gray',
    targetArrow: IArrow.DEFAULT
});

// Set default label style
graph.nodeDefaults.labels.style = new DefaultLabelStyle({
    font: '14px Arial',
    textFill: 'black'
});
How do you apply styles to individual elements?
const graph = graphComponent.graph;

// Create node with custom style
const node = graph.createNode({
    style: new ShapeNodeStyle({
        fill: 'lightgreen',
        stroke: '3px darkgreen',
        shape: 'ellipse'
    })
});

// Change style of existing node
graph.setStyle(node, new ShapeNodeStyle({
    fill: 'orange',
    stroke: '2px red'
}));

// Create edge with custom style
const edge = graph.createEdge({
    source: node1,
    target: node2,
    style: new PolylineEdgeStyle({
        stroke: '3px blue',
        targetArrow: IArrow.TRIANGLE
    })
});
What are the built-in node styles?
yFiles provides several built-in node styles:
  • ShapeNodeStyle: Basic shapes (rectangle, ellipse, etc.)
  • RectangleNodeStyle: Simple rectangles with rounded corners
  • ImageNodeStyle: Nodes with images
  • GroupNodeStyle: Special style for group nodes
  • BevelNodeStyle: 3D beveled appearance
  • ShinyPlateNodeStyle: Glossy, shiny appearance
What are the built-in edge styles?
Common edge styles include:
  • PolylineEdgeStyle: Standard straight/bent edges
  • ArcEdgeStyle: Curved edges
  • BezierEdgeStyle: Smooth Bezier curves
  • BridgeEdgeStyle: Edges with bridges at crossings
How do you use conditional styling?
// Apply different styles based on node data
graph.nodes.forEach(node => {
    if (node.tag?.type === 'important') {
        graph.setStyle(node, new ShapeNodeStyle({
            fill: 'red',
            stroke: '3px darkred',
            shape: 'diamond'
        }));
    } else if (node.tag?.type === 'process') {
        graph.setStyle(node, new ShapeNodeStyle({
            fill: 'lightblue',
            stroke: '2px darkblue',
            shape: 'round-rectangle'
        }));
    } else {
        graph.setStyle(node, new ShapeNodeStyle({
            fill: 'lightgray',
            stroke: '1px gray',
            shape: 'ellipse'
        }));
    }
});

// Conditional edge styling
graph.edges.forEach(edge => {
    const weight = edge.tag?.weight || 1;
    graph.setStyle(edge, new PolylineEdgeStyle({
        stroke: `${weight}px gray`,
        targetArrow: weight > 3 ? IArrow.TRIANGLE : IArrow.DEFAULT
    }));
});
