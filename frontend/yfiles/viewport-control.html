What is Viewport Control?
Viewport Control manages the visible area of the graph, including zoom level, pan position, and what portion of the graph is currently displayed.
How do you control the viewport?
// Set zoom level
graphComponent.zoom = 1.5;

// Zoom in/out
graphComponent.zoomIn();
graphComponent.zoomOut();

// Zoom to specific level with animation
graphComponent.zoomTo(2.0);
graphComponent.zoomToAnimated(2.0);

// Fit graph to view
graphComponent.fitGraphBounds();
graphComponent.fitGraphBounds(new Insets(20));

// Fit with animation
graphComponent.fitGraphBounds(new Insets(20), true);

// Center on specific point
graphComponent.viewPoint = new Point(100, 100);

// Zoom to specific rectangle
graphComponent.zoomToAnimated(new Rect(0, 0, 500, 500));

// Set zoom limits
graphComponent.minimumZoom = 0.1;
graphComponent.maximumZoom = 10;

// Get current viewport
const viewport = graphComponent.viewport;
console.log(`Viewport: ${viewport.width} x ${viewport.height}`);
