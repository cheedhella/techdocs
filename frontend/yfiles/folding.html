What is Folding?
Folding allows users to expand and collapse group nodes, hiding or showing their contents. This is essential for managing large, hierarchical graphs.
How do you enable folding?
// Enable folding on the graph
const foldingManager = new FoldingManager();
const foldingView = foldingManager.createFoldingView();
const graph = foldingView.graph;

// Use the folding graph with GraphComponent
graphComponent.graph = graph;

// Collapse a group
foldingView.collapse(groupNode);

// Expand a group
foldingView.expand(groupNode);

// Check if collapsed
if (foldingView.isCollapsed(groupNode)) {
    console.log('Group is collapsed');
}
