What is OrganicLayout?
OrganicLayout is a force-directed layout algorithm that creates natural-looking, organic arrangements of graphs. It's ideal for:
  • Social networks
  • Network topology diagrams
  • Relationship graphs
  • Biological networks
  • Any graph without strict hierarchical structure
The algorithm treats nodes as physical objects with repulsive forces and edges as springs, creating balanced, aesthetically pleasing layouts.
How do you apply OrganicLayout?
// Create and apply layout
const layout = new OrganicLayout();
await graphComponent.morphLayout(layout);

// With configuration
const layout = new OrganicLayout({
    minimumNodeDistance: 50,
    preferredEdgeLength: 100,
    deterministic: true
});

await graphComponent.morphLayout(layout, '1s');
What are the key configuration options?
const layout = new OrganicLayout({
    // Minimum distance between nodes
    minimumNodeDistance: 40,
    
    // Preferred edge length
    preferredEdgeLength: 80,
    
    // Scope: entire graph or selection
    scope: OrganicLayoutScope.ALL,
    
    // Quality vs speed tradeoff
    qualityTimeRatio: 0.6,  // 0 = fast, 1 = high quality
    
    // Deterministic results
    deterministic: true,
    
    // Compact layout
    compactnessFactor: 0.5,  // 0 = loose, 1 = compact
    
    // Consider node sizes
    considerNodeSizes: true,
    
    // Avoid node overlaps
    nodeOverlapsAllowed: false
});
How do you handle groups in OrganicLayout?
const layout = new OrganicLayout({
    // Enable group layout
    groupNodeCompactness: 0.8
});

const layoutData = new OrganicLayoutData();

// Define group behavior
layoutData.groupNodeModes.mapper = node => {
    if (graph.isGroupNode(node)) {
        return GroupNodeMode.FIX_BOUNDS;
    }
    return null;
};

await graphComponent.morphLayout(layout, layoutData);
Can you show a practical example?
// Create a social network graph
const graph = graphComponent.graph;

// Create people nodes
const people = [];
for (let i = 0; i < 10; i++) {
    const node = graph.createNode();
    graph.addLabel(node, `Person ${i + 1}`);
    people.push(node);
}

// Create random connections
for (let i = 0; i < 15; i++) {
    const source = people[Math.floor(Math.random() * people.length)];
    const target = people[Math.floor(Math.random() * people.length)];
    if (source !== target) {
        graph.createEdge(source, target);
    }
}

// Apply organic layout
const layout = new OrganicLayout({
    minimumNodeDistance: 60,
    preferredEdgeLength: 100,
    qualityTimeRatio: 0.8,
    deterministic: true
});

await graphComponent.morphLayout(layout);
graphComponent.fitGraphBounds(new Insets(20));
