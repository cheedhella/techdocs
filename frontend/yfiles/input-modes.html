What are Input Modes?
Input Modes control how users interact with the graph visualization. They define what happens when users click, drag, hover, or use keyboard shortcuts. yFiles provides several built-in input modes and allows custom implementations.
What are the main input modes?
  • GraphEditorInputMode: Full editing capabilities
  • GraphViewerInputMode: View-only, no editing
  • MoveInputMode: Move nodes and edges
  • CreateEdgeInputMode: Create edges
  • NavigationInputMode: Pan and zoom only
How do you set up different input modes?
// Full editing mode
const editorMode = new GraphEditorInputMode({
    allowCreateNode: true,
    allowCreateEdge: true,
    allowEditLabel: true
});
graphComponent.inputMode = editorMode;

// View-only mode
const viewerMode = new GraphViewerInputMode({
    selectableItems: GraphItemTypes.NONE,
    clickableItems: GraphItemTypes.NODE | GraphItemTypes.EDGE
});
graphComponent.inputMode = viewerMode;

// Navigation only (pan and zoom)
const navMode = new NavigationInputMode();
graphComponent.inputMode = navMode;
How do you customize input mode behavior?
const inputMode = new GraphEditorInputMode();

// Disable specific features
inputMode.allowCreateNode = false;
inputMode.allowDelete = false;

// Configure selection
inputMode.selectableItems = GraphItemTypes.NODE | GraphItemTypes.EDGE;
inputMode.marqueeSelectableItems = GraphItemTypes.NODE;

// Configure click behavior
inputMode.clickableItems = GraphItemTypes.ALL;
inputMode.addItemClickedListener((sender, evt) => {
    console.log('Clicked:', evt.item);
});

// Configure double-click
inputMode.addItemDoubleClickedListener((sender, evt) => {
    if (evt.item instanceof INode) {
        console.log('Double-clicked node');
    }
});

graphComponent.inputMode = inputMode;
