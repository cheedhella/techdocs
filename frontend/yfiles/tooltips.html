How do you add tooltips to graph elements?
Tooltips provide additional information when users hover over graph elements. 
const inputMode = new GraphEditorInputMode();

// Enable tooltips
inputMode.toolTipItems = GraphItemTypes.NODE | GraphItemTypes.EDGE;

// Add tooltip listener
inputMode.addQueryItemToolTipListener((sender, evt) => {
    if (evt.item instanceof INode) {
        const node = evt.item;
        evt.toolTip = `Node: ${node.labels.first()?.text || 'Unnamed'}`;
        evt.handled = true;
    } else if (evt.item instanceof IEdge) {
        const edge = evt.item;
        evt.toolTip = `Edge from ${edge.sourceNode.labels.first()?.text} to ${edge.targetNode.labels.first()?.text}`;
        evt.handled = true;
    }
});

graphComponent.inputMode = inputMode;
How do you create rich HTML tooltips?
inputMode.addQueryItemToolTipListener((sender, evt) => {
    if (evt.item instanceof INode) {
        const node = evt.item;
        const data = node.tag;
        
        // Create HTML tooltip
        evt.toolTip = `
            

                
${data?.name || 'Node'}

                
Type: ${data?.type || 'Unknown'}

                
ID: ${data?.id || 'N/A'}

            

        `;
        evt.handled = true;
    }
});
