What is Cycle Detection?
Cycle Detection identifies circular paths in a graph where you can start at a node and return to it by following edges. This is important for validating dependencies and detecting circular references.
How do you detect cycles?
// Detect cycles in directed graph
const cycleDetector = new CycleEdges();
const result = cycleDetector.run(graph);

if (result.edges.size > 0) {
    console.log(`Found ${result.edges.size} cycle edges`);
    
    // Highlight cycle edges
    result.edges.forEach(edge => {
        graph.setStyle(edge, new PolylineEdgeStyle({
            stroke: '3px red dashed',
            targetArrow: IArrow.TRIANGLE
        }));
    });
} else {
    console.log('Graph is acyclic (no cycles found)');
}

// Check if graph is acyclic
const isAcyclic = result.edges.size === 0;
