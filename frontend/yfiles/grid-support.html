What is Grid Support?
Grid Support displays a visual grid in the background and enables snapping to grid lines, helping create structured, aligned diagrams.
How do you add a grid?
// Create and configure grid
const grid = new GridVisualCreator({
    horizontalSpacing: 50,
    verticalSpacing: 50,
    stroke: '1px lightgray'
});

// Add grid to GraphComponent
graphComponent.backgroundGroup.addChild(
    grid.createVisual(graphComponent.createRenderContext())
);

// Enable grid snapping
const inputMode = new GraphEditorInputMode();
inputMode.snapContext = new GraphSnapContext({
    enabled: true,
    snapToGridEnabled: true,
    gridSpacing: 50
});

graphComponent.inputMode = inputMode;
