What are Decorators?
Decorators in yFiles allow you to add visual enhancements like highlights, selection indicators, and focus visuals to graph elements without modifying their core styles.
How do you use the Highlight Decorator?
// Get highlight manager
const highlightManager = graphComponent.highlightIndicatorManager;

// Add highlight to node
highlightManager.addHighlight(node);

// Remove highlight
highlightManager.removeHighlight(node);

// Clear all highlights
highlightManager.clearHighlights();

// Custom highlight style
highlightManager.nodeStyle = new ShapeNodeStyle({
    stroke: '3px yellow',
    fill: 'transparent'
});
How do you customize selection indicators?
// Customize selection appearance
const selectionManager = graphComponent.selectionIndicatorManager;

// Custom node selection style
selectionManager.nodeStyle = new ShapeNodeStyle({
    stroke: '3px blue',
    fill: 'rgba(0, 0, 255, 0.1)'
});

// Custom edge selection style
selectionManager.edgeStyle = new PolylineEdgeStyle({
    stroke: '4px blue'
});
Can you show a practical example?
// Highlight neighbors when node is selected
graphComponent.selection.addItemSelectionChangedListener((sender, evt) => {
    const item = evt.item;
    const highlightManager = graphComponent.highlightIndicatorManager;
    
    if (item instanceof INode && evt.itemSelected) {
        // Highlight the selected node's neighbors
        const graph = graphComponent.graph;
        graph.neighbors(item).forEach(neighbor => {
            highlightManager.addHighlight(neighbor);
        });
        
        // Highlight connected edges
        graph.edgesAt(item).forEach(edge => {
            highlightManager.addHighlight(edge);
        });
    } else if (!evt.itemSelected) {
        // Clear highlights when deselected
        highlightManager.clearHighlights();
    }
});
