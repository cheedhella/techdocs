What is Filtering?
Filtering allows you to show or hide graph elements based on criteria, without actually removing them from the graph. This is useful for focusing on specific aspects of the data.
How do you implement filtering?
// Create filtered graph
const filteredGraph = new FilteredGraphWrapper(
    graph,
    nodePredicate,
    edgePredicate
);

// Node filter function
function nodePredicate(node) {
    // Show only nodes of specific type
    return node.tag?.type === 'important';
}

// Edge filter function
function edgePredicate(edge) {
    // Show only edges with weight > 3
    return edge.tag?.weight > 3;
}

// Use filtered graph
graphComponent.graph = filteredGraph;

// Update filter
filteredGraph.nodePredicateChanged();
filteredGraph.edgePredicateChanged();
