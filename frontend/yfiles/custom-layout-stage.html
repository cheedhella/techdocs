What is a Custom Layout Stage?
A Custom Layout Stage allows you to modify or extend the layout pipeline by adding custom processing steps before, after, or between existing layout algorithms.
How do you create a custom layout stage?
// Custom layout stage that adds spacing
class CustomSpacingStage extends LayoutStageBase {
    applyLayout(graph) {
        // Apply core layout first
        this.applyLayoutCore(graph);
        
        // Then add custom spacing
        graph.nodes.forEach(node => {
            const layout = node.layout;
            graph.setNodeLayout(node, new Rect(
                layout.x * 1.5,  // Increase horizontal spacing
                layout.y * 1.5,  // Increase vertical spacing
                layout.width,
                layout.height
            ));
        });
    }
}

// Use custom stage with main layout
const mainLayout = new HierarchicLayout();
const customStage = new CustomSpacingStage();
customStage.coreLayout = mainLayout;

await graphComponent.morphLayout(customStage);
