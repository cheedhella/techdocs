1. VS Code Extensions
  • Once you install an extension, you don't need to restart VS Code.
  • You can list all installed extensions by navigating to the Extensions view menu.
  • Any installed extension can be disabled if needed.
2. Recommended Extensions
  1. Rainbow Brackets: Uses rainbow-colored brackets to help you match them easily.
  2. Quokka.js: A live scratchpad for JavaScript that shows output as you type.
  3. Polacode: Helps you create good-looking snapshots of your code.
  4. Advanced New File: Quickly create a new file, inferring the path and extension from the current file.
  5. Live Server: Launch a local development server with live reload feature for static & dynamic pages.
    • Click 'Go Live' on the status bar to toggle the server.
    • Use the Command Palette to 'Open with Live Server' or 'Stop Live Server'.
    • Right-click an HTML file and select 'Open with Live Server'.
  6. Open In Browser: Allows you to open the current file in your default browser.
  7. VSCode-Icons: Adds intuitive icons to your files in the explorer.
  8. Import Cost: Displays the size of an imported package inline.
  9. DotENV: Provides syntax highlighting for .env files.
  10. Better Comments: Improves your code comments by highlighting them based on type.
    • * for important information.
    • ! for deprecated methods.
    • ? for questions.
    • TODO for to-do items.
  11. JavaScript (ES6) code snippets: Provides code snippets for JavaScript, TypeScript, Vue, React, and HTML.
  12. Search node_modules: A simple command for searching the node_modules directory.
  13. Intellisense for CSS class names in HTML: Provides CSS class name completion for the HTML class attribute.
  14. Bookmarks: Helps you mark lines in your code and navigate between them easily.
  15. Markdown All in One: Provides all you need to write Markdown (keyboard shortcuts, table of contents, auto preview, and more).
  16. ES7+ React/Redux/React-Native snippets: Provides code snippets for React, Redux, and React-Native.
