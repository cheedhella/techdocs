1. VS Code Overview
  • Side Panel: Has 5 options: Explorer, Search, Source Control, Run and Debug, Extensions.
    • Cmd + B: Show/Hide Side Panel
    • Cmd + Shift + E: Open Explorer
    • Cmd + Shift + F: Open Find/Search in the workspace
    • Cmd + Shift + X: Open Extensions
  • Mini-map: A helpful overview on the right-hand side for very long files.
  • Title Bar: By default, it shows the file name and the project it belongs to.
  • File Explorer: For working with files.
    • Single-click a file to open it temporarily (soft open).
    • Double-click a file to open it permanently.
    • Cmd + P: Quickly open a file by its name.
    • Cmd + W: Close the current file.
  • Workspace: Creates a settings file and allows you to group multiple project folders.

3. Key Features
  • Integrated Terminal: Allows you to run commands from within VS Code.
    • Ctrl + `: Open/Close Integrated Terminal.
    • Cmd + Shift + C: Open in an external terminal.
  • code command: After installation, you can open folders from your command line with code ..
  • Intellisense: Provides smart code completions, parameter info, and quick info for variables and functions.
    • Trigger with Ctrl+Space or by typing ..
    • Works out-of-the-box for JS, TS, JSON, HTML, CSS, etc.
    • Can be extended with language-specific extensions.
4. Emmet Actions via Command Palette

Open the Command Palette (Cmd + Shift + P) and search for these commands:

  • Wrap with Abbreviation: Takes an Emmet abbreviation, expands it, and places the selected content inside the last element of the generated snippet.
  • Wrap Individual Lines with Abbreviation: Wraps each selected line with an abbreviation. For example, select multiple lines and use li* to wrap each one in an `
  • ` tag.
  • Update Tag: Renames an HTML tag. Useful for changing a `` to a `
    ` while keeping its content.
  • Remove Tag: Removes the parent tag, leaving the inner content.
  • Go to Matching Pair: Jumps between an opening and closing tag.
  • Merge Lines: Collapses all selected lines into a single line.
  • Evaluate Math Expression: Select a simple math expression like `10+5` and run this command to replace it with the result `15`.
