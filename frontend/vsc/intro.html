1. What is Visual Studio Code?
  • It is a free, open-source code editor developed by Microsoft;
2. Features of Visual Studio Code?
  • Open Source;
  • Cross Platform - works on all windows/linux/mac etc;
  • Lightweight and Fast;
  • Supports many languages through extensions - HTML, CSS, JavaScript, React, Java, C++, go, python, JSON, XML, YAML etc;
  • IntelliSense - Provides smart code completion, syntax highlighting, and parameter hints based on variable types and function definitions;
  • GIT Integration -> You can do anything using editor such as clone, commit, pull, push;
  • Debugging -> Breakpoints, step through, watches etc;
  • Integrated terminal - You don’t need to switch to another window to run commands;
  • Extensions Marketplace - thousands of extensions are available for languages, themes, frameworks, linters and debuggers;
3. Visual Studio vs Visual Studio Code
  • Visual Studio Code is an editor while Visual Studio is an IDE;
  • Visual Studio Code is cross-platform and fast, while Visual Studio is Windows/Mac only and not fast;
