1. What is Zustand?
  • It is a global state manager, which helps you in sharing data/state b/w multiple components in a React application;
2. How to create a Store?
  • create((setState, getState) => ({ ... })) is used to create a store;
  • It takes 2 callbacks:
  • set(partialState) - Updates state -> can merge or replace parts of it;
  • get() - Returns the current state —> lets you read data inside actions;
3. Accessing the Store
  • const count = useStore((state) => state.count);
  • const getCount = useStore((state) => state.getCount);
  • const count = useStore((state) => state.getCount() );
