3. NodeJS
  • Download & install NodeJS from: https://nodejs.org
  • It also installs npm and npx;
  • npm(node package manager) - It is used to manage shared packages/libraries;
  • npx(node package executor) - It is used to run packages directly without installing them globally;
  • It looks in: your local node_modules/.bin folder; If found, it uses it; If not, Your local node_modules/.bin folder; Eg: npx create-react-app my-app
  • Verify installation: node -v, npm -v, npx -v
4. TypeScript
  • Globally
    • Install: npm install -g typescript
    • Verify: tsc --version
  • Project Specific
    • Do this in your project folder:
    • npm init -y # create a nodejs package, if package.json if missing
    • npm install --save-dev typescript # Adds typescript to your project dependencies
    • Verify: npx tsc --version
    • npx tsc --init # It creates tsconfig.json file with default settings;
    • npx tsc --init --rootdir src --outdir lib # You can specify the location of ts files and location of generated js files;
    • npx tsc --watch # If you make any changes, it recompiles the ts file on the fly;
    • To run generated JS: node lib/index.js
  • By default, VSC comes with Emmet plugin;
5. React
