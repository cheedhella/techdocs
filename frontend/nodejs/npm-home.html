Learning Path

Recommended order for mastering npm:

  1. Getting Started - What is npm, installation, package.json
  2. Installing Packages - Basic install commands, dependencies
  3. Managing Packages - Update, uninstall, audit
  4. Scripts - Automate tasks with npm scripts
  5. Configuration - .npmrc, config commands
  6. Publishing - Share your packages (optional)
  7. Workspaces - Monorepo management
  8. Advanced Topics - Peer dependencies, caching
  9. Security - Best practices, audit
  10. Troubleshooting - Common issues and fixes

Quick Reference

# Install packages
npm install package-name
npm install -D package-name  # devDependency
npm install -g package-name  # global

# Update packages
npm update
npm update package-name

# Remove packages
npm uninstall package-name

# Run scripts
npm run script-name
npm start
npm test
npm run build

# Security
npm audit
npm audit fix

# View packages
npm list
npm outdated

# Clean install
npm ci
