What files does an Angular component have?
  • An Angular component is usually split into multiple files for clarity and maintainability.
  • Typical files: TypeScript class, HTML template, CSS/SCSS styles, and a spec test file.
  • This separation keeps behavior, structure, and presentation organized.
Common component file set
File Purpose
user-card.component.ts Contains component logic, inputs/outputs, and methods.
user-card.component.html Defines the UI markup rendered by the component.
user-card.component.scss Contains styles scoped to this component.
user-card.component.spec.ts Unit tests for component behavior and rendering.
Example component

1) TypeScript:

import { Component, Input } from '@angular/core';

@Component({
  selector: 'app-user-card',
  templateUrl: './user-card.component.html',
  styleUrls: ['./user-card.component.scss']
})
export class UserCardComponent {
  @Input() name = '';
  @Input() role = '';

  get heading(): string {
    return `${this.name} (${this.role})`;
  }
}

2) Template:

<section class="card">
  <h3>{{ heading }}</h3>
  <button type="button">View Profile</button>
</section>

3) Styles:

.card {
  border: 1px solid #d5d5d5;
  border-radius: 8px;
  padding: 12px;
}

4) Basic test:

it('shows user heading', () => {
  component.name = 'Asha';
  component.role = 'Admin';
  fixture.detectChanges();
  expect(fixture.nativeElement.textContent).toContain('Asha (Admin)');
});
