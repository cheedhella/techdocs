What is Angular CLI?
  • Angular CLI is the command-line tool for creating, developing, building, and testing Angular applications.
  • It automates repetitive setup tasks and applies Angular best-practice defaults.
What Angular CLI does?
Command What it does
ng new my-angular-app It creates a new project with default project structure, installs dependencies, configures TypeScript, sets up routing, configures build tools, adds testing setup;
ng generate component my-component | ng g c my-component Component is reusable UI building block; It generates a new component;
ng generate service my-service | ng g s my-service Service is used for Authentication, API calls and shared data;
ng g module my-module It is used for feature separation, lazy loading, and organizing related components, services, and other code into cohesive units;
ng g pipe my-pipe It is used to transform data in templates; Eg: uppercase text, date formatting;
ng g guard my-guard It is used to protect routes and control access based on conditions; Eg: authentication, role-based access;
ng serve It starts the local development server at http://localhost:4200 with these features: fast rebuild, live reloading, auto-refresh on file save, error display in browser;
ng build Builds the app into deployable bundles.
ng build --configuration production Builds an optimized production bundle (minified, tree-shaken, ahead-of-time compilation, deadcode removal, compression optimized etc);
ng test Runs unit tests for the application(components, services, pipes, etc) using the configured test runner; Usually, uses karma or jasmine;
ng e2e Runs end-to-end tests(like open page, click button, test output) when an e2e framework is configured in the workspace;
ng lint Checks code quality and style issues using the configured linter.
ng update Angular CLI helps upgrade Angular safely; It updates Angular packages and applies migration schematics when available.
Summary of Angular CLI commands
  • Creates project
  • Generates UI pieces
  • Adds reusable services
  • Protects routes
  • Runs locally
  • Tests app
  • Builds deployable version
Best practices for Angular CLI usage
  • Use CLI generators to maintain consistency and follow Angular conventions.
  • Leverage build configurations for different environments (dev, staging, prod).
  • Integrate linting and testing into CLI workflows for code quality.
  • Adopt a consistent project structure for scalability and team collaboration.
Angular CLI vs Manual Setup
  • Angular CLI provides a streamlined, consistent approach to project setup and development.
  • Manual setup offers more flexibility but requires more configuration and maintenance.
  • CLI ensures best practices and conventions are followed automatically.
  • Manual setup may be necessary for highly customized or legacy projects.
