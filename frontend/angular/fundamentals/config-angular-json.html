What is angular.json?
  • angular.json is the workspace configuration file used by Angular CLI.
  • It defines projects, build options, serve settings, test options, and named configurations (like development or production).
  • Angular CLI reads this file when running commands such as ng build and ng serve.

angular.json is the Angular workspace configuration file. It tells the Angular CLI how to build, serve, test, lint, and generate code for your project.

Main sections:

$schema: Points to the JSON schema for validation and editor autocomplete.
version: Config format version.
newProjectRoot: Default folder where new projects are created.
projects: The most important section. Contains one or more apps/libraries in the workspace.
Inside each project:

projectType: application or library
root: Project root path
sourceRoot: Source files path, often src
prefix: Default selector prefix for generated components
architect or targets: Defines CLI tasks
Common targets under architect / targets:

build: Build configuration
serve: Dev server configuration
test: Unit test configuration
lint: Lint task
extract-i18n: Translation extraction
Typical build.options fields:

outputPath: Where build files go
index: HTML entry file
main or browser: Main TS entry
polyfills: Polyfills file(s)
tsConfig: TypeScript config file
assets: Static files copied as-is
styles: Global style files
scripts: Global JS files
allowedCommonJsDependencies: Suppress CommonJS warnings for listed packages
Configurations:

Usually under build.configurations and serve.configurations
  Examples: production, development
  Override base options for specific environments
  Can set:
    optimization
    sourceMap
    fileReplacements
    budgets
    outputHashing

How it is used:
  ng serve reads the serve target
  ng build reads the build target
  ng test reads the test target
  ng generate component my-cmp uses project defaults like prefix

Common customizations:
  Add global SCSS/CSS in styles
  Add static files in assets
  Set environment replacements in fileReplacements
  Tune production bundle size in budgets
  Change output folder with outputPath
Important configuration sections
Section What it controls
projects All apps/libraries in the workspace.
architect.build.options Base build settings: output path, index, assets, styles, scripts.
architect.build.configurations Named build profiles such as production and development.
architect.serve Dev server behavior and which build configuration to use.
architect.test Unit test runner options and test-specific assets/styles.
fileReplacements Swaps files per environment (for example, environment.ts).
Example angular.json snippet
{
  "projects": {
    "demo-app": {
      "architect": {
        "build": {
          "options": {
            "outputPath": "dist/demo-app",
            "index": "src/index.html",
            "main": "src/main.ts",
            "assets": ["src/favicon.ico", "src/assets"],
            "styles": ["src/styles.scss"]
          },
          "configurations": {
            "production": {
              "optimization": true,
              "sourceMap": false,
              "fileReplacements": [
                {
                  "replace": "src/environments/environment.ts",
                  "with": "src/environments/environment.prod.ts"
                }
              ]
            },
            "development": {
              "optimization": false,
              "sourceMap": true
            }
          }
        },
        "serve": {
          "configurations": {
            "production": {
              "buildTarget": "demo-app:build:production"
            },
            "development": {
              "buildTarget": "demo-app:build:development"
            }
          },
          "defaultConfiguration": "development"
        }
      }
    }
  }
}
