1. Install Net-SNMP
  • You can install either net-snmp OR libsnmp-dev libraries;
  • MacOS
    • brew install net-snmp
    • sudo dnf install net-snmp-devel net-snmp-utils - Installs Net-SNMP development package(net-snmp-config.h etc)
  • Linux
    • # Debian/Ubuntu sudo apt update sudo apt install libsnmp-dev snmp snmp-mibs-downloader # Fedora / RHEL / CentOS sudo dnf install net-snmp net-snmp-utils net-snmp-devel
  • Verify: snmpget --version # If you see version, then no errors!
  • Test device side: ./snmp_tool 192.168.1.100 public get 1.3.6.1.2.1.1.1.0 # If the device allows SNMP access, you should see something like: SNMPv2-MIB::sysDescr.0 = STRING: Linux router 5.15.0-105-generic
