Data Types
  • Numeric Types 
    | Type           | Use                           |
| -------------- | ----------------------------- |
| TINYINT        | Small integers                |
| SMALLINT       | Medium-small integers         |
| INT            | Normal integers               |
| BIGINT         | Very large integers           |
| FLOAT / DOUBLE | Approximate decimals          |
| DECIMAL(p,s)   | Exact decimals (money values) |


    
p -> stands for Precision, total number of digits(on both sides of the decimal point) in the value;

    
s -> stands for Scale, number of digits after decimal point;

    
Eg:
Height -> decimal (3,2) -> 6.10, 5.80;
Weight -> decimal (5,2) -> 80.40, 190.20;
  • String Types
    | Type       | Use                  |
| ---------- | -------------------- |
| CHAR(n)    | Fixed-length text    |
| VARCHAR(n) | Variable-length text |
| TEXT       | Large text           |
  • Date & Time Types
    | Type      | Use                    |
| --------- | ---------------------- |
| DATE      | Date only              |
| TIME      | Time only              |
| DATETIME  | Date + time            |
| TIMESTAMP | Auto-tracked timestamp |
| YEAR      | Year only              |
  • Binary Types - useful for files/images/raw data;
    | Type      | Use               |
| --------- | ----------------- |
| BINARY    | Fixed binary      |
| VARBINARY | Variable binary   |
| BLOB      | Large binary data |
  • Binary Type
    | Type      | Use               |
| --------- | ----------------- |
| BOOLEAN   | Stores TRUE/FALSE values |
  • Enum Type one value; Eg: status ENUM('pending','approved');
  • Set Type multiple values; Eg: roles SET('admin','editor');
  • Best Practices:
    • INT → normal numbers
    • VARCHAR → most text fields
    • DECIMAL → money
    • TIMESTAMP → created/updated time
    • TEXT → large text such as JSON data etc;
    • BLOB → raw binary data such as audio, video, images, PDFs etc;
  • | TEXT Types | Max Size |
