NULL value
  • NULL means No value / unknown / missing data;
  • It is different from: 0, empty string, false;
  • Checking for NULL: IS NULL, IS NOT NULL;
  • NOT NULL constraint -> Prevents NULL values; These columns must contain a value;
  • DEFAULT -> If no value is specified, it defaults to specified value; Eg: status VARCHAR(20) DEFAULT 'active';
  • SELECT IFNULL(phone, 'No Number') FROM users; -> Replace NULL with another value;
