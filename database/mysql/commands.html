Data Definition Language (DDL)

Commands used to define, modify, or drop the structure of database objects like tables and indexes.

CommandDescription
CREATECreates a new database, table, index, or view.
ALTERModifies an existing database object (e.g., adding a column).
DROPDeletes a database, table, index, or view permanently.
TRUNCATERemoves all records from a table and resets auto-increment values.
RENAMERenames a table or database object.
Data Manipulation Language (DML)

Commands used for managing and manipulating data within existing tables.

CommandDescription
SELECTRetrieves data from one or more tables.
INSERTAdds new rows of data into a table.
UPDATEModifies existing data within a table.
DELETERemoves specific rows from a table.
REPLACEInserts a row, or deletes and re-inserts if a duplicate key exists.
Data Control Language (DCL)

Commands used to control access and permissions for database users.

CommandDescription
GRANTGives specific privileges/permissions to a user or role.
REVOKEWithdraws previously granted privileges from a user or role.
Transaction Control Language (TCL)

Commands used to manage transactions and ensure data integrity.

CommandDescription
COMMITSaves all changes made during the current transaction permanently.
ROLLBACKUndoes all changes made since the last commit or savepoint.
SAVEPOINTSets a point within a transaction to which you can later roll back.
SET TRANSACTIONConfigures the isolation level or read/write mode for transactions.
Administrative & Utility Commands

General commands for database inspection and session management.

CommandDescription
DESCRIBEDisplays the structure of a specific table (columns, types, keys).
SHOWLists various metadata (e.g., SHOW TABLES, SHOW DATABASES).
USESelects the default database for subsequent queries.
EXPLAINProvides information about how MySQL executes a specific query.
SETAssigns a value to a system or user-defined variable.
STATUSDisplays current server status and connection information.

Basic Example Usage

Common Workflow
-- Create a table (DDL)
CREATE TABLE logs (id INT PRIMARY KEY, msg TEXT);

-- Insert data (DML)
INSERT INTO logs VALUES (1, 'System Started');

-- View data (DML)
SELECT * FROM logs;

-- View structure (Utility)
DESCRIBE logs;
