SQL Development
  • Write, run and save SQL scripts in the SQL Editor;
  • Execute selected statements or full scripts depending on the task;
  • View query results in grid mode and export if needed;
  • Use SQL snippets panel for frequently used statements;
Helpful workflow
  • Start with a SELECT preview before UPDATE or DELETE operations;
  • Use transactions for risky changes and commit only after validation;
  • Keep reusable scripts in version control;
  • Prefer parameterized and deterministic scripts for repeatability;
