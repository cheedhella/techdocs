Connection Management
  • Create separate saved connections for development, staging and production;
  • Use clear connection names like local-dev, stage-readonly and prod-admin;
  • Enable SSL for remote and production servers;
  • Set color tags so risky environments are visually obvious;
Managing multiple databases safely
  • Open separate SQL editor tabs for each connection;
  • Confirm active connection and default schema before executing write queries;
  • Use read-only users for analysis and reporting tasks;
  • Store credentials with Workbench vault integration where possible;
