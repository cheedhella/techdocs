User and Privilege Management
  • Create user accounts with host-level restrictions;
  • Grant or revoke privileges at global, database, table or routine level;
  • Use role-based access for simpler permission governance;
  • Audit effective grants to ensure least-privilege access;
Security best practices
  • Use dedicated users for applications, humans and automation;
  • Avoid granting SUPER-like broad permissions unnecessarily;
  • Rotate passwords and enforce stronger authentication methods;
  • Review grants periodically, especially in production;
