Server Health Checks
  • Monitor current connections, threads and transaction activity;
  • Inspect memory, I/O and buffer behavior for bottlenecks;
  • Review locks and waiting sessions during incidents;
  • Check InnoDB status indicators for stability signals;
What to watch regularly
  • Sudden growth in active sessions or long-running statements;
  • Repeated deadlocks and lock wait spikes;
  • Error-log patterns that indicate configuration stress;
  • Resource saturation trends before peak usage windows;
