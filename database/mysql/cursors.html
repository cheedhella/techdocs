What is a Cursor?
  • It is a database object, which is used for iterating the result of a SELECT query;
  • Note: Cursors are Read-only, Forward-only, Non-scrollable;
Purpose of Cursors?
  • Generally, we use cursor inside a stored procedure, trigger, function to process the individual rows returned by SELECT query;
  • It can used for migrating data with custom logic;
How to use a Cursor?
  • There are 4 steps in the lifecycle of a Cursor: DECLARE, OPEN, FETCH, CLOSE;
  • 
# Syntax 
DECLARE cursor_name CURSOR FOR
SELECT column1, column2 FROM table_name;

OPEN cursor_name;

FETCH cursor_name INTO variable1, variable2;

CLOSE cursor_name;
                
  • 
# Example 
# Employee table 
| id | name  | salary |
| -- | ----- | ------ |
| 1  | Ravi  | 30000  |
| 2  | Priya | 40000  |
| 3  | Arun  | 50000  |

# Increase Salary
DELIMITER $$

CREATE PROCEDURE increase_salary()
BEGIN

    -- Variable declarations
    DECLARE done INT DEFAULT FALSE;
    DECLARE emp_id INT;
    DECLARE emp_name VARCHAR(100);
    DECLARE emp_salary DECIMAL(10,2);

    -- Declare cursor
    DECLARE emp_cursor CURSOR FOR
        SELECT id, name, salary FROM employees;

    -- Handler for end of rows
    DECLARE CONTINUE HANDLER FOR NOT FOUND
        SET done = TRUE;

    -- Open cursor
    OPEN emp_cursor;

    read_loop: LOOP

        -- Fetch row into variables
        FETCH emp_cursor INTO emp_id, emp_name, emp_salary;

        -- Exit loop when no more rows
        IF done THEN
            LEAVE read_loop;
        END IF;

        -- Increase salary by 10%
        SET emp_salary = emp_salary * 1.10;

        -- Display result
        SELECT emp_id, emp_name, emp_salary;

    END LOOP;

    -- Close cursor
    CLOSE emp_cursor;

END$$

DELIMITER ;



# Output:
| emp_id | emp_name | updated_salary |
| ------ | -------- | -------------- |
| 1      | Ravi     | 33000          |
| 2      | Priya    | 44000          |
| 3      | Arun     | 55000          |
When to use Cursors?
  • Avoid cursors when a simple UPDATE does the work, as cursor is slower than a normal SQL query and consume more memory;
  • Use cursor only when there is complex row by row processing is required, processing of each row depends on previous row;
