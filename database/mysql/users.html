User
  • In MySQL, user is uniquely identified by: 'username'@'host'
  • MySQL uses host part for security and access control;
  • Same username can have different permisssions depending on where the connection comes from;
  • CREATE USER 'username'@'host' IDENTIFIED BY 'password';
  • When a connection request comes, MySQL tries to find the best matching host;
  • Host matching priority: Exact host match, specific wildcard patterns, % wildcard;
