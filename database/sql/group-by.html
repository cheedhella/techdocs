Grouping Data

What is the GROUP BY Clause?

  • The GROUP BY statement groups rows that have the same values into summary rows.
  • It is often used with aggregate functions (COUNT(), MAX(), MIN(), SUM(), AVG()) to group the result-set by one or more columns.
  • Any column in the SELECT list that is not part of an aggregate function must be included in the GROUP BY clause.

Basic GROUP BY Example
-- Find the number of customers in each country
SELECT COUNT(CustomerID), Country
FROM Customers
GROUP BY Country;

-- Calculate total sales per category
SELECT CategoryID, SUM(Price) as TotalRevenue
FROM Products
GROUP BY CategoryID;

What is the HAVING Clause?

  • The HAVING clause was added to SQL because the WHERE keyword cannot be used with aggregate functions.
  • WHERE filters individual rows before grouping occurs.
  • HAVING filters groups after the GROUP BY clause has been applied.

GROUP BY with HAVING
-- Find countries with more than 5 customers
SELECT COUNT(CustomerID), Country
FROM Customers
GROUP BY Country
HAVING COUNT(CustomerID) > 5;

-- Find categories with average price higher than $50
SELECT CategoryID, AVG(Price)
FROM Products
GROUP BY CategoryID
HAVING AVG(Price) > 50;

Understanding Aggregation Logic

  • Phase 1 (FROM/WHERE): The engine identifies the source tables and filters raw rows.
  • Phase 2 (GROUP BY): The remaining rows are organized into "buckets" based on the grouping columns.
  • Phase 3 (Aggregation): The aggregate functions (SUM, COUNT, etc.) are calculated for each individual bucket.
  • Phase 4 (HAVING): The engine discards buckets that do not meet the group-level criteria.

Complex Grouping Example
-- Order of operations: FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY
SELECT CategoryID, COUNT(*) as ProductCount
FROM Products
WHERE SupplierID != 1
GROUP BY CategoryID
HAVING COUNT(*) > 2
ORDER BY ProductCount DESC;
