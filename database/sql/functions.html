Functions in MySQL

What are Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)?

  • Aggregate functions perform a calculation on a set of values and return a single value.
  • COUNT(): Returns the number of rows.
  • SUM(): Returns the total sum of a numeric column.
  • AVG(): Returns the average value of a numeric column.
  • MIN() / MAX(): Returns the smallest and largest value.

Aggregate Functions Examples
-- Count total orders
SELECT COUNT(order_id) FROM orders;

-- Get total revenue and average price
SELECT SUM(total_amount), AVG(total_amount) FROM orders;

-- Find the cheapest and most expensive product
SELECT MIN(price), MAX(price) FROM products;

Common String Functions

  • CONCAT(str1, str2): Joins two or more strings together.
  • UPPER() / LOWER(): Converts text to uppercase or lowercase.
  • LENGTH(): Returns the length of a string in bytes.
  • SUBSTRING(str, start, len): Extracts a portion of a string.

String Manipulation Examples
-- Combine first and last name
SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM users;

-- Format email to lowercase
SELECT LOWER(email) FROM employees;

-- Get first 3 characters of a product code
SELECT SUBSTRING(product_code, 1, 3) FROM inventory;

Common Numeric Functions

  • ABS(): Returns the absolute (positive) value of a number.
  • ROUND(val, decimals): Rounds a number to a specified number of decimal places.
  • CEIL() / FLOOR(): Rounds a number up or down to the nearest integer.

Numeric Calculation Examples
-- Round tax calculations to 2 decimals
SELECT ROUND(price * 0.15, 2) FROM invoices;

-- Always round up to the next whole dollar
SELECT CEIL(shipping_fee) FROM orders;

Common Date & Time Functions

  • NOW(): Returns the current date and time.
  • CURDATE(): Returns the current date only.
  • DATEDIFF(d1, d2): Returns the number of days between two dates.
  • DATE_FORMAT(): Formats a date as specified.

Date & Time Examples
-- Find how many days ago an order was placed
SELECT DATEDIFF(NOW(), order_date) AS days_since_order FROM orders;

-- Format date as 'Month Day, Year'
SELECT DATE_FORMAT(created_at, '%M %d, %Y') FROM users;
