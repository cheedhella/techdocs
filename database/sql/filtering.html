Filtering & Searching Data

What are Logical Operators (AND, OR, NOT)?

  • Used to combine multiple conditions in a WHERE clause.
  • AND: Returns true if all conditions are true.
  • OR: Returns true if at least one condition is true.
  • NOT: Reverses the result of a condition.

Logical Operators Example
SELECT * FROM products 
WHERE category = 'Electronics' AND price < 500;

SELECT * FROM users 
WHERE city = 'London' OR city = 'Paris';

SELECT * FROM orders 
WHERE NOT status = 'Cancelled';

How do IN and BETWEEN work?

  • IN: Checks if a value matches any value in a list or subquery.
  • BETWEEN: Filters values within a inclusive range (numbers, text, or dates).

IN & BETWEEN Example
-- Using IN for multiple values
SELECT * FROM offices 
WHERE country IN ('USA', 'UK', 'Japan');

-- Using BETWEEN for a range
SELECT * FROM products 
WHERE price BETWEEN 10 AND 50;

How to use LIKE and Wildcards?

  • Used for pattern matching in string columns.
  • % (Percent): Represents zero, one, or multiple characters.
  • _ (Underscore): Represents a single character.

Pattern Matching Examples
-- Finds any values that start with 'a'
SELECT * FROM customers WHERE name LIKE 'a%';

-- Finds any values that have 'or' in any position
SELECT * FROM customers WHERE name LIKE '%or%';

-- Finds any values that have 'r' in the second position
SELECT * FROM customers WHERE name LIKE '_r%';

How to check for NULL values?

  • You cannot use = NULL because NULL represents an unknown value.
  • Use IS NULL to find empty fields and IS NOT NULL to find fields with data.

NULL Comparison
SELECT * FROM employees 
WHERE reports_to IS NULL;

SELECT * FROM customers 
WHERE email IS NOT NULL;

What about Regular Expressions?

  • Regular expressions provide more powerful search patterns than LIKE.
  • In MySQL, the REGEXP or RLIKE operator is used.

REGEXP Examples
-- Find names starting with A, B, or C
SELECT * FROM products WHERE name REGEXP '^[ABC]';

-- Find names ending with 'shop'
SELECT * FROM vendors WHERE name REGEXP 'shop$';

-- Find names containing exactly 5 characters
SELECT * FROM categories WHERE name REGEXP '^.{5}$';
