The DELETE Statement

What is DELETE?

  • The DELETE statement is used to remove existing records (rows) from a table.
  • Similar to UPDATE, the WHERE clause is essential to specify which records to delete. Without it, all records will be deleted.


-- Delete a single record
DELETE FROM Customers WHERE CustomerID = 1;

-- Delete all records from a table (similar to TRUNCATE but logs individual row deletions)
DELETE FROM Customers;
