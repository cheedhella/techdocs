The ORDER BY Clause

What is ORDER BY?

  • The ORDER BY keyword is used to sort the result-set of a query.
  • It sorts records in ascending order by default.
  • To sort in descending order, use the DESC keyword.


-- Order by CustomerName in ascending order
SELECT * FROM Customers ORDER BY CustomerName;

-- Order by Country in ascending, then CustomerName in descending order
SELECT * FROM Customers ORDER BY Country ASC, CustomerName DESC;
