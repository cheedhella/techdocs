SQL Joins Explained

What is an INNER JOIN?

  • The INNER JOIN keyword selects records that have matching values in both tables.
  • It is the most common type of join and effectively finds the intersection of two tables.
  • If a row exists in one table but has no matching ID in the other, it will be excluded from the results.

INNER JOIN Example
SELECT Orders.OrderID, Customers.CustomerName
FROM Orders
INNER JOIN Customers ON Orders.CustomerID = Customers.CustomerID;

What are LEFT and RIGHT JOINs?

  • LEFT JOIN: Returns all records from the left table, and matched records from the right. If no match, right-side columns contain NULL.
  • RIGHT JOIN: Returns all records from the right table, and matched records from the left. If no match, left-side columns contain NULL.

Outer Join Examples
-- All customers and any orders they might have (Left Join)
SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID;

-- All orders and the customer details for each order (Right Join)
SELECT Orders.OrderID, Customers.CustomerName
FROM Orders
RIGHT JOIN Customers ON Orders.CustomerID = Customers.CustomerID;

What is the FULL OUTER JOIN concept?

  • Returns all records when there is a match in either the left or the right table.
  • Note: MySQL does not support FULL JOIN directly. You can emulate it using a UNION of a LEFT JOIN and a RIGHT JOIN.

Emulating FULL JOIN in MySQL
SELECT * FROM t1 LEFT JOIN t2 ON t1.id = t2.id
UNION
SELECT * FROM t1 RIGHT JOIN t2 ON t1.id = t2.id;

What are SELF and CROSS JOINs?

  • SELF JOIN: A regular join where a table is joined with itself. This is useful for hierarchical data like employee/manager relationships.
  • CROSS JOIN: Returns the Cartesian product of the two tables (every row from table A paired with every row from table B).

Self & Cross Join Examples
-- SELF JOIN: Finding managers
SELECT e1.name AS Employee, e2.name AS Manager
FROM employees e1
INNER JOIN employees e2 ON e1.manager_id = e2.employee_id;

-- CROSS JOIN: Generating all combinations
SELECT * FROM Products
CROSS JOIN Colors;

How do Multi-table joins work?

  • You can join three or more tables by simply adding more JOIN clauses.
  • The database engine processes these sequentially to build the final result set.

Multi-table Join Example
SELECT Orders.OrderID, Customers.CustomerName, Shippers.ShipperName
FROM Orders
INNER JOIN Customers ON Orders.CustomerID = Customers.CustomerID
INNER JOIN Shippers ON Orders.ShipperID = Shippers.ShipperID;
