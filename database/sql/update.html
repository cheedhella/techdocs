The UPDATE Statement

What is UPDATE?

  • The UPDATE statement is used to modify existing records in a table.
  • It is crucial to use the WHERE clause with UPDATE to specify which records should be updated. Omitting WHERE will update ALL records.


-- Update a single record
UPDATE Customers SET ContactName = 'Alfred Schmidt', City = 'Frankfurt' WHERE CustomerID = 1;

-- Update multiple records (e.g., all customers in a specific country)
UPDATE Customers SET PostalCode = '00000' WHERE Country = 'Germany';
