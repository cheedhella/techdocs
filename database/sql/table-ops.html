What is CREATE TABLE?

  • The CREATE TABLE statement is used to create a new table in a database.
  • You must specify column names and their associated data types.
  • Constraints (like PRIMARY KEY or NOT NULL) are often defined during this step.

Create Table Example
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

What is ALTER TABLE?

  • The ALTER TABLE statement is used to add, delete, or modify columns in an existing table.
  • It can also be used to add or drop various constraints.

Modifying Table Structure
-- Add a new column
ALTER TABLE users ADD phone_number VARCHAR(15);

-- Modify an existing column data type
ALTER TABLE users MODIFY COLUMN username VARCHAR(100);

-- Drop a column
ALTER TABLE users DROP COLUMN email;

What is DROP TABLE vs TRUNCATE TABLE?

  • DROP TABLE: Deletes the table definition and all its data. The table no longer exists.
  • TRUNCATE TABLE: Deletes all data inside the table, but keeps the table structure for future use. It is faster than DELETE FROM because it doesn't log individual row deletions.

Table Deletion Operations
-- Deletes all data but keeps the table
TRUNCATE TABLE users;

-- Deletes the entire table structure
DROP TABLE users;

How to Rename Tables and Columns?

  • Renaming helps maintain clarity as the database schema evolves.
  • Syntax can vary slightly between MySQL, PostgreSQL, and SQL Server.

Renaming Examples (MySQL)
-- Rename a table
RENAME TABLE users TO app_users;

-- Rename a column (MySQL 8.0+)
ALTER TABLE app_users RENAME COLUMN username TO full_name;
