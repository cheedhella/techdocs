What is CREATE DATABASE?

  • The CREATE DATABASE statement is used to create a new SQL database.
  • It initializes the storage structure where tables, views, and other objects will reside.
  • In most systems, you must have administrative privileges to execute this command.

Creating a New Database
CREATE DATABASE shop_db;

What is DROP DATABASE?

  • The DROP DATABASE statement is used to delete an existing SQL database.
  • Warning: Dropping a database will result in the loss of all tables and data stored within it.
  • It is a permanent action and cannot be undone easily without a backup.

Deleting a Database
-- This removes the database and everything inside it
DROP DATABASE shop_db;

-- Safer way to drop
DROP DATABASE IF EXISTS shop_db;
