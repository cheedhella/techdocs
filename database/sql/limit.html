The LIMIT Clause

What is LIMIT?

  • The LIMIT clause is used to restrict the number of records returned by a query.
  • It is very useful for pagination or when you only need a subset of the data.
  • Syntax can vary slightly (e.g., TOP in SQL Server, FETCH FIRST in others).


-- Select the first 5 customers
SELECT * FROM Customers LIMIT 5;

-- Select 10 customers starting from the 6th record (offset 5)
SELECT * FROM Customers LIMIT 5, 10; -- (offset, count)
