The INSERT INTO Statement

What is INSERT INTO?

  • The INSERT INTO statement is used to add new records (rows) to an existing table in a database.
  • You can insert data into all columns or specific columns.


-- Insert into all columns (values must be in the order of columns in the table)
INSERT INTO Customers (CustomerID, CustomerName, ContactName, Address, City, PostalCode, Country)
VALUES (1, 'Cardinal', 'Tom B. Erichsen', 'Skagen 21', 'Stavanger', '4006', 'Norway');

-- Insert into specific columns
INSERT INTO Customers (CustomerName, City, Country)
VALUES ('Alfreds Futterkiste', 'Berlin', 'Germany');
