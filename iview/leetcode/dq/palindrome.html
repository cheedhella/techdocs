1. What is Palindrome?
  • Palidrome is a string which reads the same forward and backward; Eg: racecar, madam;
2. Given a string, check if it is a palindrome or not? How to check if a string is a palindrome
  • Take a Deque, dq;
  • For each character in the string, add it to the end of the deque;
  • Compare the characters from the front and the back of the deque;
  • If the characters are not the same, return false;
  • If the characters are the same, remove the front and the back characters from the deque;
  • If the deque is empty, return true;
  • If the deque is not empty, return false;
  • Time Complexity: O(n); we are iterating through the string once and comparing the characters from the front and the back of the deque.
  • Space Complexity: O(n); we are using a deque to store the characters of the string.
Palindrome Check with ArrayDeque

import java.util.ArrayDeque;
import java.util.Deque;

public class PalindromeChecker {
    public static void main(String[] args) {
        String str = "racecar";
        System.out.println(isPalindrome(str));
    }

    static boolean isPalindrome(String str) {
        Deque deque = new ArrayDeque<>();

        // Add all characters
        for (char ch : str.toCharArray()) {
            deque.addLast(ch);
        }

        // Compare from both ends
        while (deque.size() > 1) {
            if (deque.removeFirst() != deque.removeLast()) {
                return false;
            }
        }
        return true;
    }
}
