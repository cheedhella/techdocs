Problem statement
  • You are given an array of coins and a target amount.
  • You need to find the minimum number of coins that can be used to make the target amount.
  • You can use each coin multiple times.
  • You can use any number of coins to make the target amount.
Coins = {1, 2, 5} Amount = 11 Possible ways: 5 + 5 + 1 = 3 coins ✅ (best) 2 + 2 + 2 + 2 + 2 + 1 = 6 coins ❌ 👉 Answer = 3 coins dp[i] = minimum coins needed to make amount i dp[i] = min(dp[i], dp[i - coin] + 1) # dp[i - coin] → best way to make remaining amount +1 → for the current coin 👉 “I used one coin, now I rely on a smaller solved problem.” Algorithm: Step 1: Initialize dp array with infinity dp = [0, ∞, ∞, ∞, ∞, ∞, ∞, ∞, ∞, ∞, ∞, ∞] //dp[0] = 0 (0 coins needed for amount 0) //Everything else = infinity (we don’t know yet) Step 2: For each coin, update the dp array for coin in coins: for i in range(coin, amount + 1): dp[i] = min(dp[i], dp[i - coin] + 1) Step 3: Return the last element of the dp array ------------------------------------------------ Algorithm MinCoins(coins, amount): 1. Create array dp[0 … amount] 2. For i = 0 to amount: dp[i] = ∞ 3. dp[0] = 0 4. for coin in coins: for i in range(coin, amount + 1): dp[i] = min(dp[i], dp[i - coin] + 1) For i = 1 to amount: For each coin in coins: If i >= coin: dp[i] = min(dp[i], dp[i - coin] + 1) 5. If dp[amount] == ∞: return -1 Else: return dp[amount] ------------------------------------------------ We still use Dynamic Programming, but: 👉 We must avoid reusing the same coin So we iterate backwards (this is the key trick!) Algorithm MinCoins_Once(coins, amount): 1. Create dp[0…amount] 2. Fill with ∞ 3. dp[0] = 0 4. For each coin in coins: For i = amount down to coin: dp[i] = min(dp[i], dp[i - coin] + 1) 5. If dp[amount] == ∞: return -1 Else: return dp[amount] ------------------------------------------------ Forward loop → reuse allowed Backward loop → reuse NOT allowed public int coinChangeSpaceOptimized(int[] coins, int amount) { int[] dp = new int[amount + 1]; Arrays.fill(dp, Integer.MAX_VALUE); dp[0] = 0; for (int coinIndex = 0; coinIndex < coins.length; coinIndex++) { if (coins[coinIndex] <= amount) { dp[coins[coinIndex]] = 1; } } for (int i = 1; i <= amount; i++) { for (int j = 0; j < coins.length; j++) { if (coins[j] <= i && dp[i - coins[j]] != Integer.MAX_VALUE) { dp[i] = Math.min(dp[i], dp[i - coins[j]] + 1); } } } return dp[amount] == Integer.MAX_VALUE ? -1 : dp[amount]; }
