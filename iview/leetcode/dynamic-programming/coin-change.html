Coin Change Problem (#322)

Problem: You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1.

Algorithm: Dynamic Programming (Bottom-Up)

  • We use an array dp of size amount + 1, where dp[i] stores the minimum coins needed for amount i.
  • Initialize dp[0] = 0 and all other values to amount + 1 (a value larger than any possible solution).
  • For each amount from 1 to amount:
    • Iterate through each coin. If coin <= currentAmount, then:
    • dp[currentAmount] = min(dp[currentAmount], 1 + dp[currentAmount - coin])
  • The final answer is dp[amount], unless it's still amount + 1, in which case return -1.

Complexity:

  • Time Complexity: O(amount * n) where n is the number of coins.
  • Space Complexity: O(amount) for the DP table.

Coin Change (Java)

import java.util.Arrays;

public class CoinChange {
    public static void main(String[] args) {
        int[] coins = {1, 2, 5};
        int amount = 11;
        System.out.println("Minimum coins needed: " + coinChange(coins, amount));
    }

    public static int coinChange(int[] coins, int amount) {
        // dp[i] will store the minimum coins needed for amount i
        int[] dp = new int[amount + 1];
        
        // Fill dp array with a value larger than any possible answer
        Arrays.fill(dp, amount + 1);
        
        // Base case: 0 coins needed for amount 0
        dp[0] = 0;

        // Iterate through all amounts from 1 to 'amount'
        for (int i = 1; i <= amount; i++) {
            // Try every coin denomination
            for (int coin : coins) {
                if (i - coin >= 0) {
                    dp[i] = Math.min(dp[i], 1 + dp[i - coin]);
                }
            }
        }

        // If dp[amount] is still the initial value, it's impossible to make the amount
        return dp[amount] > amount ? -1 : dp[amount];
    }
}

Output:
Minimum coins needed: 3 (5 + 5 + 1)
