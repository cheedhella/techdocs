0/1 Knapsack Problem

Problem Statement

Given weights and values of n items, put these items in a knapsack of capacity W to get the maximum total value in the knapsack. In the 0/1 Knapsack problem, you are not allowed to break items; you either take the whole item or don't take it at all (0 or 1).

Algorithm (Dynamic Programming)

The core idea is to build a 2D table dp[n+1][W+1] where dp[i][w] represents the maximum value that can be attained with weight less than or equal to w using items up to i.

  • Base Case: If i = 0 or w = 0, dp[i][w] = 0.
  • Recursive Step:
    • If weight[i-1] <= w: dp[i][w] = max(val[i-1] + dp[i-1][w - weight[i-1]], dp[i-1][w])
    • Else: dp[i][w] = dp[i-1][w]

Example

Items: (Value: 60, Weight: 10), (Value: 100, Weight: 20), (Value: 120, Weight: 30)
Knapsack Capacity: 50
Max Value: 220 (by taking items with weights 20 and 30)


public class Knapsack {
    /**
     * Solves the 0/1 Knapsack problem using Dynamic Programming.
     * @param W Capacity of knapsack
     * @param wt Weights of items
     * @param val Values of items
     * @param n Number of items
     * @return Maximum value that can be put in a knapsack of capacity W
     */
    public static int knapSack(int W, int[] wt, int[] val, int n) {
        int[][] dp = new int[n + 1][W + 1];

        // Build table dp[][] in bottom up manner
        for (int i = 0; i <= n; i++) {
            for (int w = 0; w <= W; w++) {
                if (i == 0 || w == 0) {
                    dp[i][w] = 0;
                } else if (wt[i - 1] <= w) {
                    // Max of (including the item, excluding the item)
                    dp[i][w] = Math.max(val[i - 1] + dp[i - 1][w - wt[i - 1]], dp[i - 1][w]);
                } else {
                    // Weight of item is more than capacity, exclude it
                    dp[i][w] = dp[i - 1][w];
                }
            }
        }
        return dp[n][W];
    }

    public static void main(String[] args) {
        int[] val = {60, 100, 120};
        int[] wt = {10, 20, 30};
        int W = 50;
        int n = val.length;
        System.out.println("Maximum value in Knapsack: " + knapSack(W, wt, val, n));
    }
}

Output:
Maximum value in Knapsack: 220

Real-world Applications

  • Resource Allocation: Selecting the best combination of projects or investments given a fixed budget.
  • Cargo Loading: Optimizing the loading of containers or trucks with weight limits.
  • Network Routing: Selecting data packets to transmit over a bandwidth-limited connection.
  • Cryptography: The Merkle-Hellman knapsack cryptosystem (though now largely historical).
