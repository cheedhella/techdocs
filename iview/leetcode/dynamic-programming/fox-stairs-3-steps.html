Climbing Stairs - 3 Steps Variation (Dynamic Programming)

Problem: A fox wants to reach step N. It can jump either 1 step, 2 steps, or 3 steps at a time. How many different ways (combinations) can it reach step N?

Example:
Input: N = 4
Output: 7
Explanation: The combinations are: (1,1,1,1), (1,1,2), (1,2,1), (2,1,1), (2,2), (1,3), (3,1)

Approach 1: Recursion with Memoization (Top-Down DP) - O(N) Time, O(N) Space
To reach step N, the fox could have jumped from step N-1 (by taking 1 step), from step N-2 (by taking 2 steps), or from step N-3 (by taking 3 steps). Therefore, the total ways to reach N is the sum of the ways to reach N-1, N-2, and N-3. We use an array to store previously calculated answers to avoid redundant calculations.

Approach 2: Tabulation (Bottom-Up DP) - O(N) Time, O(N) Space
We build an array dp from size 0 to N. dp[i] stores the number of ways to reach step i. We set the base cases: dp[0] = 1, dp[1] = 1, dp[2] = 2. Then we iterate from step 3 to N, calculating dp[i] = dp[i-1] + dp[i-2] + dp[i-3].

Approach 3: Space Optimization - O(N) Time, O(1) Space
Since we only ever need the results of the last 3 steps to calculate the current step, we don't need a full array of size N. We can just keep three variables to store the last three results, dropping the space complexity to O(1).


public class FoxStairs {
    
    // Approach 1: Recursion with Memoization (Top-Down) O(N) Time, O(N) Space
    public int climbStairsMemo(int n) {
        if (n < 0) return 0;
        int[] memo = new int[n + 1];
        return climbStairsMemoHelper(n, memo);
    }
    
    private int climbStairsMemoHelper(int n, int[] memo) {
        if (n < 0) return 0;
        if (n == 0 || n == 1) return 1;
        if (n == 2) return 2;
        
        if (memo[n] != 0) return memo[n];
        
        memo[n] = climbStairsMemoHelper(n - 1, memo) + 
                  climbStairsMemoHelper(n - 2, memo) + 
                  climbStairsMemoHelper(n - 3, memo);
                  
        return memo[n];
    }

    // Approach 2: Tabulation (Bottom-Up) O(N) Time, O(N) Space
    public int climbStairsTabulation(int n) {
        if (n < 0) return 0;
        if (n == 0 || n == 1) return 1;
        if (n == 2) return 2;
        
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        dp[2] = 2;
        
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3];
        }
        
        return dp[n];
    }
    
    // Approach 3: Space Optimization O(N) Time, O(1) Space
    // To reach step N, the fox could have come from:
    // N - 1 (then jumped 1)
    // N - 2 (then jumped 2)
    // N - 3 (then jumped 3)
    // So the recurrence is:
    // f(n) = f(n-1) + f(n-2) + f(n-3)

    // Intuition for the recurrence:
    // Imagine the fox is standing on the final step 'N'. What was the *very last* jump it made?
    // There are only 3 possibilities:
    // 1. It was at step N-1, and made a 1-step jump.
    // 2. It was at step N-2, and made a 2-step jump.
    // 3. It was at step N-3, and made a 3-step jump.
    // 
    // Because these are the ONLY ways to arrive at step N, the total number of unique paths 
    // to reach step N is exactly the sum of the paths to reach N-1, N-2, and N-3.
    // 
    // Recurrence Formula: f(n) = f(n-1) + f(n-2) + f(n-3)
    // 
    // Since calculating the current step only requires knowledge of the PREVIOUS 3 steps, 
    // we do not need to store the entire array of size N. We can optimize memory to O(1) 
    // by only keeping track of the last 3 results in variables.
    public int climbStairsOptimized(int n) {
        if (n < 0) return 0;
        if (n == 0) return 1; // one way: stay where you are (0 steps)
        if (n == 1) return 1; // one way: jump 1 step
        if (n == 2) return 2; // two ways: jump 1 step, or jump 2 steps
        
        int stepMinus3 = 1; // Represents ways to reach step 0
        int stepMinus2 = 1; // Represents ways to reach step 1
        int stepMinus1 = 2; // Represents ways to reach step 2
        int current = 0;
        
        for (int i = 3; i <= n; i++) {
            current = stepMinus1 + stepMinus2 + stepMinus3;
            
            // Shift values forward for the next iteration
            stepMinus3 = stepMinus2;
            stepMinus2 = stepMinus1;
            stepMinus1 = current;
        }
        
        return current;
    }

    public static void main(String[] args) {
        FoxStairs solver = new FoxStairs();
        
        int[] testCases = {3, 4, 5, 10};
        
        for (int n : testCases) {
            System.out.println("Input: N = " + n);
            System.out.println("Output (Memoization):  " + solver.climbStairsMemo(n));
            System.out.println("Output (Tabulation):   " + solver.climbStairsTabulation(n));
            System.out.println("Output (Optimized):    " + solver.climbStairsOptimized(n));
            System.out.println("-".repeat(20));
        }
    }
}
