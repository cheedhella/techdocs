Find the first K smallest elements in the Array?

Given an array of integers, find the first K smallest elements in the array.

Example:

  • Input: [1, 3, 9, 15, 12, 5], K = 3
  • Output: [1, 3, 5]

We can use a min-heap to find the first K smallest elements in the array.

Algorithm:

  • 1. Heapify the input array
  • 2. Remove the smallest element K times

Time Complexity: O(N + K*logN)

Space Complexity: O(N)

                
                    public static void findFirstKSmallestElements(int[] arr, int k) {
                        MinHeap heap = new MinHeap(arr);
                        for (int i = 0; i < k; i++) {
                            System.out.println(heap.removeMin());
                        }
                    }

We can also use a max-heap to find the first K smallest elements in the array;

Algorithm:

  • 1. Add first K elements into max-heap
  • 2. For remaining elements:
    • If current element < heap top → replace top
    • Heap will contain K smallest elements

Time Complexity: O(N*logK)

Space Complexity: O(K)

                
                    public static void findFirstKSmallestElements(int[] arr, int k) {
                        MaxHeap heap = new MaxHeap(arr);
                        for (int i = k; i < arr.length; i++) {
                            if (arr[i] < heap.top()) {
                                heap.removeMax();
                                heap.insert(arr[i]);
                            }
                        }
                        return heap.toArray();
                    }
