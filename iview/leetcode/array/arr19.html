Find Maximum in Bitonic Array

Problem: A bitonic array is an array that is first monotonically increasing and then monotonically decreasing. Find the maximum element in such an array.

Algorithm:

  • We can use modified binary search, instead of scanning the entire array;
  • Binary Search Approach: Since the array is sorted in two parts, we can use a modified binary search to find the peak element.
  • In each step, compare the middle element with its next element:
    • If arr[mid] < arr[mid + 1], we are in the increasing part, so the maximum is to the right of mid. Set start = mid + 1.
    • If arr[mid] > arr[mid + 1], we are in the decreasing part, so the maximum is at mid or to its left. Set end = mid.
  • The loop terminates when start == end, which will be the index of the maximum element.

Complexity:

  • Time Complexity: O(log n)
  • Space Complexity: O(1)

Find Maximum in Bitonic Array

public class BitonicMax {
    public static void main(String[] args) {
        int[] arr = {1, 3, 8, 12, 4, 2};
        System.out.println("Maximum element: " + findMax(arr));
    }

    public static int findMax(int[] arr) {
        int start = 0;
        int end = arr.length - 1;

        while (start < end) {
            int mid = start + (end - start) / 2;

            if (arr[mid] > arr[mid + 1]) {
                // We are in the decreasing part
                // The current mid could be the maximum
                end = mid;
            } else {
                // We are in the increasing part
                // The maximum must be to the right
                start = mid + 1;
            }
        }

        // When start == end, we've found the peak
        return arr[start];
    }
}

Output:
Maximum element: 12
