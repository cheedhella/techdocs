Smallest Common Number in 3 Sorted Arrays

Problem: Given three integer arrays sorted in ascending order, find the smallest number that is present in all three arrays.

Algorithm:

  • Maintain three pointers, i, j, and k, initially pointing to the first element of each array.
  • Compare the elements at these pointers:
    • If a[i] == b[j] == c[k], we found the smallest common number.
    • Otherwise, increment the pointer that points to the smallest of the three current elements.
  • Repeat until one of the pointers reaches the end of its array.

Smallest Common Number in 3 Sorted Arrays

public class SmallestCommonNumber {
    public static void main(String[] args) {
        int[] a1 = {1, 5, 10, 20, 40, 80};
        int[] a2 = {6, 7, 20, 80, 100};
        int[] a3 = {3, 4, 15, 20, 30, 70, 80, 120};

        Integer result = findSmallestCommon(a1, a2, a3);
        if (result != null) {
            System.out.println("Smallest common number: " + result);
        } else {
            System.out.println("No common number found");
        }
    }

    public static Integer findSmallestCommon(int[] a1, int[] a2, int[] a3) {
        int i = 0, j = 0, k = 0;

        while (i < a1.length && j < a2.length && k < a3.length) {
            if (a1[i] == a2[j] && a2[j] == a3[k]) {
                return a1[i];
            }

            // Move the pointer pointing to the smallest number
            if (a1[i] <= a2[j] && a1[i] <= a3[k]) {
                i++;
            } else if (a2[j] <= a1[i] && a2[j] <= a3[k]) {
                j++;
            } else {
                k++;
            }
        }

        return null;
    }
}

Smallest common number: 20
