Given an array of integers, re-arrange its elements in such a way that the negative elements appear at one side and positive elements appear at the other?

// Simpler approach, but uses O(N) extra space;
public class P6_1 {
    public static void main(String[] args) {
        int[] arr = {10, -1, 20, 4, 5, -9, -6};

        int[] result = new int[arr.length];
        int index = 0;

        // First store all negatives
        for (int num : arr) {
            if (num < 0) result[index++] = num;
        }

        // Then store all positives
        for (int num : arr) {
            if (num >= 0) result[index++] = num;
        }

        System.out.println("Array after rearranging:");
        for (int num : result) {
            System.out.print(num + " ");
        }
    }
}

Output: -1 -9 -6 10 20 4 5


Given an array of integers, re-arrange its elements in such a way that the negative elements appear at one side and positive elements appear at the other?

// 2-pointer approach: it avoids extra space;
// Use two pointers: left starts from the beginning, right from the end;
// Move pointers inward, swapping when a positive number is on the left and a negative on the right;
// Result: All negatives grouped on one side, all positives on the other;

public class P6_2 {
    public static void main(String[] args) {
        int[] arr = {10, -1, 20, 4, 5, -9, -6};

        rearrange(arr);

        System.out.println("Array after rearranging:");
        for (int num : arr) {
            System.out.print(num + " ");
        }
    }

    public static void rearrange(int[] arr) {
        int left = 0;
        int right = arr.length - 1;

        while (left <= right) {
            // If left is negative, it's already on correct side
            if (arr[left] < 0 && arr[right] < 0) {
                left++;
            }
            // If right is positive, it's already on correct side
            else if (arr[left] > 0 && arr[right] > 0) {
                right--;
            }
            // If left is positive and right is negative, swap them
            else if (arr[left] > 0 && arr[right] < 0) {
                int temp = arr[left];
                arr[left] = arr[right];
                arr[right] = temp;
                left++;
                right--;
            }
            // If left is negative and right is positive, both are in place
            else {
                left++;
                right--;
            }
        }
    }
}

Output: 
Array after rearranging: -1 -9 -6 10 20 4 5
