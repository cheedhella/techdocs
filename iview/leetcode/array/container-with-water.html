Container With Most Water (#11)

Problem: You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water. Return the maximum amount of water a container can store.

Algorithm: Two Pointers

  • We use two pointers, left at the beginning and right at the end of the array.
  • The area of water is determined by the shorter of the two lines: Area = min(height[left], height[right]) * (right - left).
  • To maximize the area, we need to find taller lines. Since the width (right - left) will only decrease as we move the pointers, we should move the pointer that points to the shorter line.
  • If height[left] < height[right], move left++.
  • Otherwise, move right--.

Complexity:

  • Time Complexity: O(n) - Single pass through the array.
  • Space Complexity: O(1) - Constant extra space.

Container With Most Water (Java)

public class ContainerWithMostWater {
    public static void main(String[] args) {
        int[] height = {1, 8, 6, 2, 5, 4, 8, 3, 7};
        System.out.println("Maximum water: " + maxArea(height));
    }

    public static int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            // Calculate current area
            int currentHeight = Math.min(height[left], height[right]);
            int currentWidth = right - left;
            int currentArea = currentHeight * currentWidth;

            // Update global maximum
            maxArea = Math.max(maxArea, currentArea);

            // Move the pointer pointing to the shorter line
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}

Output:
Maximum water: 49
