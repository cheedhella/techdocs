Given an array of integers, Find 2nd maximum in it?

// Time Complexity: O(N);
public class P4 {
    public static void main(String[] args) {
        int[] arr = {10, 5, 20, 8, 20, 3};

        Integer max = null, secondMax = null; // Keep track of max and 2nd max

        for (int num : arr) {
            if (max == null || num > max) {
                secondMax = max;
                max = num;
            } else if ((secondMax == null || num > secondMax) && num != max) {
                secondMax = num;
            }
        }

        if (secondMax == null) {
            System.out.println("No second maximum (array may have all elements equal).");
        } else {
            System.out.println("Second maximum: " + secondMax);
        }
    }
}

Output:
Second maximum: 10


Given an array of integers, Find kth maximum in it?

// Use Sorting -> Time Complexity: O(N logN), suited for smaller arrays;
import java.util.Arrays;

public class P4_2 {
    public static void main(String[] args) {
        int[] arr = {10, 5, 20, 8, 20, 3, 15, 7, 12, 18};
        int k = 5; // 5th maximum

        // Sort array in descending order
        Arrays.sort(arr);
        
        // Remove duplicates and count down to 5th unique maximum
        int count = 0;
        int last = Integer.MIN_VALUE;

        for (int i = arr.length - 1; i >= 0; i--) {
            if (arr[i] != last) {
                count++;
                last = arr[i];
            }
            if (count == k) {
                System.out.println(k + "th maximum: " + arr[i]);
                return;
            }
        }

        System.out.println("Array doesn't have " + k + " unique elements.");
    }
}

Output:
5th maximum: 8


Given an array of integers, Find kth maximum in it?

You can use either a min-heap or a max-heap, to find the k-th maximum (or k-th minimum);
Time Complexity: O(n log k), good when k is small compared to array size, efficient for larger arrays;


import java.util.*;

public class P4_3 {
    public static void main(String[] args) {
        int[] arr = {10, 5, 20, 8, 20, 3, 15, 7, 12, 18};
        int k = 5; // 5th maximum

        Set unique = new HashSet<>();
        for (int num : arr) {
            unique.add(num); // remove duplicates
        }

        PriorityQueue minHeap = new PriorityQueue<>();

        for (int num : unique) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll(); // remove smallest
            }
        }

        // After removing k elements, smallest element in the min-heap is the k th maximum;
        if (minHeap.size() < k) {
            System.out.println("Array doesn't have " + k + " unique elements.");
        } else {
            System.out.println(k + "th maximum: " + minHeap.peek());
        }
    }
}

Output:
5th maximum: 8
