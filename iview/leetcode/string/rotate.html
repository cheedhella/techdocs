How to check if a String is a Rotation of Another String?

public class RotateString {
    public static void main(String[] args) {
        String str1 = "abcde";
        String str2 = "cdeab";
        boolean isRotation = isRotation(str1, str2);
        System.out.println("Is '" + str1 + "' a rotation of '" + str2 + "'? " + isRotation);
    }

    // Trick: check if s2 is substring of s1+s1
    public static boolean isRotation(String str1, String str2) {
        return (str1.length() == str2.length()) && ((str1 + str1).contains(str2));
    }
}

Output:
Is 'abcde' a rotation of 'cdeab'? true
