Algorithm
  • Take hashset, seen;
  • For each character ch = str.charAt(i):
    • If ch is not in seen, add it to seen and add it to result;
    • Else skip it;
  • Return the result;
  • Time Complexity: O(n), where n is the length of the string;
  • Space Complexity: O(n), where n is the length of the string;
How to remove duplicate characters from a String?

public class RemoveDuplicates {
    public static void main(String[] args) {
        String str = "aabbbcc";
        String result = removeDuplicates(str);
        System.out.println("Result: " + result);
    }

    public static String removeDuplicates(String str) {
        return str.chars().distinct().mapToObj(c -> String.valueOf((char) c)).collect(Collectors.joining());
    }
}

Output:
Result: abc
