Sort Words by Length and Alphabet

Problem: Given a list of words, sort them such that shorter words appear first. If two words have the same length, they should be sorted alphabetically.

Algorithm:

  • Use Java's Arrays.sort() or Collections.sort().
  • Provide a custom Comparator.
  • First comparison criteria: String::length.
  • Secondary comparison criteria: Comparator.naturalOrder() (alphabetical).

Sort Words by Length and Alphabet

import java.util.Arrays;
import java.util.Comparator;

public class SortWords {
    public static void main(String[] args) {
        String[] words = {"apple", "banana", "kiwi", "cherry", "pear", "fig", "date"};

        // Custom sorting: by length (primary), then alphabetically (secondary)
        Arrays.sort(words, Comparator.comparingInt(String::length)
                                     .thenComparing(Comparator.naturalOrder()));

        System.out.println("Sorted words: " + Arrays.toString(words));
    }
}

Output:
Sorted words: [fig, date, kiwi, pear, apple, cherry, banana]
