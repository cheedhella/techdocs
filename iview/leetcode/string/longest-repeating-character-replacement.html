Problem Statement
  • You are given a string s and an integer k. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most k times.
  • Return the length of the longest substring containing the same letter you can get after performing the above operations.
  • Example 1:
Input: s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.

Example 2:
Input: s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA".
The substring "BBBB" has the longest repeating letters, which is 4.
There may exists other ways to achieve this answer too.
Approach: Sliding Window
  • Use a sliding window with two pointers, left and right, initially at 0.
  • Maintain a frequency map (or an array of size 26 for uppercase English letters) to count the occurrences of each character in the current window.
  • Keep track of the maximum frequency (maxFreq) of any single character in the current window.
  • The number of characters we need to replace in the current window to make all characters identical is the length of the window minus the maximum frequency: (right - left + 1) - maxFreq.
  • If this number of replacements exceeds k, the current window is invalid. We must shrink the window by moving the left pointer to the right, decrementing the frequency of the character that goes out of the window.
  • Update the maximum length found so far for a valid window.
  • Key Idea: Keep expanding window, shrink only when replacements needed exceed k;
Algorithm
  • Initialize count array of size 26, maxFreq = 0, left = 0, maxLength = 0
For right from 0 to len(s) - 1:
    Increment count of s[right]
    Update maxFreq = max(maxFreq, count of s[right])
    
    If (right - left + 1) - maxFreq > k:
        Decrement count of s[left]
        left += 1
        
    maxLength = max(maxLength, right - left + 1)
    
Return maxLength
Longest Repeating Character Replacement (LeetCode #424)

Return the length of the longest substring containing the same letter you can get after performing at most k character replacements.


public class Main {
    public static void main(String[] args) {
        String s1 = "ABAB";
        int k1 = 2;
        System.out.println("Input: s = " + s1 + ", k = " + k1 + " | Output: " + characterReplacement(s1, k1));
        
        String s2 = "AABABBA";
        int k2 = 1;
        System.out.println("Input: s = " + s2 + ", k = " + k2 + " | Output: " + characterReplacement(s2, k2));
    }
    
    public static int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int maxFreq = 0;
        int left = 0;
        int maxLength = 0;
        
        for (int right = 0; right < s.length(); right++) {
            // Add the current character to the window
            count[s.charAt(right) - 'A']++;
            
            // Update the maximum frequency of a single character in the window
            maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);
            
            // If the number of characters to replace exceeds k, shrink the window
            if ((right - left + 1) - maxFreq > k) {
                count[s.charAt(left) - 'A']--;
                left++;
            }
            
            // Update the maximum length of the valid window
            maxLength = Math.max(maxLength, right - left + 1);
        }
        
        return maxLength;
    }
}

Time Complexity: O(n), where n is the length of the string. Both left and right pointers traverse the string at most once.
Space Complexity: O(1), since the size of the count array is fixed at 26 (constant space).
