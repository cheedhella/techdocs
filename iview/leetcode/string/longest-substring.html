Problem Statement
  • Given a string s, find the longest substring with unique characters(without duplicate/repeating characters)?
  • Example 1:
Input: "abcabcbb"
Output: "abc", "bca" and "cab"

Example 2:
Input: "bbbbb"
Output: b

Example 3:
Input: "pwwkew"
Output: "wke" and "kew"
Approach: Sliding Window
  • Take two pointers - left and right, both pointing to the start of the string;
  • Take an empty set, to store the characters in the current window(not ordered); It helps in finding if a character is already present in the window or not in O(1) time;
  • For each character in the string, do the following:
    • If the character is not in the set, add it to the set and move right to next character;
    • If the character is already in the set, keep removing the character at left from set and increasing left, until the set doesn't contain the current character;
  • In the end, left points to where the longest substring starts and right points to where the longest substring ends;
Algorithm
  • Take an empty set, s;
left = 0;
for right from 0 to len(s)-1:
    while s[right] is in set:
        remove s[left] from set
        left += 1
    add s[right] to set
return s[left : right]
Longest Substring Without Repeating Characters (LeetCode #3)

Given a string s, find the length of the longest substring without repeating characters.


import java.util.*;
public class Main
{
	public static void main(String[] args) {
	    String input1 = "abacde";
		System.out.println("input: " + input1 + ", ouput: " + longestUniqueSubstring(input1));
		String input2 = "adcdeab";
		System.out.println("input: " + input2 + ", ouput: " + longestUniqueSubstring(input2));
		String input3 = "bbbbb";
		System.out.println("input: " + input3 + ", ouput: " + longestUniqueSubstring(input3));
	}
	
	public static String longestUniqueSubstring(String s) {
        Set set = new HashSet<>();
        
        int left = 0;
        String result = "";

        for (int right = 0; right < s.length(); right++) {

            // remove duplicates
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }

            // add current character
            set.add(s.charAt(right));

            // update result directly
            // If you remove below, you will get last window, need not be the longest window;
            // When input is abcabcbb, you will get "b", instead of "abc";
            String current = s.substring(left, right + 1);
            if (current.length() > result.length()) {
                result = current;
            }
        }

        return result;
    }
}

Time Complexity: O(n), where n is the length of the string;
Space Complexity: O(n), where n is the length of the string;

Output:
input: abacde, ouput: bacde
input: adcdeab, ouput: cdeab
input: bbbbb, ouput: b
