1. What is DeQueue(Double-Ended Queue)?
  • It is a linear data structure that allows insertion and deletion of elements from both ends — front and rear;
  • It is like a combination of stack and queue;
  • It supports mainly these operations: addFirst(x), addLast(x), removeFirst(), removeLast(), peekFirst(), peekLast();
  • addFirst(x) - insert at front; Time Complexity: O(1);
  • addLast(x) - insert at rear; Time Complexity: O(1);
  • removeFirst() - delete from front; Time Complexity: O(1);
  • removeLast() - delete from rear; Time Complexity: O(1);
  • peekFirst() - get element from front; Time Complexity: O(1);
  • peekLast() - get element from rear; Time Complexity: O(1);
  • java.util.ArrayDeque - Backed by a resizable array (fast, no capacity limit);
  • java.util.LinkedList - It uses a double linked list to implement dequeue(slightly slower but more flexible)
DeQueue implementation using ArrayDeque

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Deque deque = new ArrayDeque<>();

        // Add elements at both ends
        deque.addFirst(10);
        deque.addLast(20);
        deque.addLast(30);
        deque.addFirst(5);

        System.out.println("Deque: " + deque);

        // Remove elements
        deque.removeFirst(); // removes 5
        deque.removeLast();  // removes 30

        System.out.println("After removals: " + deque);

        // Peek at both ends
        System.out.println("Front element: " + deque.peekFirst());
        System.out.println("Rear element: " + deque.peekLast());
    }
}

Output:
Deque: [5, 10, 20, 30]
After removals: [10, 20]
Front element: 10
Rear element: 20


DeQueue implementation using LinkedList;

import java.util.Deque;
import java.util.LinkedList;

public class Main {
    public static void main(String[] args) {
        // Create a Deque using LinkedList
        Deque deque = new LinkedList<>();

        // Add elements at both ends
        deque.addFirst(10);  // front
        deque.addLast(20);   // rear
        deque.addLast(30);   // rear
        deque.addFirst(5);   // front

        System.out.println("Initial Deque: " + deque);

        // Access elements
        System.out.println("Front element: " + deque.peekFirst());
        System.out.println("Rear element: " + deque.peekLast());

        // Remove elements from both ends
        deque.removeFirst();  // removes 5
        deque.removeLast();   // removes 30

        System.out.println("After removals: " + deque);

        // Add more elements
        deque.addFirst(100);
        deque.addLast(200);
        System.out.println("After adding more: " + deque);

        // Remove all elements
        while (!deque.isEmpty()) {
            System.out.println("Removing: " + deque.removeFirst());
        }

        System.out.println("Deque is now empty: " + deque);
    }
}

Output:
Initial Deque: [5, 10, 20, 30]
Front element: 5
Rear element: 30
After removals: [10, 20]
After adding more: [100, 10, 20, 200]
Removing: 100
Removing: 10
Removing: 20
Removing: 200
Deque is now empty: []
2. When to use LinkedList as Deque?
  • When frequent insertions/removals are needed at both ends;
  • When you don’t need random access (LinkedList traversal is slower than arrays);
  • Good for task scheduling, sliding window problems etc;
  • Use ArrayDeque, for palindrome checking etc;
