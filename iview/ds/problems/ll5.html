Given K Sorted Linked Lists, how to merge all of them into another Sorted Linked List?
Method 1: Using Hashing;
  • Take the first list, which is already sorted;
  • For each node in other lists,
    • Insert it into the first list;
Complexity: It takes O(n * k^2) time;
Method 2: Using Min-Heap;
  • Create min-heap and insert first elements of all K lists;
  • while min-heap is not empty
    • extract min from it(root is the minimum) and add it to result list;
    • If there exists another element next to the element(in the same linked list) extracted in above step, insert it into min-heap;
  • return the head node of the resulting list;
Complexity: It takes O(N * log K) time and O(K) extra space for heap; N - total number of nodes; K - total number of lists;
Method 3: Divide and Conquer technique;
  • The idea is to pair up K lists and merge each pair in linear time using O(1) space;
  • After the first cycle, K/2 lists are left each of size 2*N. After the second cycle, K/4 lists are left each of size 4*N and so on;
  • Repeat the procedure until we have only one list left;
Complexity: It takes O(N * log K) time, but it requires no extra space;
