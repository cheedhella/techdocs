1. What is Stack?
  • A linear data structure that follows the principle of LIFO — Last In, First Out;
  • It means the element that is most recently added to the stack is removed first;
  • It supports mainly 2 operations: push() and pop();
  • push(data) - It inserts the given object at the top of the stack; Stack overflow occurs if you try to push, when the stack is already full; Time Complexity: O(1);
  • pop() - It removes the top object from the stack; Stack underflow occurs if you try to pop, when the stack is already empty; Time Complexity: O(1);
  • peek() - It returns the top object from the stack without removing it; Time Complexity: O(1);
Stack implementation

class Stack {
    int top;
    int[] arr;
    int capacity; // It is possible to dynamically increase the capacity of the stack

    Stack(int size) {
        arr = new int[size];
        capacity = size;
        top = -1;
    }

    // Add element to stack
    void push(int x) {
        if (top == capacity - 1) {
            System.out.println("Stack Overflow");
            return;
        }
        arr[++top] = x;
    }

    // Remove top element
    int pop() {
        if (isEmpty()) {
            System.out.println("Stack Underflow");
            return -1;
        }
        return arr[top--];
    }

    // Peek top element
    int peek() {
        if (isEmpty()) {
            System.out.println("Stack is empty");
            return -1;
        }
        return arr[top];
    }

    // Check if empty
    boolean isEmpty() {
        return top == -1;
    }

    // Display stack elements
    void display() {
        for (int i = top; i >= 0; i--) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
    }
}

public class Main {
    public static void main(String[] args) {
        Stack s = new Stack(5);

        s.push(10);
        s.push(20);
        s.push(30);
        s.display();

        System.out.println("Top element: " + s.peek());

        s.pop();
        s.display();
    }
}

Output:

30 20 10
Top element: 30
20 10
