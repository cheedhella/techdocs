1. What is Bubble Sort?
  • It compares each element in the array with it's next element and swaps if they are not in order;
  • Once you complete an iteration, the largest element in the given array, bubbles up towards the end of the array; So, it is called Bubble Sort;
  • This process is repeated for n-1 passes, where n is the number of elements in the array;
  • At the end of the n-1 th pass, the array will be sorted;
2. Complexity
  • Time Complexity: Best Case: O(n) - If the array is already sorted; Worst Case: O(n^2);
  • Space Complexity: O(1);
3. Applications
  • It's never used because of it's average and worst case complexity is O(n^2);
4. Implementation
                
import java.util.*;

public class BubbleSort {
    private static final int[] sorted_input = new int[] { 1, 2, 3, 4  };
    private static final int[] reverse_sorted_input = new int[] { 10, 9, 8, 7, 6 };

    public static void main(String args[]) {
        BubbleSort.sort(Arrays.copyOf(sorted_input, sorted_input.length));
        System.out.println("----------------------------");
        BubbleSort.sort(Arrays.copyOf(reverse_sorted_input, sorted_input.length));
        System.out.println("----------------------------");
        BubbleSort.sort_improved(Arrays.copyOf(sorted_input, sorted_input.length));
        System.out.println("----------------------------");
        BubbleSort.sort_improved(Arrays.copyOf(reverse_sorted_input, sorted_input.length));
    }

    public static void sort(int[] data) {
        System.out.println("Input: " + Arrays.toString(data));
        int i;
        for (i = 1; i < data.length; i++) { // n-1 iterations needed!
            for (int j = 0; j < data.length - i; j++) {
                // Compare & Swap
                if (data[j] > data[j + 1]) {
                    int temp = data[j];
                    data[j] = data[j + 1];
                    data[j + 1] = temp;
                }
            }
        }
        System.out.println("No of iterations taken: " + (i - 1));
        System.out.println("Output: " + Arrays.toString(data));
    }

    // Used to stop iteration, if array is already sorted!
    public static void sort_improved(int[] data) {
        System.out.println("Input: " + Arrays.toString(data));
        int i;
        for (i = 1; i < data.length; i++) {
            boolean anySwaps = false;
            for (int j = 0; j < data.length - i; j++) {
                // Compare & Swap
                if (data[j] > data[j + 1]) {
                    anySwaps = true;
                    int temp = data[j];
                    data[j] = data[j + 1];
                    data[j + 1] = temp;
                }
            }
            if (!anySwaps) { // If there are no swaps, it means array is sorted!
                break;
            }
        }
        System.out.println("No of iterations taken: " + (i - 1));
        System.out.println("Output: " + Arrays.toString(data));
    }
}

5. What is Sinking Sort?
  • It is same as Bubble sort, just the direction of the comparison is reversed;
  • In case of Bubble Sort, the largest element bubbles up towards the end of the array;
  • In case of Sinking Sort, the smallest element sinks down towards the start of the array;
