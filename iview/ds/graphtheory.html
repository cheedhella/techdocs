Breadth First Search

 

Search a graph (directed or not) in breadth first; this is done by 
using a queue where the vertices found are stored.

Here is a brief description of the BFS algorithm:

    bfs (Graph G)
    {
	all vertices of G are first painted white
	
	the graph root is painted gray and put in a queue

	while the queue is not empty
	{
	    a vertex u is removed from the queue

	    for all white successors v of u
	    {
	        v is painted gray
		v is added to the queue
	    }

	    u is painted black
	}
    }





Depth First Search


The general idea is the same, but we now use a stack instead of a queue. 
With recursion of course, so the stack management is all done by Java.

Here is a brief description of the DFS algorithm:


    dfs-visit (Graph G, Vertex u)
    {
	the vertex u is painted gray
	
	for all white successors v of u
	{
	    dfs-visit(G, v)
	}

	u is painted black
    }


    dfs (Graph G)
    {
	all vertices of G are first painted white

	dfs-visit(G, root of G)
    }

Topological Ordering

What is a Topological Ordering of a Graph?
A topological ordering of a directed acyclic graph G  is a linear ordering of all its nodes as follows. 
If G contains an edge e=(u,v), node u appears before v in the ordering. If G is contains cycles, no topological 
ordering is possible.


Algorithm: (topological ordering)


    list L = empty
    while (G is not empty)
    find a vertex v with no incoming edges
    delete v from G
    add v to L




Running Time: is linear in the size of the graph (O(|V|+|E|)).

Algorithm: (topological ordering, detailed
implementation)



    list K = empty
    list L = empty
    for each vertex v in G
    let I[v] = number of incoming edges to v
    if (I[v] = 0) add v to K
    while (G is not empty)
    remove a vertex v from K
    for each outgoing edge (v,w)
    decrement I[w]
    if (I[w] = 0) add w to K
    add v to L
