1. What is Trie?
  • Trie is a tree based data structure that is used to store strings for fast retrieval;
  • Its name comes from the fact that Trie is reTrieval data structure;
  • It organizes information in a hierarchy;
    • Two strings with a common prefix have same ancestor in the tree;
    • If you have 1000's of strings, then you can use trie to store them; It is easy to search if the string exists in the collection or not;
    • For eg, trie is ideal data structure for storing dictionary;
    • Trie is used to prefix based searching and you can sort the collection;
  • Each node can have a max of 26 children(mind you, that number varies, if you want to store different set of alphabets);
  • Root node is always null and doesn't store anything;
  • Except root, each node in a trie contains the following:
    • a character or a digit;
    • Pointer to children nodes;
    • Flag that is set to true, if the current node completes a word;
2. Applications of Trie?
  • Autocomplete
  • Spell checker
  • IP Routing
3. Trie vs Hash table
  • Trie is useful to story huge number of strings, such as Dictionary and retrieve faster;
  • In case of Trie: No hashing algorithm, no key collisions;
  • Trie has a better worst-case complexity;
  • Hash table doesn't support prefix search;
  • Hash table requires more space than trie;

// Multiple readers allowed

    import java.util.*;
    import java.util.concurrent.ConcurrentHashMap;
    import java.util.concurrent.locks.ReentrantReadWriteLock;
    
    class TrieRW {
    
        static class Node {
            ConcurrentHashMap children = new ConcurrentHashMap<>();
            boolean isEnd;
        }
    
        private final Node root = new Node();
        private final ReentrantReadWriteLock lock = new ReentrantReadWriteLock();
    
        public void insert(String word) {
            lock.writeLock().lock();
            try {
                Node node = root;
                for (char c : word.toCharArray()) {
                    node = node.children.computeIfAbsent(c, k -> new Node());
                }
                node.isEnd = true;
            } finally {
                lock.writeLock().unlock();
            }
        }
    
        public void delete(String word) {
            lock.writeLock().lock();
            try {
                delete(root, word, 0);
            } finally {
                lock.writeLock().unlock();
            }
        }
    
        private boolean delete(Node node, String word, int index) {
            if (index == word.length()) {
                if (!node.isEnd) return false;
                node.isEnd = false;
                return node.children.isEmpty();
            }
    
            char c = word.charAt(index);
            Node child = node.children.get(c);
            if (child == null) return false;
    
            boolean shouldDelete = delete(child, word, index + 1);
    
            if (shouldDelete) {
                node.children.remove(c);
                return node.children.isEmpty() && !node.isEnd;
            }
            return false;
        }
    
        public List getWordsWithPrefix(String prefix) {
            lock.readLock().lock();
            try {
                List result = new ArrayList<>();
                Node node = root;
    
                for (char c : prefix.toCharArray()) {
                    node = node.children.get(c);
                    if (node == null) return result;
                }
    
                dfs(node, new StringBuilder(prefix), result);
                return result;
            } finally {
                lock.readLock().unlock();
            }
        }
    
        private void dfs(Node node, StringBuilder path, List result) {
            if (node.isEnd) result.add(path.toString());
    
            for (Map.Entry entry : node.children.entrySet()) {
                path.append(entry.getKey());
                dfs(entry.getValue(), path, result);
                path.deleteCharAt(path.length() - 1);
            }
        }
    }
