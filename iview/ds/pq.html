1. What is Priority Queue?
  • Priority Queue is a special type of queue in which each element is associated with a priority, and elements with higher priority are dequeued first (even if they arrived later);
  • It supports mainly 2 operations: insert(x, priority) and delete();
  • Priority queues are usually implemented using a binary heap, because it efficiently maintains order by priority;
  • Min-Heap → smallest element has the highest priority;
  • Max-Heap → largest element has the highest priority;
  • java.util.PriorityQueue
    • min-heap based implementation;
    • It supports these operations: add(x) and poll() -> Time Complexity: O(log n); peek() -> Time Complexity: O(1);
    • It orders elements according to their natural ordering (e.g., numbers in ascending order, strings alphabetically) or provide a custom comparator, if you want to use max-heap;
Priority Queue implementation

import java.util.PriorityQueue;

public class Main {
    public static void main(String[] args) {
        // Min-heap by default (smallest number = highest priority)
        PriorityQueue pq = new PriorityQueue<>();

        pq.add(30);
        pq.add(10);
        pq.add(20);

        System.out.println("Priority Queue elements: " + pq);

        System.out.println("Head (highest priority): " + pq.peek());
        pq.poll(); // removes the highest priority element
        System.out.println("After removing head: " + pq);
    }
}


Output:
Priority Queue elements: [10, 30, 20]
Head (highest priority): 10
After removing head: [20, 30]


Priority Queue implementation for object with custom priority;

import java.util.*;

class Task {
    String name;
    int priority;

    Task(String name, int priority) {
        this.name = name;
        this.priority = priority;
    }

    public String toString() {
        return name + " (priority " + priority + ")";
    }
}

public class Main {
    public static void main(String[] args) {
        // Higher priority value = higher importance
        PriorityQueue taskQueue = new PriorityQueue<>(
            (a, b) -> b.priority - a.priority
        );

        taskQueue.add(new Task("Email reply", 2));
        taskQueue.add(new Task("Server crash fix", 5));
        taskQueue.add(new Task("Code review", 3));

        while (!taskQueue.isEmpty()) {
            System.out.println("Processing: " + taskQueue.poll());
        }
    }
}

Output:
Processing: Server crash fix (priority 5)
Processing: Code review (priority 3)
Processing: Email reply (priority 2)
