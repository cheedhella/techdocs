What is a Expression Tree?
It is a binary tree which represents an expression;
In expression tree, each internal node contains operator and each leaf node contains operand;
An operator can be unary or binary;

Eg: Expression tree for 3 + ((5+9)*2) would be:

			+	
		 3	    * 
			 +     2 
		   5   9
Evaluation of Postfix Expression:
- Take an empty Stack, s;
- For each character in the postfix expression,
  - If current character is operand, push it to stack;
  - If current character is binary operator, pop two values from stack, apply the operation and push the result to stack;
- In the end, only element in the stack will be the expression value;
