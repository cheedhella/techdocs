1. What is Linked List?
  • A linear data structure in which elemenets are not stored at contiguous memory locations;
  • Each node in the list has 2 parts: data and a reference to the next node;
  • A special pointer, named head, always points to the first node in the list; It can be null, when the list is empty;
2. Array VS Linked List?
  • Size
    • In case of Arrays, size is fixed(you must know the maximum number of elements to be stored in advance);
    • In case of Linked List, size can grow/shrink dynamically, as insert/delete elements;
  • Storage
    • In case of Arrays, elements are stored contiguously;
    • In case of Linked List, elements are not stored contiguously;
  • Memory Allocation
    • In case of Array, memory is allocated at compile time;
    • In case of Linked List, memory is allocated at run time;
  • Memory Efficiency
    • For a given number of elements, Linked List takes more memory, as each node need to maintain a reference to next node;
  • Operations
    • Insertion/Deletion is faster in Linked Lists; Random Access(by index) is not possible in Arrays, so, we can't use it for binary search;
    • Accessing/Modifying an element is faster in Arrays;
3. What is Single Linked List?
  • Each node points only to the next node;
  • Navigation is one-way;
  • Implementation is here;
4. What is Double Linked List?
  • Each node has two pointers — one to the next node and one to the previous;
  • Allows forward and backward traversal;
5. What is Double Linked List?
  • The last node points back to the first node, forming a loop;
6. Time Complexicity
  • Insertion - O(1) at head to O(n) at middle/end;
  • Deletion - O(1) at head to O(n) at middle/end;;
  • Search - O(n);
  • Traversal - O(n);
