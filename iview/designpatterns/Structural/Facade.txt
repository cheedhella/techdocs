Facade Design Pattern
	Facade wraps a set of complex classes and provides a simple/unified interface to the client;
	In other words, It hides the complexity of the system and provides a simple/unified interface 
	to the client;

	It is a Structural pattern, because we are adding a new class to wrap all complex components 
	and provide a unified interface;

	Example 1:
		To switch-on a computer, you just need to press the power button;
		You don't need to know how it works internally; Here, power button is called a Facade;

	Example 2:
		To Start/Stop a car, you just need to press start/stop button;
		You don't need to know how it works internally; Here, start/stop button is called a Facade;
		https://www.baeldung.com/java-facade-pattern

	Example 3:
		If you want to organize a birthday party for 100 guests, you can let the party organizer 
		know your preferences(such as date and time of party, number of guests, party type, 
		decoration, food preferences etc); You don't have to worry about where to buy 
		food items/decoration items, how to cook, how to serve etc;
		Here, Party Organizer is called a Facade and it provides a simple and unified interface to you;

	Example 4:
		In Java, java.sql.DriverManager acts as a Facade because it provides a unified way of creating
		a connection(java.sql.Connection) to any DB; Actual implementation is left to the vendor;
			Connection c = DriverManager.getConnection("jdbc:oracle:thin:@localhost:1521:xe", user, pass;

	Example 5: Remote that sets up multiple systems;
		You can think of a remote control that sets up different systems as a Facade;
		Once you press ON, it turns on your TV, setup box, home theater and dims the lights etc;
		That's a Facade - one button/function that takes care of a set of complicated steps;

	Example 6: Trip Planner, which takes care of transportation, accomodation and everything in one click;
