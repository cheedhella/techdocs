1. What is Observerable Observer Design Pattern?
    👉 One Subject (Observable) 👉 Many Observers (Subscribers) When subject changes → all observers are notified 
    
# Publisher 
import java.util.*;

class WeatherStation {
    private List observers = new ArrayList<>();
    private int temperature;

    public void addObserver(Observer o) {
        observers.add(o);
    }

    public void setTemperature(int temperature) {
        this.temperature = temperature;
        notifyObservers();
    }

    private void notifyObservers() {
        for (Observer o : observers) {
            o.update(temperature);
        }
    }
}


# Subscriber 
interface Observer {
    void update(int temperature);
}
class PhoneDisplay implements Observer {
    public void update(int temp) {
        System.out.println("Phone shows temp: " + temp);
    }
}

class TVDisplay implements Observer {
    public void update(int temp) {
        System.out.println("TV shows temp: " + temp);
    }
}

# Temperature changes → WeatherStation notifies → Phone + TV update

| Concept   | Example            |
| --------- | ------------------ |
| Subject   | WeatherStation     |
| Observers | Phone, TV          |
| Event     | Temperature change |
