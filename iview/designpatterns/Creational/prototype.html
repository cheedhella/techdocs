1. What is Prototype Design Pattern?
  • It is used to create new objects by copying (cloning) an existing object, instead of building it from scratch;
  • It is especially useful when the object creation is complex or powerful;
  • 
# Shallow copy (by default)
List skills = new ArrayList<>();
    skills.add("Java");
    
    Employee e1 = new Employee("John", "IT", skills);
    Employee e2 = (Employee) e1.clone();
    
    e2.skills.add("Python");
    
    System.out.println(e1.skills); // [Java, Python] ❌ (shared!)



    

    
# Deep Copy 
@Override
protected Object clone() throws CloneNotSupportedException {
    Employee copy = (Employee) super.clone();
    copy.skills = new ArrayList<>(this.skills); // deep copy
    return copy;
}
