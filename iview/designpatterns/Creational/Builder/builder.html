1. What is Builder Design Pattern?
  • It is used to create complex objects step by step, especially when the object has too many optional parameters;
  • Eg: User user = User.builder().name("Alice").email("alice@mail.com").build();
  • Eg: WebClient client = WebClient.builder().baseUrl("https://api.example.com").defaultHeader("Content-Type", "application/json").build();
  • Eg: String query = new SQLQueryBuilder().select("*").from("users").where("age > 25").orderBy("name").build();
