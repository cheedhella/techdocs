1. What is Singleton Design Pattern?
  • It ensures that a class has only one instance and provides a global access point to it;
  • Eg: Runtime.getRuntime();
  • 
# Double-Checked Locking - thread-safe and efficient;
class Singleton {
    private static volatile Singleton instance;

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}

# Bill Pugh Singleton(uses class loading) - thread-safe and lazy
class Singleton {
    private Singleton() {}

    private static class Holder {
        private static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
