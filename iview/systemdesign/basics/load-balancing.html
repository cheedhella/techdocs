1. What is a Load Balancer?
  • A device or software that acts as a reverse proxy and distributes network or application traffic across a number of servers.
  • Prevents any single server from becoming a bottleneck, improving reliability and availability.
2. Benefits
  • High Availability: If one server fails, the LB redirects traffic to healthy servers.
  • Scalability: Allows adding or removing servers based on demand.
  • Performance: Distributes load to prevent server overload.
  • Security: Can provide SSL termination and DDoS protection.
3. Load Balancing Algorithms
  • Round Robin: Requests are distributed sequentially.
  • Least Connections: Sends traffic to the server with the fewest active connections.
  • Least Response Time: Sends traffic to the server with the lowest latency.
  • IP Hash: Uses client IP to determine which server receives the request (ensures session persistence).
4. Layer 4 vs Layer 7 Load Balancing
  • Layer 4 (Transport Layer): Based on IP and TCP/UDP ports. Faster but "blind" to application data.
  • Layer 7 (Application Layer): Based on HTTP headers, cookies, or URL paths. Allows "smart" routing (e.g., `/api` to one pool, `/images` to another).
5. Common Tools
  • NGINX, HAProxy, AWS ELB/ALB, Google Cloud Load Balancing.
