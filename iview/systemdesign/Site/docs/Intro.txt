SDIs are unstructured, where candidates are asked to take on an open-ended design problem that doesn’t have a standard solution.

Before you attempt:
1. Clarify Requirements and Ambiguities
	Since you will be give only 35-40 minutes to design a (supposedly) large system, you should clarify which part of the system you will be focusing on;

2. Back-of-the-envelope estimation
	Understand the scale of the system that you are going to design; 

3. System interface definition
	Define what APIs are expected from the system. 

4. Defining data model

5. High-level design

6. Detailed Design

7. Identify and Resolve bottlenecks
