1. Explain Microservices Architecture?
  • In case of monolithic architecture, entire application is built, deployed and scaled as a single unit; A change in one of the modules can only be brought into production, by bringing a new version of the entire application;
  • In case of microservices architecture, application is split into a collection of loosely coupled, independently deployable services; A change in one of the services can be brought into production, by deploying only that service;
2. Core Principles of Microservices
  • Breaks complexapplication into autonomous services
    • It breaks complex application into smaller and more manageable services, each responsible for a specific function;
  • Independent development and deployment
    • Teams can develop and deploy services independantly;
    • This speeds up development and reduces the time to market;
  • Scalability
    • You can scale only the services that are needed, instead of scaling the entire application;
  • Polygot Architecture
    • Each service can use a different technology; One servie can use Java, another can use Python etc;
  • Improved Fault Isolation
    • If one service fails, it does not affect the other services;
  • Better team organization
    • Teams can work on services independantly;
3. Bottom line
  • Microservices are used to make large systems easier to build, scale, maintain and evolve;
