1. What is an Edge Services?
  • It is the outermost layer that is exposed to the internet; It can be: CDN, API Gateway etc;
  • It is often called BFF (Backend for Frontend);
  • Instead of exposing many backend services directly via API Gateway, you create client-focused(mobile, web etc) edge services, so that you can customize response for each client type;
2. When client makes a request, will the request goes to API Server first or edge services first?
  • The request will go to edge services first and then to API Gateway; In many architectures, these 2 roles are combined; Tools like Kong, Nginx can play both the roles;
