What is Competing Consumers pattern?

  • Microservices are distributed in nature; When you work with distributed systems, always remember one thing - anything could happen;
  • We might be dealing with network issues, service unavailability, application slowness etc;
  • In that case, issue in one system might affect another system behavior/performance;

  • Bulkhead Pattern says failure in one service or a group of services should not bring down the whole application;
  • In other words, it is used to limit the resources which can be used by a service, so that resource exhaustion can be reduced;

  • It's named after the sectioned partitions (bulkheads) of a ship's hull; If the hull of a ship is compromised, only the damaged section fills with water, which prevents the ship from sinking;

  • for designing highly resilient Microservices using a library resilience4j along with Spring Boot
