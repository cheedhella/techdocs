What is Brownfield vs Greenfield deployment?

    Greenfield and Brownfield software development are 2 different software development methodologies;
  • Greenfield development refers to developing a system for a totally new environment and requires development from a clean slate – no legacy code around;
  • Brownfield software development refers to the development and deployment of a new software system in the presence of existing or legacy software systems.
