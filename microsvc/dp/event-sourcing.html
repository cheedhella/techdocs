1. What is Event Sourcing?
  • Instead of storing only the current state of an entity, Event Sourcing stores the entire history of changes as a sequence of events;
  • The current state is reconstructed by replaying all events from the beginning;
  • This provides a complete audit log and the ability to restore state at any point in time;
2. Key Concepts
  • Event Store: A database that stores the sequence of events;
  • Snapshots: Periodic captures of the state to speed up reconstruction by avoiding replaying thousands of events;
  • Immutability: Events are never changed or deleted; new events are only appended;
3. Benefits
  • Auditability: Perfect history of everything that happened in the system;
  • Temporal Queries: Ability to see what the state was at any specific time;
  • Decoupling: Other services can react to events as they happen;
