1. What is Fuzziness Search?
  • It is all about guessing what the user means, in case if he typed it wrong;
  • Fuzziness is applied at the query time, not during indexing;
  • When you search for foxx, It looks for nearby words like: fog, fox, box etc;
  • It uses edit distance (Levenshtein algorithm) to measure similarity;
  • It returns matches based on closeness, even if not exact;
  • Edit distance -> number of single-character edits (insertions, deletions, or substitutions) needed to turn one word into another word;
  • By default, if the edit distance between your query and a word in the index is small (e.g. ≤ 2), elasticsearch considers it a match; You can configure it in your query parameter;
  • GET /articles/_search { "query": { "match": { "content": { "query": "quik foxx", "fuzziness": "AUTO" } } } }
