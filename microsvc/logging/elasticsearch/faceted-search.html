1. What is Faceted Search?
  • It allows users to filter and refine search results using multiple facets - such as brand, price range, color, date, or rating;
  • GET /products/_search { "query": { "match": { "name": "laptop" } }, "aggs": { "brands": { "terms": { "field": "brand.keyword" } }, "price_ranges": { "range": { "field": "price", "ranges": [ { "to": 500 }, { "from": 500, "to": 1000 }, { "from": 1000, "to": 2000 } ] } } } }
