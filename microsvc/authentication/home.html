Authentication

1. What is Authentication?
  • Verifying who the user or system is;
  • Commonly done via tokens, certificates, or credentials;
2. Types of Authentication?
  • Token Based Authentication
    • JWT(JSON Web Token)
  • Service-to-Service Authentication
    • mTLS - often used with istio, linkerd;
3. Popular Authentication
  • Keycloak
  • Okta
  • Azure Active Directory
  • Ping Identity
| Scenario                   | Recommended Mechanism             |
| -------------------------- | --------------------------------- |
| User login (Web/Mobile)    | OpenID Connect + JWT              |
| Service-to-service         | mTLS or OAuth2 Client Credentials |
| Public APIs                | OAuth2 + JWT                      |
| Internal tools             | API Key (low risk only)           |
| Enterprise SSO             | OIDC + Central IdP                |
| High security environments | mTLS + Zero Trust                 |
