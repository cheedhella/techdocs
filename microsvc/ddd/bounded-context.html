1. What is Bounded Context?
  • In large systems, the same word can mean different things in different services;
  • For example, in a company, HR, Finance, Engineering all use the word 'employee', each department has it's own rules; Each department is a bounded context;
  • Typically, each microservice can have it's own bounded context;
  • Each context will have it's own definition of entities; It doesn't leak internal details to other services;
