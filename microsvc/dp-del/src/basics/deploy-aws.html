How to deploy a Microservice in AWS?

  • Based on requirement, you could choose a different backend for each microservice;
  • EC2
    • There is a misconception that you can't run microservices on AWS EC2;
    • You can run each microservice on it's own EC2 instance, which can be part of a different Auto Scaling Group with different scaling creteria;
    • You can select appropriate EC2 instance, based on the nature of the microservice;
    • For eg, if the microservice is memory intensive, you can select a EC2 instance with higher memory and scale based on memory;
    • You can use Elastic Load Balancer OR Amazon API Gateway to host the microservices;
  • AWS Lambda
    • You can also use AWS Lambda, serverless alternative, where each microservice backend is implemented in separate lamda functions; Note that lambda scales automatically;
    • There is no Auto Scaling Group; Lambda can also fronted by Elastic Load Balancer OR Amazon API Gateway;
  • Container
    • Another option is you can containerize your application and run in Amazon Elastic Kubernetes Service or Amazon Elastic Container Service;
    • In this case as well, it can be fronted by Elastic Load Balancer OR Amazon API Gateway;
