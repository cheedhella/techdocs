What is Proxy?

  • The proxy server acts as an intermediatory between the clients and servers;
  • There are 2 types of proxy servers:
    • Forward Proxy;
    • Reverse Proxy;

What is Forward Proxy?

  • Often called Proxy Server;
  • It is used to protect the identity of the client, by masking it's IP address; In other words, It sends the request on behalf of client;
  • It is part of the client side infrastructure;
  • Examples: Squid, CGI-Proxy, PHP-Proxy etc;
  • Proxy can also be used to:
    • Log requests;
    • Filter requests;
    • Transform requests by adding/removing headers, encrypting/decrypting, or compressing it;
    • Cache data;

What is Reverse Proxy?

  • Reverse proxy retrieves a resource from one or more servers, on behalf of a client and returns it to the client, appearing as if the response is originated from the proxy server, thus anonymizing the server;
  • In other words, it is part of server side infrastructure and it hides the identity of the server;
  • Examples: HAProxy, nginx, Apache httpd etc;
  • Reverse Proxy can also be used to:
    • Routing requests to appropriate servers;
    • Load Balancing;
    • It helps in mitigating DDoS attacks by throttling incoming requests;
    • Cache data;

Reverse Proxy VS Load Balancer

  • Reverse Proxy accepts the request from a client, forwards it to a server that can fulfill it and returns the server's response to the client;
  • Load Balancer distributes incoming client requests among a group of servers, in each case returning the response from the selected server to the appropriate client;
  • Nginx is a high-performance open-source tool for reverse proxying, load balancing, caching, and more;
