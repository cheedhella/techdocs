1. What is Open-Closed Principle?
  • A class should be open for extension, but closed for modification;
  • In microservices, we should be able to add a new service, without modifying existing ones;
  • For eg, if we want to add a new payment method(like paypal) to payment service, we should be able to do it without any changes to order service;
2. Why is it important?
  • Faster to develop and easy to deploy - Add new service and deploy only that service; No need to touch existing ones;
