    Spring Kafka Concepts to Learn — Summary
1. KafkaTemplate

The main API used by Spring to send messages to Kafka.

Supports synchronous and asynchronous sends.

Allows use of custom serializers, headers, and partitioning logic.

2. Message Listener Containers

Spring’s abstraction for consuming Kafka messages.

Two main types:

KafkaMessageListenerContainer – single-threaded.

ConcurrentMessageListenerContainer – multi-threaded; commonly used.

Handles polling, thread management, commits, and errors.

3. @KafkaListener

Annotation-based consumer definition.

Supports:

Concurrency settings

Batch vs. record-level consumption

Filtering, error handling, retry

Externalized topics and group IDs

4. Serialization & Deserialization

Spring Kafka supports:

String / JSON (via Jackson) / ByteArray

Custom serializers and deserializers

ErrorHandlingDeserializer helps catch and redirect deserialization failures.

5. Error Handling

Critical for production apps:

SeekToCurrentErrorHandler (older versions)

DefaultErrorHandler (newer versions)

Controls:

Retries

Backoff strategies

Dead-letter publishing (DLT)

6. Dead Letter Topic (DLT)

A separate Kafka topic for messages that failed processing.

Spring Boot auto-configures DLT handlers.

Supports observability and reprocessing.

7. Transactions

Ensures exactly-once semantics for producer + consumer.

Enable when:

You need atomic send + database updates

Using Kafka Streams-like reliability but in Spring

8. Batch Processing

Process messages in batches instead of one-by-one.

Improves throughput.

Key properties:

max.poll.records

@KafkaListener(batch = true)

9. Consumer Group Management

Understanding:

Group coordination

Partition rebalancing

Offset management

Spring Kafka allows:

Manual commit

Async commit

Synchronous commit

10. Offset Strategies

Types:

Auto commit

Manual commit within listener

Manual after processing

Important for at-least-once / exactly-once guarantees.

11. Headers and Metadata

Kafka headers allow:

Tracing

Correlation IDs

Routing logic

Spring integrates message headers with Message API.

12. Spring Boot Autoconfiguration

Simplifies:

Producer/consumer factory creation

Listener containers

Error handlers

Driven by application.properties or application.yml.

13. Kafka Streams Integration (optional but powerful)

For stream processing inside Spring Boot.

Concepts to learn:

Topologies

KStream, KTable

State stores

Windowing and joins

📘 Quick Learning Path

Start with producers and consumers (KafkaTemplate, @KafkaListener).

Learn serialization + deserialization.

Understand error handling + DLT.

Explore concurrency and container config.

Add transactions if needed for exactly-once.

Advanced: Kafka Streams + stateful processing.
