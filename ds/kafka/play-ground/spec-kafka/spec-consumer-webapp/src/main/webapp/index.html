📥 Spec Consumer - Kafka Order Consumer

Welcome to the Spec Consumer web application. This service consumes order messages from Kafka and logs them.

Available Endpoints:

GET /start

Start the consumer listener. The listener will consume orders from Kafka and print them to logs.

Example: curl http://localhost:8080/spec-consumer/start

GET /stop

Stop the consumer listener.

Example: curl http://localhost:8080/spec-consumer/stop

GET /status

Check the current status of the consumer and the number of messages consumed.

Example: curl http://localhost:8080/spec-consumer/status

GET /reset

Reset the consumed message count to zero.

Example: curl http://localhost:8080/spec-consumer/reset

Configuration:

  • Kafka Topic: orders
  • Bootstrap Servers: 10.253.228.200:9092
  • Consumer Group: order-consumer-group
  • Serialization Format: JSON / TMF64 (configurable)
  • Auto Offset Reset: earliest
