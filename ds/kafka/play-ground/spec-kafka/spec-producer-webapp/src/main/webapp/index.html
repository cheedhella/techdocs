🚀 Spec Producer - Kafka Order Producer

Welcome to the Spec Producer web application. This service produces order messages to Kafka.

Available Endpoints:

GET /produce

Start producing orders to Kafka. Orders will be generated and sent every 2 seconds.

Example: curl http://localhost:8080/spec-producer/produce

GET /stop

Stop producing orders to Kafka.

Example: curl http://localhost:8080/spec-producer/stop

GET /status

Check the current status of the producer.

Example: curl http://localhost:8080/spec-producer/status

Configuration:

  • Kafka Topic: orders
  • Bootstrap Servers: localhost:9092
  • Serialization Format: JSON / TMF64 (configurable)
  • Production Interval: 2 seconds
