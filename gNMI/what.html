1. What is gNMI?
  • It’s a protocol defined by the OpenConfig, for network management and telemetry;
  • It provides a standardized way to configure, retrieve state, and subscribe to telemetry data from network devices (like routers and switches) using gRPC as the transport and protobuf as the encoding;
  • In short: gNMI is like an API for talking to network devices (similar to how REST or NETCONF works), but optimized for modern telemetry and configuration at scale;
  • Configure devices
    • Configure devices (set/change network parameters)
    • Retrieve operational state (get current configuration or status)
    • Subscribe to telemetry streams (real-time monitoring)
  • Key features
    • Uses gRPC (efficient, streaming, bidirectional communication)
    • Data modeled using YANG models
    • Encodes data in protobuf for compact and efficient exchange
    • Supports secure transport (TLS)
  • Main RPCs
    • Capabilities: Query what models, encodings, and features the device supports
    • Get: Retrieve the current state/config of a device
    • Set: Modify configuration
    • Subscribe: Stream telemetry data in real time (polling, once-off, or continuous)
2. gRPC Implementations
  • gnmi
    • Reference implementaiton(by OpenConfig), written in Go;
    • Provides gnmi_cli (a command-line client) for testing gNMI RPCs - Often used as tool for validation;
  • User space scheduling and M:N modeling
    • goroutines are scheduled in the user space(rather than kernel space) by go runtime;
      So, swiching b/w goroutines is faster - as there is no need to enter kernel mode, only minimal state(like program counter, stack pointer etc) needs to be saved/restored;
    • Goroutines are multiplexed onto OS threads - It means thousands of goroutines can run on just a handful of threads, thus taking less memory and CPU;
  • gnmi-gateway(Arista’s open source project)
    • Collects telemetry via gNMI and forwards to backends like Kafka, Prometheus, or InfluxDB;

package main

import (
    "fmt"
    "time"
)

func printMessage(msg string) {
    for i := 0; i < 3; i++ {
        fmt.Println(msg, i)
        time.Sleep(500 * time.Millisecond)
    }
}

func main() {
    go printMessage("goroutine") // run concurrently with main goroutine
    printMessage("main")         // run in main goroutine - It is possible main routine can finish and die before child goroutine;
}

Output:
main 0
goroutine 0
main 1
goroutine 1
goroutine 2
main 2
