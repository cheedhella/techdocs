9. Command-Line Overrides

Overriding pom.xml Configuration from the Command Line
# Override target image
mvn jib:build -Dimage=myregistry.io/myapp:v2.0

# Set JVM flags
mvn jib:build -Djib.container.jvmFlags=-Xmx1g,-Xms512m

# Set environment variables
mvn jib:build -Djib.container.environment=ENV=prod,DEBUG=false

# Set ports
mvn jib:build -Djib.container.ports=8080,9090

# Override base image
mvn jib:build -Djib.from.image=eclipse-temurin:21-jre

# Set main class
mvn jib:build -Djib.container.mainClass=com.example.Main

# Set creation time
mvn jib:build -Djib.container.creationTime=USE_CURRENT_TIMESTAMP

# Skip Jib execution
mvn package -Djib.skip=true

# Use specific credentials
mvn jib:build \
  -Djib.to.auth.username=$USERNAME \
  -Djib.to.auth.password=$PASSWORD

# Build to Docker daemon
mvn jib:dockerBuild -Dimage=myapp:local

# Build as tarball
mvn jib:buildTar -Djib.outputPaths.tar=target/myapp.tar

# Build offline (use cached layers only)
mvn jib:build -Djib.offline=true

# Build with verbose output
mvn jib:build -X

Common Command-Line Properties:

  • -Dimage - Target image name
  • -Djib.from.image - Base image
  • -Djib.to.tags - Image tags (comma-separated)
  • -Djib.container.jvmFlags - JVM flags (comma-separated)
  • -Djib.container.environment - Environment variables
  • -Djib.container.ports - Exposed ports
  • -Djib.container.user - Container user
  • -Djib.skip - Skip Jib execution
  • -Djib.allowInsecureRegistries - Allow HTTP registries

Quick Reference Commands

# Build and push to registry
mvn compile jib:build

# Build to local Docker daemon
mvn compile jib:dockerBuild

# Build as tarball
mvn compile jib:buildTar

# Override image name
mvn jib:build -Dimage=myregistry.io/myapp:v1.0

# Use specific profile
mvn jib:build -Pprod

# Skip tests and build
mvn clean package jib:build -DskipTests

# Build with custom JVM flags
mvn jib:build -Djib.container.jvmFlags=-Xmx2g,-Xms1g

# Build with debug enabled
mvn jib:dockerBuild \
  -Djib.container.jvmFlags=-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=*:5005 \
  -Djib.container.ports=8080,5005
