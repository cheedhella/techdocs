7. Plugin Extensions

Extending Jib Functionality with Custom Plugins
<configuration>
    <pluginExtensions>
        <pluginExtension>
            <implementation>com.google.cloud.tools.jib.maven.extension.nativeimage.JibNativeImageExtension</implementation>
        </pluginExtension>
    </pluginExtensions>
</configuration>

Available Extensions:

  • Native Image Extension: Build GraalVM native images
  • Ownership Extension: Set file ownership in images
  • Layer Filter Extension: Customize layer creation
  • Custom Extensions: Create your own Jib extensions

Layering Configuration

<containerizingMode>exploded</containerizingMode>
<!-- Options: exploded (default), packaged -->

<!-- Custom layer configuration -->
<extraDirectories>
    <paths>
        <path>
            <from>target/dependencies</from>
            <into>/app/libs</into>
        </path>
    </paths>
</extraDirectories>

Build Configuration Options

<configuration>
    <!-- Allow insecure registries (not recommended for production) -->
    <allowInsecureRegistries>false</allowInsecureRegistries>
    
    <!-- Skip building the image (useful for multi-module projects) -->
    <skip>false</skip>
    
    <!-- Offline mode -->
    <offline>false</offline>
    
    <!-- Use only project cache -->
    <useOnlyProjectCache>false</useOnlyProjectCache>
    
    <!-- Send credentials over HTTP (insecure) -->
    <sendCredentialsOverHttp>false</sendCredentialsOverHttp>
</configuration>

Using Skip in Multi-Module Projects:

<!-- In parent pom.xml - skip by default -->
<plugin>
    <groupId>com.google.cloud.tools</groupId>
    <artifactId>jib-maven-plugin</artifactId>
    <version>3.4.0</version>
    <configuration>
        <skip>true</skip>
    </configuration>
</plugin>

<!-- In child module pom.xml - enable for specific modules -->
<plugin>
    <groupId>com.google.cloud.tools</groupId>
    <artifactId>jib-maven-plugin</artifactId>
    <configuration>
        <skip>false</skip>
        <to>
            <image>myregistry.io/${project.artifactId}</image>
        </to>
    </configuration>
</plugin>

<!-- Or skip from command line -->
<!-- mvn package -Djib.skip=true -->
