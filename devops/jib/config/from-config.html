2. From Configuration (Base Image)

Configuring the Base Image

Configure the base image your application will be built on:

Default Base Images (if not specified):

  • JAR files: eclipse-temurin:17-jre (or latest available Java 17 JRE)
  • WAR files: jetty:11-jre17-alpine (Jetty servlet container)
<configuration>
    <from>
        <!-- Base image -->
        <image>eclipse-temurin:17-jre</image>
        
        <!-- Alternative: Use distroless for smaller, more secure images -->
        <!-- <image>gcr.io/distroless/java17-debian12</image> -->
        
        <!-- Authentication for private base images -->
        <auth>
            <username>${env.REGISTRY_USERNAME}</username>
            <password>${env.REGISTRY_PASSWORD}</password>
        </auth>
        
        <!-- Specify platform (for multi-arch) -->
        <platforms>
            <platform>
                <architecture>amd64</architecture>
                <os>linux</os>
            </platform>
            <platform>
                <architecture>arm64</architecture>
                <os>linux</os>
            </platform>
        </platforms>
    </from>
</configuration>

Popular Base Images:

  • eclipse-temurin:17-jre - OpenJDK 17 (recommended for most apps)
  • eclipse-temurin:21-jre - OpenJDK 21 (latest LTS)
  • gcr.io/distroless/java17-debian12 - Minimal distroless image (most secure)
  • amazoncorretto:17 - Amazon's OpenJDK distribution
  • azul/zulu-openjdk:17-jre - Azul's OpenJDK build

Using Image Digest Instead of Tag

<from>
    <!-- More secure: pin to specific digest -->
    <image>gcr.io/distroless/java17-debian12@sha256:abc123...</image>
</from>
