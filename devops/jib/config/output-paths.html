6. Output Paths Configuration

Configuring Where Jib Stores Build Artifacts
<configuration>
    <outputPaths>
        <!-- Where to save the image digest -->
        <digest>${project.build.directory}/jib-image.digest</digest>
        
        <!-- Where to save the image ID -->
        <imageId>${project.build.directory}/jib-image.id</imageId>
        
        <!-- Where to save the image JSON -->
        <imageJson>${project.build.directory}/jib-image.json</imageJson>
        
        <!-- Tarball output location (for jib:buildTar) -->
        <tar>${project.build.directory}/jib-image.tar</tar>
    </outputPaths>
</configuration>

Why Use Output Paths:

  • Track image digests for deployment verification
  • Use image ID in subsequent CI/CD steps
  • Store image metadata for auditing
  • Generate SBOM (Software Bill of Materials)
