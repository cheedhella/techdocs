Jib

1. What is Jib?
  • Jib takes your spring boot application and builds a docker image, compliant to OCI(Open Container Initiative) format, without any Dockerfile and pushes the images to registries like docker hub, GitHub Container Registry etc;
  • So, it is ideal choice for CI/CD environments;
  • You don't need to know best practices for creating Dockerfiles;
  • You don't need to install Docker to create image; // Docker is needed if you want to install image;
  • It is open-source and developed by Google;
  • Alternatives: Buildpacks, Spotify, Fabric8.io;
  • Smart Layering: Jib separates out application into layers: dependencies, snapshot dependencies, resources, classes; If you change only one class, Jib rebuilds only that layer; So, it is optimized for faster incremental builds;
  • Reproducible Builds: Images are Deterministic, Timestamp-independent, Consistent across environments;
  • OCI compliant images: Jib builds standard OCI images, so they run in: Docker, K8s, Podman, containerd;
2. How to use it?
  • Add this maven dependency: 
    
  com.google.cloud.tools
  jib-maven-plugin
  3.4.0
  • Build and push: mvn compile jib:build -Dimage=myrepo/myapp
3. Docker image vs OCI Image?
| Feature                     | Docker Image   | OCI Image     |
| --------------------------- | -------------- | ------------- |
| Format                      | Docker-defined | Open standard |
| Compatible with Docker?     | Yes            | Yes           |
| Compatible with Podman/K8s? | Yes            | Yes           |
| Difference in practice      | Almost none    | Standardized  |
4. Jib vs Dockerfile?
| Feature                 | Jib         | Dockerfile     |
| ----------------------- | ----------- | -------------- |
| Requires Docker         | ❌ No        | ✅ Yes          |
| Custom OS setup         | ❌ Limited   | ✅ Full control |
| Java-optimized layering | ✅ Yes       | ❌ Manual       |
| CI friendly             | ✅ Excellent | Good           |
| Multi-language support  | ❌ Java only | ✅ Any          |
