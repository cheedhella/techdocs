Docker Image Naming

1. Image Name Syntax
[registry]/[namespace]/[repository]:[tag]

Example:

docker.io/cheedhella/jib-demo:latest
Part Description Example
registry The container registry host. If omitted, Docker defaults to docker.io docker.io, ghcr.io, gcr.io
namespace Your Docker Hub account name (or organisation) cheedhella
repository The image name jib-demo
tag The version label. Defaults to latest if omitted latest, 1.0-SNAPSHOT, v2.1
2. What Happens When You Pull an Image

When you run:

docker pull docker.io/cheedhella/jib-demo:latest

Docker will:

  1. Connect to Docker Hub (docker.io)
  2. Look under the namespace cheedhella
  3. Find the repository jib-demo
  4. Pull the image with tag latest
3. What Happens if the Repository Does Not Exist on Docker Hub?

When pushing (e.g. via jib:build), Docker / Jib will:

  1. Authenticate you with your credentials
  2. Verify you own the namespace (cheedhella)
  3. Create the repository automatically (if your account allows it)
  4. Push the image layers and manifest

When pulling a non-existent repository, Docker will return a 404 Not Found error.

4. Common Registry Formats
Registry Image Name Format
Docker Hub docker.io/username/myapp:tag
GitHub Container Registry ghcr.io/username/myapp:tag
Google Artifact Registry us-docker.pkg.dev/project-id/repo/myapp:tag
Amazon ECR 123456789.dkr.ecr.us-east-1.amazonaws.com/myapp:tag
Azure Container Registry myregistry.azurecr.io/myapp:tag
5. Setting the Image Name in Jib

In pom.xml:

<to>
    <image>docker.io/cheedhella/jib-demo</image>
    <tags>
        <tag>latest</tag>
        <tag>${project.version}</tag>
    </tags>
</to>

Override from CLI:

mvn compile jib:build -Dimage=docker.io/cheedhella/jib-demo:v2.0
