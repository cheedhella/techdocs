Resource Quotas

1. What are Resource Quotas?
  • Set limits on the total resources a namespace can consume;
  • Prevents any single team/project from monopolizing cluster resources;
  • Applied per namespace;
2. ResourceQuota YAML
apiVersion: v1
kind: ResourceQuota
metadata:
  name: dev-quota
  namespace: dev
spec:
  hard:
    requests.cpu: "4"
    requests.memory: 8Gi
    limits.cpu: "8"
    limits.memory: 16Gi
    pods: "20"
    services: "10"
    persistentvolumeclaims: "5"
    configmaps: "20"
    secrets: "20"
3. How It Works
  • When a quota is active, every Pod in the namespace must specify resource requests/limits;
  • If creating a resource would exceed the quota, the request is rejected;
  • Use with LimitRange to set default requests/limits for Pods that don't specify them;
4. Commands
# Create
kubectl apply -f quota.yaml

# View usage
kubectl describe resourcequota dev-quota -n dev

# Output:
# Name:            dev-quota
# Resource         Used   Hard
# --------         ----   ----
# limits.cpu       2      8
# limits.memory    4Gi    16Gi
# pods             5      20
