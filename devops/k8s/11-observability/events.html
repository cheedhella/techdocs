Kubernetes Events

1. What are Events?
  • Events are records of things that happened in the cluster;
  • Generated by the API Server, kubelet, scheduler, and controllers;
  • Stored in etcd with a default TTL of 1 hour;
  • Essential for understanding why something happened (or didn't);
2. Viewing Events
# All events in default namespace
kubectl get events

# Sorted by time
kubectl get events --sort-by='.lastTimestamp'

# All namespaces
kubectl get events -A

# Events for a specific resource
kubectl describe pod my-pod   # Events section at the bottom

# Watch events in real-time
kubectl get events -w
3. Event Types
TypeDescription
NormalInformational events (Pod scheduled, image pulled, container started)
WarningSomething unexpected (failed to pull image, probe failed, back-off restarting)
4. Common Events
  • Scheduled — Pod assigned to a node;
  • Pulling / Pulled — Image being pulled / successfully pulled;
  • Created / Started — Container created / started;
  • Killing — Container being terminated;
  • Unhealthy — Probe failed;
  • FailedScheduling — No suitable node found;
  • BackOff — Back-off restarting failed container;
  • FailedMount — Volume mount failed;
