kubectl commands quick reference

1. Containers
CommandDescription
# exec -> Execute a command in a container;
kubectl exec <pod-name> -- <command>Executes a command in a pod;
kubectl exec <pod-name> -c <container-name> -- <command>Executes a command in a specific container;
# exec -it -> Open an interactive terminal with container shell;
kubectl exec -it <pod-name> -- bashExecutes a command in a pod and opens an interactive terminal;
kubectl exec -it <pod-name> -c <container-name> -- bashExecutes a command in a specific container and opens an interactive terminal;
# Logs -> View logs of a container;
kubectl logs <pod-name> -c <container-name>Get logs of a specific container in a pod;
kubectl logs -f <pod-name> -c <container-name>Tail the logs of a container;
kubectl logs <pod-name> --previousGet logs from previous crashed container;
2. Pods
CommandDescription
kubectl run <pod-name> --image=<image-name> --port=<port> -n <namespace>Creates a pod with one container(running on specified port);
kubectl run mc-bb-p0 --image=busybox -it --rm -- shit -> opens interactiver terminal with container shell; --rm -> removes the pod after you exit the container; -- separates kubectl options from container command; BusyBox / Alpine -> sh; Ubuntu / Debian -> bash; Alpine -> ash;
kubectl get podsLists all pods in the current namespace;
kubectl describe pod <pod-name>Shows detailed information about a pod - image, port, environment variables, resource limits etc;
kubectl get pod <pod-name> -o yamlShows the YAML definition of a pod;
kubectl delete pod <pod-name>Deletes a pod;
kubectl logs <pod-name>Shows the logs for a pod;
kubectl port-forward <pod-name> 8080:80Forwards a port from a pod to a local port;
kubectl attach <pod-name>Attaches to a running pod;
kubectl top pod <pod-name>Shows resource usage for a pod;
kubectl cp file.txt <pod-name>:/tmp/file.txtCopy file from local machine to pod;
kubectl cp <pod-name>:/tmp/file.txt file.txtCopy file from pod to local machine;
3. Deployment
CommandDescription
kubectl create -f devops/k8s/pg/deployment-1.yaml It creates a deployment from a YAML file;
kubectl get deployList all deployments in the current namespace;
kubectl get podsLists all pods in the current namespace;
kubectl scale deployment nginx-deployment --replicas=4Scale up;
kubectl scale deployment nginx-deployment --replicas=2Scale down;
kubectl set image deployment/nginx-deployment nginx=nginx:1.26Rolling upgrade;
kubectl rollout status deployment nginx-deploymentView status of a deployment;
kubectl rollout history deployment nginx-deploymentView history of a deployment;
kubectl rollout undo deployment nginx-deploymentRollback to previous version;
kubectl rollout undo deployment nginx-deployment --to-revision=2Rollback to a specific revision;
kubectl rollout pause deployment nginx-deploymentPause a deployment;
kubectl rollout resume deployment nginx-deploymentResume a deployment;
kubectl delete deployment nginx-deploymentDelete a deployment;
3. Job

CommandDescription
kubectl get jobsList all jobs in the current namespace;
kubectl get cronjobsList all cron jobs in the current namespace;
kubectl get j,cj -AList all jobs and cron jobs across all namespaces;
kubectl get pods -l job-name=List all pods created by a Job;
kubectl logs -l job-name=Get logs of all pods created by a Job;
kubectl patch job <job-name> -p '{"spec":{"suspend":true}}'Suspend a job;
kubectl patch job <job-name> -p '{"spec":{"suspend":false}}'Resume a Job;
kubectl get cjList all cron jobs in the current namespace;
kubectl get jobs | grep Get all Jobs created by a Cron Job; Job created by CronJob doesn't have any label with cronjob name;
kubectl get pods | grep Get all Pods created by a Cron Job;
4. Daemonset
kubectl rollout status ds/ -> Shows progress of update across nodes. kubectl rollout undo ds/ -> Reverts to previous version. kubectl rollout history ds/ -> View rollout history; kubectl rollout restart ds/ -> Restart DaemonSet; Forces pods to restart on all nodes. kubectl delete ds -> delete a daemonset; kubectl delete pod -> 👉 DaemonSet automatically recreates it.
CommandDescription
kubectl get dsList all daemonsets in the current namespace;
kubectl get ds -AList all daemonsets across all namespaces;
kubectl get pods -l <label>Get all pods created dae;
kubectl get pvcList all PVCs in the current namespace;

CommandDescription
# get -> Quick summary;
kubectl get <resource-type> <resource-name>It gives quick summmary of a specific object of a given resource type(such as pods, nodes, services, deployments etc);
kubectl get <resource-type>It gives quick summmary of all objects of a given resource type(such as pods, nodes, services, deployments etc);
kubectl get allIt gives quick summmary of all the resources in the cluster;
# describe -> Detailed information about a specific resource;
kubectl describe <resource-type> <resource-name>It gives detailed information about a given resource type(such as pods, nodes, services, deployments etc);
# get -o yaml -> Complete YAML definition;
kubectl get <resource-type> <resource-name> -o yamlShows the YAML definition of a given resource type(such as pods, nodes, services, deployments etc);
kubectl cp
CommandDescription
# When there is only one container in the pod, you don't need to specify the container name;
kubectl cp <source> <pod-name>:<destination>Copy file from local machine to pod;
kubectl cp <pod-name>:<source> <destination>Copy file from pod to local machine;
# When there are multiple containers in the pod, you need to specify the container name;
kubectl cp <source> <pod-name>:<destination> -c <container-name>Copy file from local machine to pod specific container;
kubectl cp <pod-name>:<source> <destination> -c <container-name>Copy file from pod specific container to local machine;
kubectl taint nodes - # Remove taint https://www.baeldung.com/ops/kubernetes-taints-management kubectl delete all --all # Delete all resources in default namespace; kubectl delete all --all -n <namespace> # Delete all resources in specified namespace; kubectl delete all --all --all-namespaces # Delete all resources in all namespaces; kubectl delete pods,deployments,services --all --all-namespaces # Delete all pods, deployments and services in all namespaces; kubectl api-resources kubectl drain kubectl drain and kubectl cordon kubectl drain --ignore-daemonsets kubectl uncordon
