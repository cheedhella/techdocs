Service — LoadBalancer

1. What is LoadBalancer?
  • Provisions an external load balancer from the cloud provider (AWS ELB, Azure LB, GCP LB);
  • Assigns an external IP that routes traffic to the Service;
  • Automatically creates NodePort and ClusterIP as well;
  • The simplest way to expose a Service externally in a cloud environment;
2. LoadBalancer YAML
apiVersion: v1
kind: Service
metadata:
  name: my-lb-svc
spec:
  type: LoadBalancer
  selector:
    app: myapp
  ports:
    - port: 80
      targetPort: 8080
3. Traffic Flow
Internet → Cloud LB (External IP) → NodePort → ClusterIP → Pod
4. Considerations
  • Cost: Each LoadBalancer Service creates a separate cloud load balancer — can get expensive;
  • On-premise: Requires MetalLB or similar to provide LoadBalancer functionality;
  • Better alternative: Use Ingress to share a single load balancer across multiple services;
5. Check External IP
# Wait for external IP assignment
kubectl get svc my-lb-svc -w

# Output:
# NAME        TYPE           CLUSTER-IP     EXTERNAL-IP     PORT(S)
# my-lb-svc   LoadBalancer   10.0.171.239   52.149.12.34    80:31234/TCP
