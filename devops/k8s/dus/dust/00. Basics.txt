
What is K8s Cluster?
	Cluster is nothing but a set of nodes;

What is K8s Node?
	What is K8s? K8s is a Resource Manager; 
	What Resources it manages? It manages Virtual Servers(not physical);
	What is Virtual Server? 
		In AWS, it is called EC2 instance; In Azure, it is called Virtual Machine; In Google Cloud, it is called Compute Engine; 
		K8s gave all of them a generic name - called Worker Node;
	To manage 100s of worker nodes, you need Master Nodes;
	To simlify:
		Worker Node -> Runs our applications;
		Master Node -> Manages the Cluster or worker nodes;

	- Replica Set
	- Deployment
	- Services

	- Endpoints

	- Helm Charts
	- Taints and Tolerations
	- Network Policies
	- Pod Security Policies
	- Resource Requests and Limits
	- Pod Autoscaling
	- Liveness and Readiness Probes
	- Validating Admission Controllers
	- Jobs and CronJobs

Why so many resources?
	K8s follows single responsibility principle - each resource has only one responsibility/purpose;

How to create different resources in k8s cluster?
	There are 2 different ways to create objects in k8s cluster; First way is through command line and second is through a manifest file;
	kubectl apply -f <manifest.yaml>
	kubectl delete -f <manifest.yaml>
