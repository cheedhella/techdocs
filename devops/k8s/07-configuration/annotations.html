Annotations

1. What are Annotations?
  • Key-value pairs attached to objects for non-identifying metadata;
  • Unlike labels, annotations are NOT used for selection or filtering;
  • Can store larger data (up to 256KB), including structured data like JSON;
  • Used by tools, libraries, and controllers to store configuration;
2. Common Use Cases
  • Build/release info: build.version, git.commit;
  • Ingress controller config: nginx.ingress.kubernetes.io/rewrite-target;
  • Monitoring: prometheus.io/scrape: "true";
  • Deployment tools: Helm release info, ArgoCD sync status;
metadata:
  annotations:
    description: "Main API gateway for the application"
    prometheus.io/scrape: "true"
    prometheus.io/port: "9090"
    kubernetes.io/change-cause: "Updated image to v2.1"
3. Labels vs Annotations
FeatureLabelsAnnotations
PurposeIdentify and select objectsAttach metadata
Used in selectorsYesNo
Size limit63 chars value~256KB total
CharactersAlphanumeric, -, _, .Any string
4. Commands
# Add annotation
kubectl annotate pod my-pod description="API server"

# Update
kubectl annotate pod my-pod description="Updated API server" --overwrite

# Remove
kubectl annotate pod my-pod description-

# View
kubectl describe pod my-pod | grep Annotations
