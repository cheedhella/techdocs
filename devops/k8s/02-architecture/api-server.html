API Server

1. What is API Server?
  • Think of it as front door to your cluster; Every interaction with k8s goes through the API server;
  • It exposes REST API; All kubectl commands are converted to HTTP requests, before sending them to API Server;
  • Stateless (can scale horizontally);
  • Highly available (multiple API servers);
2. How write(create/update/delete) works?
  • When you run: kubectl apply -f pod.yaml, kubectl calls underlying REST API and API Server
    • Receives request;
    • Authenticates;
    • Authorizes;
    • Validates the request, rejects the invalid requests and adds default values;
    • Saves reqeust to etcd; API Server is the only component that talks(read/write) to etcd;
    • Notifies watchers(Scheduler watches for new pods, Controllers watch for changes, Kubelets watch assigned pods);
    • Returns response;
3. How read(get/list) works?
  • When you run: kubectl get pods, API Server
    • Receives request;
    • Authenticates;
    • Authorizes;
    • Fetch data from etcd;
    • Returns response;
4. Authentication Mechanisms?
  • Client certificates
  • Bearer tokens
  • HTTP Basic Authentication
5. Authorization Mechanisms?
  • ABAC
  • RBAC
  • The API server also supports webhook authorization (delegating decision-making to an external service), ABAC (policies in a static file), and the Node authorizer, a special-purpose authorizer that ensures kubelets can access resources only on their own node;
6. API Groups
  • Everything in Kubernetes is an API object — Pods, Services, Deployments, etc.;
  • The API is RESTful — you interact with it using standard HTTP methods (GET, POST, PUT, DELETE);
  • kubectl is just a CLI wrapper around API calls;
  • API resources are organized into API Groups and versions;

    8. What if you API server is down or you killed it(on leader node)?
    • Existing pods on the continues running;
    • kubelet running on that node, recreates the static pod;
    • Until API server is restored, that node won't accept any new pods and controllers stop reconcilation;
    • If it takes time to restore, that can trigger election;
