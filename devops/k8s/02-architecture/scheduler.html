Scheduler

1. What is Scheduler?
  • Scheduler watches API server for unscheduled Pods and assigns them to the best suitable node;
2. How it works?
    For every unscheduled Pod(API Server just saved the Pod object):
  • It removes the nodes that cannot run the Pod:
    • not having enough CPU/Memory
    • node selector mismatch
    • taints not tolerated
    • port conflicts
    • Output: List of eligible nodes;
  • Each eligible node gets a score based on rules:
    • Resource balance (least/most used);
    • Pod affinity/anti-affinity;
    • Topology spread;
    • Image locality;
    • Output: Nodes ranked from best → worst;
  • It picks the highest scoring node and sends the binding request(pod.nodeName = selected-node) to API Server; API Server updates etcd;
  • If no node is available, scheduler can evict low-priority pods;
  • Kubelet on that node sees node assignment and starts creating the Pod;
3. How it works in a multi-master setup?
  • In HA(multiple control plane nodes) setup, scheduler running on leader node only is active; Others stay in stand-by mode;
