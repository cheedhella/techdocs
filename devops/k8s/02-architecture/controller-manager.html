Controller Manager

1. What is Controller Manager?
  • It is a daemon that creates multiple controllers;
2. Controller Types?
  • ReplicaSetController
  • DeploymentController
  • StatefulSetController
  • DaemonSetController
  • JobController
  • CronJobController
3. What is Controller?
  • Each controller monitors(watches events from API server) objects of specific type;
  • It compares desired state(from spec) with actual state(from API server);
  • If there is a mismatch, it takes corrective actions;
  • It is a continous process;
4. How it works in a multi-master setup?
  • In HA(multiple control plane nodes) setup, controllers running on leader node are only active(Similar to scheduler); Others stay in stand-by mode;
