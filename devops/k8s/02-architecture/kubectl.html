kubectl

1. What is kubectl?
  • It is command line tool, which is used to interact with k8s cluster(API Server);
  • Either master or worker nodes doesn't need kubectl;
  • You can set it up on any one of master node(most convinient place to test cluster, after setup) OR your local system OR CI/CD system;
2. Setup kubectl
  • Install kubectl: apt install kubelet
3. How it works?
  • kubectl reads a kubeconfig file (default: ~/.kube/config) to know which cluster to connect to;
  • Converts your command into an API request and sends it to the API Server;
  • The API Server authenticates, authorizes, and processes the request;
  • kubectl displays the result;
4. What is kubeconfig?
  • A YAML file that stores information about clusters, users, and contexts;
  • Default location: ~/.kube/config;
  • Can be overridden with --kubeconfig flag or KUBECONFIG environment variable;
5. Structure of kubeconfig
apiVersion: v1
kind: Config
current-context: my-context

clusters:
  - name: my-cluster
    cluster:
      server: https://192.168.1.100:6443
      certificate-authority: /path/to/ca.crt

users:
  - name: my-user
    user:
      client-certificate: /path/to/client.crt
      client-key: /path/to/client.key

contexts:
  - name: my-context
    context:
      cluster: my-cluster
      user: my-user
      namespace: default
  • Clusters: Define the API Server endpoint and CA certificate;
  • Users: Define authentication credentials;
  • Contexts: Combine a cluster + user + namespace into a named context;
6. Configure kubectl(on master node)
    mkdir -p $HOME/.kube cp -i /etc/kubernetes/admin.conf $HOME/.kube/config chown $(id -u):$(id -g) $HOME/.kube/config > kubectl get nodes control-plane Ready worker-1 Ready
7. Configure kubectl(on your laptop or another VM)
    scp /etc/kubernetes/admin.conf user@your-laptop:~/.kube/config Replace: server: https://127.0.0.1:6443 -> server: https://:6443
8. Context Management
# View current context
kubectl config current-context

# List all contexts
kubectl config get-contexts

# Switch context
kubectl config use-context production-context

# Set default namespace for a context
kubectl config set-context --current --namespace=my-namespace

# Merge multiple kubeconfig files
export KUBECONFIG=~/.kube/config:~/.kube/config-cluster2
kubectl config view --merge --flatten > ~/.kube/merged-config
