Service — NodePort

1. What is NodePort?
  • Exposes the Service on a static port on every node in the cluster;
  • Accessible from outside the cluster via <NodeIP>:<NodePort>;
  • Allocates a port in the range 30000–32767 (configurable);
  • A ClusterIP is automatically created as well;
2. NodePort YAML
apiVersion: v1
kind: Service
metadata:
  name: my-nodeport-svc
spec:
  type: NodePort
  selector:
    app: myapp
  ports:
    - port: 80
      targetPort: 8080
      nodePort: 30080
  • port: ClusterIP port (internal);
  • targetPort: Pod port;
  • nodePort: External port on every node (optional — auto-assigned if omitted);
3. Traffic Flow
External Client → NodeIP:30080 → Service (ClusterIP:80) → Pod:8080
  • You can hit any node's IP — even if the Pod isn't running on that node;
  • kube-proxy routes the traffic to the correct Pod;
4. When to Use
  • Development and testing;
  • Simple external access when you don't have a cloud load balancer;
  • Not recommended for production — use LoadBalancer or Ingress instead;
