nodeSelector

1. What is nodeSelector?
  • The simplest way to constrain Pods to nodes with specific labels;
  • The Pod will only be scheduled on a node that has ALL the specified labels;
  • If no node matches, the Pod stays in Pending state;
2. Example
# Step 1: Label a node
kubectl label node worker-1 disktype=ssd

# Step 2: Use nodeSelector in Pod spec
apiVersion: v1
kind: Pod
metadata:
  name: ssd-pod
spec:
  nodeSelector:
    disktype: ssd
  containers:
    - name: app
      image: myapp:v1
3. Built-in Node Labels
  • Kubernetes automatically assigns labels to nodes:
kubernetes.io/hostname=worker-1
kubernetes.io/os=linux
kubernetes.io/arch=amd64
topology.kubernetes.io/zone=us-east-1a
topology.kubernetes.io/region=us-east-1
node.kubernetes.io/instance-type=m5.large
4. Limitations
  • Only supports exact match (equality-based) — no "prefer" or "in/notin";
  • For more flexible scheduling, use Node Affinity;
