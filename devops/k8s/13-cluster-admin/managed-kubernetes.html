Managed Kubernetes (EKS, AKS, GKE)

1. What is Managed Kubernetes?
  • Cloud providers manage the control plane for you — API Server, etcd, Scheduler, Controller Manager;
  • You only manage worker nodes and your workloads;
  • Control plane is HA, patched, and backed up automatically;
  • Significantly reduces operational burden;
2. Major Offerings

4. EKS Quick Start
# Using eksctl
eksctl create cluster \
  --name my-cluster \
  --region us-east-1 \
  --nodegroup-name workers \
  --node-type t3.medium \
  --nodes 3 \
  --managed

# Update kubeconfig
aws eks update-kubeconfig --name my-cluster --region us-east-1

# Verify
kubectl get nodes
5. When to Choose Managed vs Self-Managed
  • Choose managed when: running on cloud, small ops team, want to focus on apps not infra;
  • Choose self-managed when: on-premise requirement, need full control, compliance restrictions, bare-metal;
