What is kubectl?

1. What is kubectl?
  • kubectl (pronounced "kube-control" or "kube-C-T-L") is the command-line tool for interacting with Kubernetes clusters;
  • It communicates with the kube-apiserver to manage resources;
  • It's the primary interface for developers and operators working with Kubernetes;
  • Supports both imperative (do this now) and declarative (make it match this spec) operations;
2. How kubectl Works
  • kubectl reads a kubeconfig file (default: ~/.kube/config) to know which cluster to connect to;
  • Converts your command into an API request and sends it to the API Server;
  • The API Server authenticates, authorizes, and processes the request;
  • kubectl displays the result;
3. Syntax
kubectl [command] [TYPE] [NAME] [flags]

# Examples:
kubectl get pods                    # List all pods
kubectl get pod my-pod -o yaml      # Get a pod in YAML format
kubectl describe deployment nginx   # Detailed info about a deployment
kubectl delete service my-svc       # Delete a service
4. Useful Aliases and Autocomplete
# Create an alias
alias k='kubectl'

# Enable bash autocomplete
source <(kubectl completion bash)
echo 'source <(kubectl completion bash)' >> ~/.bashrc

# With alias
complete -o default -F __start_kubectl k
