Manual Scaling

1. Scaling Deployments
# Scale to 5 replicas
kubectl scale deployment myapp --replicas=5

# Scale to zero (stop all Pods)
kubectl scale deployment myapp --replicas=0

# Scale multiple resources
kubectl scale deployment myapp yourapp --replicas=3

# Conditional scaling (only if current replicas match)
kubectl scale deployment myapp --current-replicas=3 --replicas=5
2. Scaling Other Resources
# Scale a ReplicaSet
kubectl scale rs my-rs --replicas=4

# Scale a StatefulSet
kubectl scale statefulset mysql --replicas=3
3. Scaling via YAML
# Edit the replicas field in the manifest
spec:
  replicas: 5

# Then apply
kubectl apply -f deployment.yaml
4. Verifying Scale
# Watch Pods come up
kubectl get pods -w -l app=myapp

# Check Deployment status
kubectl rollout status deployment/myapp

# Check resource usage after scaling
kubectl top pods -l app=myapp
