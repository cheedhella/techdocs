Controller

1. What is a K8s Controller Manager?
  • K8s Controller Manager is a daemon that runs on the master node and creates multiple controllers such as Deployment Controller, ReplicaSet Controller, StatefulSet Controller, DaemonSet Controller, Job Controller, CronJob Controller etc;
  • Each controller is responsible for managing the state of a specific resource type(such as Deployment, Job etc);
2. What is a Controller?
  • It is a daemon that gets the current state of the cluster and takes corrective actions to reconcile it with desired state defined in the manifest file;
  • In other words, controllers are responsible for self-healing; If something drifts from what it should be, a controller steps in and makes it right;
  • For example, if a deployment specifies 3 Pods and the current state is 2 Pods, Deployment Controller will take corrective action to reconcile the state by creating a new Pod;
3. Controller Types
  • Deployment Controller
    • It ensures desired number of Pods(stateless applications) are running at all times;
    • It handles rolling updates and rollbacks;
  • StatefulSet Controller
    • It ensures desired number of Pods(stateful applications) are running at all times;
    • Eg: Database, Kafka, etcd etc;
  • DaemonSet Controller
    • It ensures desired number of Pods(daemons) are running on all nodes at all times;
    • Useful for Logging(Fluentd), Monitoring(Prometheus), Networking(Calico) etc;
  • Job Controller
    • It ensures desired number of Pods(jobs) are running and completed at all times;
  • CronJob Controller
    • It ensures desired number of Pods(cronjobs) are running at scheduled intervals;
