Installing Kubernetes (Minikube, kubeadm, Kind)

1. Local Development Options
  • Minikube: Runs a single-node Kubernetes cluster inside a VM or container on your local machine;
  • Kind (Kubernetes in Docker): Runs Kubernetes clusters using Docker containers as nodes — fast and lightweight;
  • Docker Desktop: Includes a built-in single-node Kubernetes cluster (enable in settings);
  • k3s: Lightweight Kubernetes distribution, ideal for local dev, IoT, and edge;
2. Minikube Setup
# Install minikube
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube

# Start a cluster
minikube start --driver=docker

# Verify
kubectl get nodes
minikube status
3. Kind Setup
# Install kind
go install sigs.k8s.io/kind@latest

# Create a cluster
kind create cluster --name my-cluster

# Verify
kubectl cluster-info --context kind-my-cluster
4. Production Setup with kubeadm
  • kubeadm is the official tool for bootstrapping production-grade Kubernetes clusters;
  • It initializes the control plane and joins worker nodes;
# On master node
sudo kubeadm init --pod-network-cidr=10.244.0.0/16

# Set up kubeconfig
mkdir -p $HOME/.kube
sudo cp /etc/kubernetes/admin.conf $HOME/.kube/config

# Install a CNI plugin (e.g., Flannel)
kubectl apply -f https://raw.githubusercontent.com/flannel-io/flannel/master/Documentation/kube-flannel.yml

# On worker node — join the cluster
sudo kubeadm join <master-ip>:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>
5. Installing kubectl
# Linux
curl -LO "https://dl.k8s.io/release/$(curl -sL https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
sudo install kubectl /usr/local/bin/kubectl

# Verify
kubectl version --client
