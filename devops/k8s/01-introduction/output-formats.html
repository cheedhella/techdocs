Output Formats and Filtering (JSONPath, custom-columns)

1. Output Formats (-o flag)
# Default table output
kubectl get pods

# Wide output (node, IP, etc.)
kubectl get pods -o wide

# YAML output
kubectl get pod my-pod -o yaml

# JSON output
kubectl get pod my-pod -o json

# Just the name
kubectl get pods -o name
2. JSONPath
# Get pod IP
kubectl get pod my-pod -o jsonpath='{.status.podIP}'

# List all pod names
kubectl get pods -o jsonpath='{.items[*].metadata.name}'

# Get container images
kubectl get pods -o jsonpath='{.items[*].spec.containers[*].image}'

# Formatted output with newlines
kubectl get pods -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.status.phase}{"\n"}{end}'

# Get node IPs
kubectl get nodes -o jsonpath='{.items[*].status.addresses[?(@.type=="InternalIP")].address}'
3. Custom Columns
# Custom column output
kubectl get pods -o custom-columns=NAME:.metadata.name,STATUS:.status.phase,NODE:.spec.nodeName

# From a file
kubectl get pods -o custom-columns-file=columns.txt
4. Filtering with Labels and Fields
# Filter by label
kubectl get pods -l app=nginx
kubectl get pods -l 'app in (nginx, redis)'
kubectl get pods -l app=nginx,tier=frontend

# Filter by field
kubectl get pods --field-selector status.phase=Running
kubectl get pods --field-selector metadata.name=my-pod

# Sort by a field
kubectl get pods --sort-by=.metadata.creationTimestamp
5. Dry Run — Generate YAML Without Applying
# Generate YAML for a deployment (without creating it)
kubectl create deployment nginx --image=nginx --dry-run=client -o yaml > deployment.yaml

# Generate YAML for a service
kubectl expose deployment nginx --port=80 --dry-run=client -o yaml > service.yaml
