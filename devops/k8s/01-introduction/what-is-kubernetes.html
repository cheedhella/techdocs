What is Kubernetes?

1. What is Kubernetes?
  • Kubernetes (K8s) is an open-source container orchestration platform originally developed by Google and now maintained by the CNCF;
  • It automates the deployment, scaling, and management of containerized applications;
  • The name "Kubernetes" comes from the Greek word for "helmsman" or "pilot" — the 8 letters between K and s give it the abbreviation K8s;
  • It provides a declarative configuration model — you describe the desired state and Kubernetes makes it happen;
2. Core Capabilities
  • Container Orchestration: Manages the lifecycle of containers across a cluster of machines;
  • Service Discovery & Load Balancing: Automatically exposes containers using DNS or IP addresses and distributes traffic;
  • Self-Healing: Restarts failed containers, replaces them, kills containers that don't respond to health checks;
  • Automated Rollouts & Rollbacks: Gradually rolls out changes and rolls back if something goes wrong;
  • Secret & Configuration Management: Manages sensitive information and application config without rebuilding images;
  • Storage Orchestration: Automatically mounts storage systems (local, cloud, NFS, etc.);
  • Horizontal Scaling: Scales applications up or down based on CPU/memory usage or custom metrics;
3. Kubernetes at a High Level
  • You package your application into a container image (e.g., Docker image);
  • You describe how to run it in a YAML manifest (Deployment, Service, etc.);
  • You submit the manifest to the Kubernetes API Server;
  • Kubernetes schedules containers onto available worker nodes in the cluster;
  • Kubernetes continuously monitors and maintains the desired state;
4. Quick Example

Deploy an nginx web server:

kubectl create deployment nginx --image=nginx:latest
kubectl expose deployment nginx --port=80 --type=NodePort
kubectl get pods

That's it — Kubernetes handles scheduling, networking, and health monitoring automatically.
