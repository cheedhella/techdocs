What is Kubernetes?

1. What is K8s(Pronounced as Koo-Ber-Net-ees)?
  • It is a container orchestration platform;
  • It manages the lifecycle of containers(deploy, scale, monitor) across a Cluster of machines;
2. Why K8s?
  • Before K8s, running applications at scale was hard;
  • K8s is used to:
    • Automated Deployment
      • Declare the desired state and K8s takes care of the rest;
    • Self-Healing
      • If application crashes, K8s automatically restart it;
      • If the node crashes, K8s automatically reschedules the application on healthy node;
      • Move the containers from one host to another, if the host dies or there is shortage of resources in it;
    • Horizontal Scaling
      • If traffic increases, K8s automatically creates more containers to handle the load(Scaling Up);
      • If traffic decreases, K8s automatically removes containers to save resources(Scaling Down);
    • Zero-Downtime Upgrades
      • Rolling updates and rollbacks
      • By gradually replacing old replicas with new ones, it ensures that the application remains available throughout the update process;
      • If new version of the application is released, k8s can update your application without downtime;
      • If something goes wrong, k8s can rollback to the previous version;
    • Resource Efficiency
      • K8s bin-packs containers onto nodes to make the most of available hardware;
    • Managing the communication b/w applications;
    • The best part is, it does all of this, without our involvement;
    • Apps build to work with k8s can be easily moved from one IaaS to another, without any changes to app source code;
3. K8s at a High Level
  • You package your application into a container image (e.g., Docker image);
  • You describe how to run it in a YAML manifest (Deployment, Service, etc.);
  • You submit the manifest to the Kubernetes API Server;
  • Kubernetes schedules containers onto available worker nodes in the cluster;
  • Kubernetes continuously monitors and maintains the desired state;
