Kubernetes API and API Server

1. The Kubernetes API
  • Everything in Kubernetes is an API object — Pods, Services, Deployments, etc.;
  • The API is RESTful — you interact with it using standard HTTP methods (GET, POST, PUT, DELETE);
  • kubectl is just a CLI wrapper around API calls;
  • API resources are organized into API Groups and versions;

3. API Request Flow
  • Authentication: Who are you? (certificates, tokens, OIDC);
  • Authorization: What are you allowed to do? (RBAC);
  • Admission Control: Mutating and validating webhooks modify or reject the request;
  • Persistence: The object is stored in etcd;
4. Exploring the API
# List all API resources
kubectl api-resources

# List API versions
kubectl api-versions

# Access API directly via proxy
kubectl proxy --port=8080
curl http://localhost:8080/api/v1/namespaces/default/pods

# Explain a resource
kubectl explain pod.spec.containers
