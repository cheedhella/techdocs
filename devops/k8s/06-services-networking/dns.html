DNS in Kubernetes (CoreDNS)

1. How DNS Works in Kubernetes
  • Kubernetes runs a DNS server (CoreDNS) as a Deployment in kube-system namespace;
  • Every Service gets a DNS record automatically;
  • Pods are configured to use the cluster DNS for name resolution;
2. Service DNS Names
# Full qualified domain name (FQDN)
<service-name>.<namespace>.svc.cluster.local

# Examples:
my-service.default.svc.cluster.local
redis.cache.svc.cluster.local

# Within the same namespace, just use the service name:
curl http://my-service
curl http://my-service:8080

# Cross-namespace:
curl http://my-service.other-namespace
3. Pod DNS
  • Regular Pods: <pod-ip-dashed>.<namespace>.pod.cluster.local
  • Example: 10-244-1-5.default.pod.cluster.local
  • StatefulSet Pods (with headless Service): <pod-name>.<service-name>.<namespace>.svc.cluster.local
4. DNS Debugging
# Run a debug Pod
kubectl run dnsutils --image=registry.k8s.io/e2e-test-images/jessie-dnsutils:1.3 -it --rm -- bash

# Inside the Pod:
nslookup my-service
nslookup my-service.default.svc.cluster.local
nslookup kubernetes.default

# Check CoreDNS pods
kubectl get pods -n kube-system -l k8s-app=kube-dns

# Check CoreDNS config
kubectl get configmap coredns -n kube-system -o yaml
