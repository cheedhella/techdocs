Access Modes (RWO, ROX, RWX)

1. What are Access Modes?
  • Define how a volume can be mounted by nodes;
  • Set on both PVs and PVCs — they must be compatible for binding;
2. Access Mode Types
ModeAbbreviationDescription
ReadWriteOnceRWOMounted as read-write by a single node
ReadOnlyManyROXMounted as read-only by many nodes
ReadWriteManyRWXMounted as read-write by many nodes
ReadWriteOncePodRWOPMounted as read-write by a single Pod (K8s 1.27+)

4. Choosing the Right Mode
  • RWO: Databases (MySQL, PostgreSQL) — single writer;
  • ROX: Shared configuration files, static assets;
  • RWX: Shared file uploads, CMS content, logs — multiple writers;
  • RWOP: When you need to ensure only one Pod writes (stricter than RWO);
