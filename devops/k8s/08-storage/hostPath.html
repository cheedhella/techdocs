hostPath

1. What is hostPath?
  • It is used to mount a file/directory from the node's filesystem into the Pod;
  • Data written by a Pod is available, as long as the Pod is running on that Node;
  • If the Pod is reassigned to a new node, it won't be able to access HostPath volumes from a previous node;
  • Security risk: Pod gets access to the host filesystem; So, it is not recommended to use in production;
2. hostPath Demo
# hostPath-demo.yaml
apiVersion: v1
kind: Pod
metadata:
  name: hostpath-demo
spec:
  containers:
  - name: app
    image: busybox
    command: ["sh", "-c", "ls /host-data; sleep 3600"]
    volumeMounts:
    - name: host-volume
      mountPath: /host-data         # It mounts the host-volume volume object at /host-data path in the container;

  volumes:
  - name: host-volume
    hostPath:                   # It creates a volume object using /tmp directory on the node; 
      path: /tmp
      type: Directory
