Persistent Volumes (PV)

1. What is a Persistent Volume?
  • A cluster-level resource that represents a piece of storage provisioned by an admin or dynamically via StorageClass;
  • Has a lifecycle independent of any Pod — data persists even after the Pod is deleted;
  • Abstracts the underlying storage technology (NFS, AWS EBS, GCE PD, etc.);
2. PV YAML
apiVersion: v1
kind: PersistentVolume
metadata:
  name: my-pv
spec:
  capacity:
    storage: 10Gi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: manual
  hostPath:
    path: /mnt/data
3. PV Status Lifecycle
PhaseDescription
AvailableNot yet bound to a PVC
BoundBound to a PVC
ReleasedPVC deleted, but PV not yet reclaimed
FailedAutomatic reclamation failed
4. Reclaim Policies
PolicyBehavior
RetainPV is kept after PVC deletion. Admin must manually clean up.
DeletePV and underlying storage are automatically deleted.
RecycleBasic scrub (rm -rf). Deprecated — use dynamic provisioning.
5. Commands
# List PVs
kubectl get pv

# Describe
kubectl describe pv my-pv
