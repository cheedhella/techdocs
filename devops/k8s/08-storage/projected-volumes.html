Projected Volumes and CSI Drivers

1. Projected Volumes
  • Combine multiple volume sources into a single directory;
  • Supported sources: secret, configMap, downwardAPI, serviceAccountToken;
volumes:
  - name: combined
    projected:
      sources:
        - secret:
            name: db-creds
        - configMap:
            name: app-config
        - downwardAPI:
            items:
              - path: "labels"
                fieldRef:
                  fieldPath: metadata.labels
2. CSI (Container Storage Interface)
  • A standard interface for exposing storage systems to container orchestrators;
  • Allows storage vendors to write a single plugin that works with Kubernetes, Mesos, etc.;
  • Replaces the old in-tree volume plugins (aws-ebs, gce-pd, etc.);
  • CSI drivers run as Pods in the cluster;

4. Volume Snapshots
  • CSI enables volume snapshots — point-in-time copies of volumes;
  • Useful for backups and cloning;
apiVersion: snapshot.storage.k8s.io/v1
kind: VolumeSnapshot
metadata:
  name: my-snapshot
spec:
  volumeSnapshotClassName: csi-snapclass
  source:
    persistentVolumeClaimName: my-pvc
