Job

1. What is a Job?
  • A Job creates Pods that run to completion — unlike Deployments which run forever;
  • Once all Pods finish successfully, the Job is complete;
  • If a Pod fails, the Job creates a new one (based on restart policy);
2. Job YAML
apiVersion: batch/v1
kind: Job
metadata:
  name: data-migration
spec:
  completions: 1
  parallelism: 1
  backoffLimit: 4
  activeDeadlineSeconds: 300
  template:
    spec:
      restartPolicy: OnFailure
      containers:
        - name: migrate
          image: myapp:migrate
          command: ["python", "migrate.py"]
3. Key Fields
FieldDescription
completionsNumber of Pods that must complete successfully (default: 1)
parallelismNumber of Pods to run concurrently (default: 1)
backoffLimitNumber of retries before marking Job as failed (default: 6)
activeDeadlineSecondsMax time the Job can run before being terminated
ttlSecondsAfterFinishedAuto-delete the Job N seconds after completion
4. Job Patterns
  • Single completion: completions: 1, parallelism: 1 — run one task;
  • Multiple completions: completions: 5, parallelism: 2 — process 5 items, 2 at a time;
  • Work queue: completions: null, parallelism: 3 — run until all work is done;
5. Commands
# Create a Job imperatively
kubectl create job test-job --image=busybox -- echo "Hello"

# List Jobs
kubectl get jobs

# View logs
kubectl logs job/data-migration

# Delete
kubectl delete job data-migration
