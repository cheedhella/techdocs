Github 
    On VM where you want to clone a repository:
        - Run: ssh-keygen
        - Copy the public key: C:\Users\Administrator/.ssh/id_ed25519.pub
    Go to GitHub → Settings → SSH and GPG keys
    Click "New SSH key"
    Set a title (e.g. "Windows VM")
    Paste the copied key into the Key field
    Click "Add SSH key"
    Test: ssh -T git@github.com

    # GitHub supports SSH over port 443, which is typically open even on restricted networks.
    C:\Users\YourUsername\.ssh\config
    Host github.com
      HostName ssh.github.com
      Port 443
      User git
      IdentityFile ~/.ssh/id_ed25519
