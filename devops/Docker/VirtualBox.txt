What is Virtualization?
	Virtualization refers to the act of creating a virtual (rather than actual) version of something(server, operating system, storage device, network).

What is Virtual Machine?
	A computer created within another computer. It runs in a window, just like another program.
	You can run multiple virtual machines simultaneously on the same physical computer.
	Guest Machine - synonym for virtual machine
	Host Machine - physical computer on which you created virtual machines
	Guest OS - OS running inside VM
	Host OS - OS running on host machine

How it helps?
	- You can run more than on virtual machine on a single computer(it reduces associated maintanance costs).
	- It allows users to share infrastructure.
	- run a software that your host os doesn't support.
	- VM is sandboxed from the rest of the system, meaning that the software inside a virtual machine cannot escape or tamper with the host. 
	  This produces an ideal environment for testing beta releases of operating systems, accessing virus-infected data etc.

What is hypervisor?
	A program that allocates resouces(CPU, RAM, harddisk, network etc) to virtual machines from host machine's resources.

Type 1 Hypervisor
	Hypervisor is installed directly on host computer(bare metal). There is host OS and hypervisor has direct access to all hardware.
	Example: Microsoft Hyper-V

Type 2 Hypervisor
	Hypervisor is installed on host OS.
	Example: Oracle VitualBox

Accessing files on Host from VM
	1. Power-off VM
	2. VitualBox -> VM Configuration -> Shared Folders
	3. Add a new shared folder
	4. Click the down arrow in the folder path box and select “Other…”. 
		Navigate to a folder on your Mac, such as your Desktop or your Documents folder. Once you have chosen your folder, click “Choose”.
	5. Make sure “Read-only” is not checked, and that “Auto-mount” is checked.
		You can choose to make it read-only, auto-mount the folder after restarts, and make the shared folder permanent.


	1. Start VM
	2. Devices ->  Shared Folders –> Shared Folders Settings

		To mount a shared folder in a Linux Guest OS such as Ubuntu, type in the following command in terminal:
		mount -t vboxsf [-o OPTIONS] sharename mountpoint
		Replace sharename with the name of the share and mountpoint with the path where you want the share to be mounted (i.e. /mnt/share).
