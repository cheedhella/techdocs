Built-in Objects 
    .(Root), .Release, .Chart, .Values, .Capabilities, .Template, .Files;
    These objects that are passed to every template by template engine;
    Each object contains a set of key-vaue pairs, where each value could be another object or function;
    Eg: .Release.Name is an object and .Files has few functions;
------------------------------------------------------------------------------------------------------------------------------------------------------
Root object 
    - Top level helm object;
    - It contains 7 objects: Release, Chart, Values, Capabilities, Template, Files, Subcharts;
------------------------------------------------------------------------------------------------------------------------------------------------------
Chart object 
    - We can acees any data from Chart.yml file;
------------------------------------------------------------------------------------------------------------------------------------------------------
Values object 
    - By default, it is an empty object;
    - It contains values from values.yml and if any user supplied values(using -f or --set ) that can be passed to templates; 
    
------------------------------------------------------------------------------------------------------------------------------------------------------
Release object 
    - It provides information about release;
------------------------------------------------------------------------------------------------------------------------------------------------------
Capabilities Object 
    - It provides information about what capabilities the k8s cluster supports;
------------------------------------------------------------------------------------------------------------------------------------------------------
Template Object 
    - It contains info about currently executed template;
------------------------------------------------------------------------------------------------------------------------------------------------------
Files Object 
    - It provides access to all non-special files in a chart;
    - We can use it to access files in the charts folder;
    - We can't use it to access templates;
