Creating Your First Chart

1. Scaffold with helm create
  • helm create generates a chart with the standard structure and default Nginx templates: 
    helm create myapp

ls -a myapp/
.helmignore  Chart.yaml  charts/  templates/  values.yaml

ls myapp/templates/
NOTES.txt  _helpers.tpl  deployment.yaml  hpa.yaml  ingress.yaml
service.yaml  serviceaccount.yaml  tests/
  • For a detailed breakdown of every generated file and its fields, see Creating a Chart — sections 2 & 3;
2. Creating a Minimal Chart from Scratch
  • You only need three files — Chart.yaml, values.yaml, and at least one template: 
    mkdir -p myapp/templates
  • Chart.yaml: 
    apiVersion: v2
name: myapp
version: 1.0.0
appVersion: "1.0.0"
description: My application
  • values.yaml: 
    replicaCount: 2
image:
  repository: nginx
  tag: "1.21"
service:
  port: 80
  • templates/deployment.yaml: 
    apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: {{ .Release.Name }}
  template:
    metadata:
      labels:
        app: {{ .Release.Name }}
    spec:
      containers:
      - name: {{ .Chart.Name }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
        ports:
        - containerPort: {{ .Values.service.port }}
  • templates/service.yaml: 
    apiVersion: v1
kind: Service
metadata:
  name: {{ .Release.Name }}
spec:
  type: ClusterIP
  ports:
  - port: {{ .Values.service.port }}
    targetPort: {{ .Values.service.port }}
  selector:
    app: {{ .Release.Name }}
3. Validate Before Installing
  • Lint — catches structural errors and best-practice violations: 
    helm lint ./myapp
  • Render — outputs final YAML without sending anything to the cluster: 
    helm template myrelease ./myapp
  • Dry-run — renders and validates against the live k8s API server: 
    helm install myrelease ./myapp --dry-run --debug
  • Server-side validation via kubectl: 
    helm template myrelease ./myapp | kubectl apply --dry-run=client -f -
4. Install and Verify
  • Install: 
    helm install myrelease ./myapp
  • Check status: 
    helm status myrelease
kubectl get all -l app=myrelease
  • Test connectivity: 
    kubectl port-forward svc/myrelease 8080:80
curl http://localhost:8080
5. Iterate (upgrade / rollback)
  • Edit values or templates, then preview and apply: 
    helm upgrade myrelease ./myapp --dry-run --debug
helm upgrade myrelease ./myapp
  • Roll back if something breaks: 
    helm rollback myrelease
  • Uninstall when done: 
    helm uninstall myrelease
6. Simplifying the Scaffolded Chart
  • The default scaffold includes files you may not need (ingress, HPA, ServiceAccount); delete what you don't use: 
    rm myapp/templates/ingress.yaml
rm myapp/templates/serviceaccount.yaml
rm myapp/templates/hpa.yaml
rm -rf myapp/templates/tests/
  • Minimal chart only needs: Chart.yaml, values.yaml, templates/deployment.yaml, templates/service.yaml;
