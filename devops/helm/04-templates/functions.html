Helm Template Functions

1. Syntax
  • Direct call: {{ functionName arg1 arg2 }}
  • Pipeline: {{ arg1 | functionName arg2 }} — arg1 becomes the last argument
  • Helm functions come from three sources: Go built-in, Sprig library, and Helm-specific;

14. Commonly Used Patterns
  • Safe image tag with fallback: 
    image: "{{ .Values.image.repository }}:{{ .Values.image.tag | default .Chart.AppVersion }}"
  • Truncated, DNS-safe name: 
    {{ printf "%s-%s" .Release.Name .Chart.Name | trunc 63 | trimSuffix "-" }}
  • Embed resources block only if defined: 
    {{- with .Values.resources }}
resources:
  {{- toYaml . | nindent 2 }}
{{- end }}
  • Required value (fail fast): 
    image: {{ required "image.repository is required" .Values.image.repository }}
  • Base64-encode a Secret value: 
    data:
  password: {{ .Values.dbPassword | b64enc | quote }}
  • Auto-trigger rollout on ConfigMap change: 
    annotations:
  checksum/config: {{ include (print $.Template.BasePath "/configmap.yaml") . | sha256sum }}
