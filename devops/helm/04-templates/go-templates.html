Go Template Basics

1. Expressions
  • Expression is any piece of code written inside {{ }} braces;
  • Helm evaluates the expression and replaces it with the result, when the template is rendered;
1.1 Expression Types
  • Lookup Expression: It is used to access values from values.yaml file;
  • Eg:
    • Template -> name: {{ .Values.name }}
    • Values.yaml -> appName: myapp
    • Output -> name: myapp
  • Function Expression: It is used to call functions;
  • Eg:
    • Template -> name: {{ upper .Values.name }}
    • Values.yaml -> appName: myapp
    • Output -> name: MYAPP
  • Pipeline Expression: It is used to chain multiple expressions together;
  • Eg:
    • Template -> name: {{ .Values.name | upper | quote }}
    • Values.yaml -> appName: myapp
    • Output -> name: "MYAPP"
  • Conditional Expression: It is used to control the flow of the template;
  • Eg:
    • Template -> name: {{ if .Values.name }} {{ .Values.name }} {{ else }} default {{ end }}
    • Values.yaml -> appName: myapp
    • Output -> name: myapp
  • Loop Expression: It is used to iterate over a list or map;
  • Eg:
    • Template -> name: {{ range .Values.name }} {{ . }} {{ end }}
    • Values.yaml -> appName: myapp
    • Output -> name: myapp
  • Variable Expression: It is used to declare variables;
  • Eg:
    • Template -> 
      {{ range .Values.ports }}
                        - containerPort: {{ . }}
                        {{ end }}
    • Values.yaml -> 
      ports:
                        - 80
                        - 443
    • Output -> 
      - containerPort: 80
                        - containerPort: 443
  • Comment Expression: It is used to add comments to the template;
  • Eg:
    • Template -> 
      {{/* This is a comment */}} 
                        name: {{ .Values.name }}
    • Values.yaml -> appName: myapp
    • Output -> name: myapp
  • Whitespace Control Expression:
    • It is used to remove unwanted spaces and newlines;
    • As YAML is indent sensitive, extra spaces and newlines can break the YAML files, so we need to remove them;
    • We can use the following syntax to remove unwanted spaces and newlines:
      • {{- expression -}} -> Removes leading spaces
      • {{ expression -}} -> Removes trailing spaces
      • {{- expression -}} -> Removes both leading and trailing spaces
  • Eg1:
    • Template -> 
      metadata:
                        name: myapp
                      
                      {{- if .Values.enabled }}
                      enabled: true
                      {{ end }}
    • If enabled = true, the blank line before if is removed;
    • If enabled = false, the blank line before if is not removed;
    • Output -> If true: 
      metadata:
                        name: myapp
                      enabled: true

      If false: 
      metadata:
                        name: myapp
  • Eg2:
    • Template -> 
      labels:
                        {{ toYaml .Values.labels }}
    • Values.yaml -> 
      labels:
                            app: myapp
                            tier: backend
    • Output -> 
      labels:
app: myapp
tier: backend
    • Correct Template -> labels: {{- toYaml .Values.labels | nindent 2 }}
    • Output -> 
      labels:
  app: myapp
  tier: backend
  • Template Action Expression: It is used to call template actions;
  • Eg:
    • Template -> name: {{ template "mychart.fullname" . }}
    • Values.yaml -> appName: myapp
    • Output -> name: myapp
2. Template Action
  • Rather than returning a value, it performs an operation that controls template behaviour;
  • It includes:
    • variable assignment
    • conditional logic
    • loops
    • invoking functions
2. Template Action Types
  • Variable action
    • It is used to assign value from expression to a variable;
    • Why is it useful? -> it simplifies code and avoids running same expression multiple times;
    • Syntax: 
      {{ $variable := expression }}
    • Eg: 
      {{ $name := .Values.name }}
    • Output: 
      {{ $name }}
  • Conditional action
    • It is used to control the flow of the template based on condition;
    • Syntax: 
      {{ if expression }} action {{ end }}
    • Eg: 
      {{ if .Values.name }} {{ .Values.name }} {{ else }} default {{ end }}
    • Eg2: 
      {{ if .Values.enabled }}
enabled: true
{{ end }}
  • Loop action
    • It is used to iterate over a list or map;
    • Syntax: 
      {{ range expression }} action {{ end }}
    • Eg: 
      {{ range .Values.ports }}
                        - containerPort: {{ . }}
                        {{ end }}
  • Function action
    • It is used to invoke a function;
    • Syntax: 
      {{ range expression }} action {{ end }}
    • Eg: 
      {{ range .Values.name }} {{ . }} {{ end }}
    • Output: 
      {{ range .Values.name }} {{ . }} {{ end }}
3. Expression vs Action
  • Expression returns a value;
  • Action does something and doesn't return anything;
5. Functions in Helm Templates
  • Helm provides over 60 functions;
  • Syntax: function arg1 arg2...
  • Eg: quote .Values.favorite.drink
6. Pipelines
  • Pipelines chain functions together, passing each result to the next function;
  • Eg: {{ cat .Chart.Name "Container" | snakecase | lower }}
7. Variables and Scope
  • Variables are used to store values;
  • Syntax: {{ $variable := expression }}
  • Eg: {{ $name := .Values.name }}
  • Output: {{ $name }}
8. Pipelines and Chaining
  • Pipelines chain functions together, passing each result to the next function;
  • Eg: {{ cat .Chart.Name "Container" | snakecase | lower }}
9. Template Helpers and Reusable Templates
  • Template helpers are used to reuse template code;
  • Syntax: {{ define "name" }} action {{ end }}
  • Eg: {{ define "mychart.fullname" }} {{ .Release.Name }}-{{ .Chart.Name }} {{ end }}
  • Output: {{ define "mychart.fullname" }} {{ .Release.Name }}-{{ .Chart.Name }} {{ end }}
10. Working with Files
  • It is used to access files in the chart;
  • Syntax: 
    {{ .Files.Get "filename" }}
  • Eg: 
    {{ .Files.Get "filename" }}
  • Output: 
    {{ .Files.Get "filename" }}
11. Template Flow and Debugging
  • It is used to control the flow of the template;
  • Syntax: 
    {{ . }}
  • Eg: 
    {{ . }}
  • Output: 
    {{ . }}
