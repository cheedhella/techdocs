Built-in Objects

1. Overview
  • Built-in Objects are the objects that are passed to every template by template engine; They are available via the . context;
  • 6 built-in objects: .Values, .Release, .Chart, .Files, .Capabilities, .Template;
2. Built-in Objects
  • Root object
    • Top level helm object;
    • It contains 7 objects: .Release, .Chart, .Values, .Capabilities, .Template, .Files, .Subcharts;
  • .Values
    • It contains all configuration values from values.yaml, -f files, and --set flags (merged, later sources win);
  • .Release
    • It contains information about the current release;
    • Fields:
      • .Release.Name -> Release name
      • .Release.Namespace -> k8s namespace
      • .Release.IsUpgrade -> True if upgrade
      • .Release.IsInstall -> True if install
      • .Release.Revision -> Revision number
  • .Chart
    • Using this, we can access any data from Chart.yaml file;
    • Fields:
      • .Chart.Name -> Chart name
      • .Chart.Version -> Chart version
      • .Chart.AppVersion -> Application version
      • .Chart.Type -> Chart type, application or library
      • .Chart.Description -> Chart description
      • .Chart.Keywords -> Chart keywords
      • .Chart.Home -> Chart home URL
      • .Chart.Maintainers -> List of maintainers
  • .Files
    • It is used to read non-template files in the chart;
    • Fields:
      • .Files.Get -> Get file content as string
      • .Files.Glob -> Match multiple files
      • .Files.Lines -> Read file line by line
    • Eg:
      • Template -> 
        {{ .Files.Get "config/db.conf" | indent 4 }}
      • Values.yaml -> 
        data:
                                app.conf: |
                                {{ .Files.Get "config/app.conf" | indent 4 }}
  • .Capabilities
    • It provides information about the k8s cluster capabilities;
    • Fields:
      • .Capabilities.KubeVersion.Version -> k8s version
      • .Capabilities.KubeVersion.Major -> k8s major version
      • .Capabilities.KubeVersion.Minor -> k8s minor version
      • .Capabilities.APIVersions -> Set of k8s API versions
      • .Capabilities.HelmVersion -> Helm version
    • Eg: Check if the cluster supports Ingress API
      • Template -> 
        {{ if .Capabilities.APIVersions.Has "networking.k8s.io/v1/Ingress" }}
                                apiVersion: networking.k8s.io/v1
                                {{ else }}
                                apiVersion: networking.k8s.io/v1beta1
                                {{ end }}
  • .Template
    • It provides information about the current template being executed;
    • Fields:
      • .Template.Name -> file name
      • .Template.BasePath -> Path to templates directory containing this template
1. The Dot (.) — Current Context
  • . (dot) is the current scope/context passed to the template;
  • At the top level of a template, . contains all built-in objects (.Values, .Release, .Chart, etc.);
  • Some actions (with, range) change what . points to inside their block;

        Files Object 
            - It provides access to all non-special files in a chart;
            - We can use it to access files in the charts folder;
            - We can't use it to access templates;
        
        > cat config1.ini 
        msg1 = Hello from config1.ini Line1
        msg2 = Hello from config1.ini Line2
        msg3 = Hello from config1.ini Line3
        
        > cat config-files/myconfig2.toml 
        appName: myapp2
        appType: db 
        appConfigEnable: true 
        
        > cat config-files/myconfig3.toml 
        
        
        {{/* .Files Object Demo */}}
        File Get: {{ .Files.Get "myconfig1.ini" }}          # Prints the content of the file specified 
        File Glob as Config: {{ (.Files.Glob "config-files/*").AsConfig }}           # Returns file body as YAML map
        File Glob as Secret: {{ (.Files.Glob "config-files/*").AsSecrets }}          # Returns file body as base-64 encoded string
        File Lines: {{ .Files.Lines "myconfig1.ini" }}          # It iterates over file content line by line and prints as single line;
        File Glob: {{ .Files.Glob "config-files/*" }}          # It is useful iterate over file content line by line;
