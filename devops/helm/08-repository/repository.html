Helm Repository

1. What is a Helm Repository?
  • It is a simple HTTP server (like Docker Registry, Maven repository) that hosts a collection of packaged charts (.tgz files);
  • It will have an index.yaml file, which contains metadata about all the charts it hosts;
  • You can use it to manage (store, get, list, update, remove) charts;
  • It is used to share charts with other developers;
  • Helm doesn't come with any repositories added during installation;
2. Popular Public Repositories
helm repo add artifact-hub https://artifacthub.github.io/helm-charts    # Artifact Hub — by far, the biggest helm repository
helm repo add nginx-stable https://helm.nginx.com/stable                # Nginx
helm repo add bitnami https://charts.bitnami.com/bitnami                # Bitnami
3. How to add a repository?
helm repo add <name> <url>
  • It adds the repository to your local Helm CLI configuration (~/.config/helm/repositories.yaml);
  • It does NOT download any charts — only registers the URL;
# ~/.config/helm/repositories.yaml
apiVersion: ""
generated: "2026-02-28T10:12:34.567Z"
repositories:
  - name: bitnami
    url: https://charts.bitnami.com/bitnami
    cache: bitnami-index.yaml
  - name: prometheus-community
    url: https://prometheus-community.github.io/helm-charts
    cache: prometheus-community-index.yaml
4. How to list repositories?
helm repo list
5. How to update a repository?
helm repo update <name>       # Update a specific repository
helm repo update              # Update all repositories
  • It fetches the latest index.yaml for the specified repository and updates the local cache (~/.cache/helm/repository/);
6. What is index.yaml?
  • It is the registry/manifest of a repository — it tells Helm what charts exist, which versions are available, and where to download them;
  • It is cached locally at ~/.cache/helm/repository/<repo-name>-index.yaml;
  • helm search uses this file to find charts;
# ~/.cache/helm/repository/bitnami-index.yaml
apiVersion: v1
generated: "2026-02-28T10:45:00Z"
entries:
  nginx:
    - version: 15.2.3
      appVersion: 1.25.3
      description: NGINX Open Source web server
      urls:
        - https://charts.bitnami.com/bitnami/nginx-15.2.3.tgz
      digest: sha256:abc123xyz456
      created: "2026-02-01T12:00:00Z"

    - version: 15.2.2
      appVersion: 1.25.2
      description: NGINX Open Source web server
      urls:
        - https://charts.bitnami.com/bitnami/nginx-15.2.2.tgz
      digest: sha256:def456uvw789
      created: "2026-01-20T12:00:00Z"

  redis:
    - version: 18.0.0
      appVersion: 7.2.1
      description: Redis in-memory database
      urls:
        - https://charts.bitnami.com/bitnami/redis-18.0.0.tgz
      digest: sha256:xyz789abc123
7. Does helm install download index.yaml if it can't find it?
  • No. helm install does NOT automatically download index.yaml if it's missing or outdated;
  • If index.yaml is missing (i.e., helm repo update was never run), it will throw: Error: chart "nginx" matching not found in bitnami index;

The flow is:

helm repo add       → stores repo URL in repositories.yaml
helm repo update    → downloads index.yaml to local cache
helm search repo    → searches inside cached index.yaml
helm install        → reads index.yaml → downloads the .tgz chart

Exception — installing via direct URL does NOT need index.yaml:

helm install myapp https://charts.bitnami.com/bitnami/nginx-15.2.3.tgz
8. How to remove a repository?
helm repo remove <name>
9. How to search repositories?
helm search repo <keyword>                  # Latest stable version of matching charts
helm search repo <keyword> --devel          # Latest version (incl. alpha/beta/rc)
helm search repo <keyword> --versions       # All versions of matching charts
helm search repo <keyword> --version ^1.0.0 # Charts matching major version 1
10. How to search Artifact Hub?
helm search hub <keyword>              # Search Artifact Hub
helm search hub <keyword> --versions   # With all versions
11. Packaging a Chart
helm package ./mychart                     # Creates mychart-0.1.0.tgz in current directory
helm package ./mychart -d /path/to/repo/   # Package and place in a specific directory
12. Generating index.yaml
helm repo index <dir>
  • Every repository must have a valid index.yaml;
  • This command reads the given directory and generates an index.yaml with metadata for all the charts found;
  • Useful when setting up your own repository;
13. Creating & Hosting a Local Repository

Step 1: Create a directory for the repository

mkdir testrepo && cd testrepo

Step 2: Generate an initial index.yaml

helm repo index .

Step 3: Package a chart into the repository directory

helm package ../firstchart -d .
# Successfully packaged chart and saved it to: ./firstchart-0.1.0.tgz

Step 4: Regenerate index.yaml to include the new chart

helm repo index .

Step 5: Host it using a simple HTTP server

python3 -m http.server --bind 127.0.0.1 8080

Step 6: Add and use the local repository

helm repo add localrepo http://127.0.0.1:8080
helm repo update localrepo

# Install from local repo
helm install mylocal01 localrepo/firstchart

# Or download first, then install
helm pull localrepo/firstchart
helm install mylocal02 firstchart*.tgz
14. Publishing Charts to a Remote Repository
  • For traditional HTTP repositories (e.g., GitHub Pages, ChartMuseum, Nexus), you upload the .tgz file and regenerate index.yaml;
  • For OCI registries (e.g., Docker Hub, AWS ECR, GCR), use helm push — see the OCI Registry page;

Example using GitHub Pages:

# Package the chart
helm package ./mychart

# Copy .tgz into your gh-pages branch directory
cp mychart-0.1.0.tgz /path/to/gh-pages-repo/

# Regenerate index.yaml (--url specifies the public URL)
helm repo index /path/to/gh-pages-repo/ --url https://<username>.github.io/<repo>

# Commit and push the gh-pages branch
cd /path/to/gh-pages-repo/
git add . && git commit -m "Add mychart 0.1.0" && git push
15. Quick Reference
helm repo add <name> <url>           # Add a repository
helm repo list                       # List all configured repositories
helm repo update <name>              # Fetch latest index.yaml for a repository
helm repo update                     # Fetch latest index.yaml for all repositories
helm repo remove <name>              # Remove a repository
helm repo index <dir>                # Generate index.yaml for a chart directory

helm search repo <keyword>           # Search across configured repositories
helm search hub <keyword>            # Search Artifact Hub

helm package ./mychart               # Package a chart into a .tgz
helm push mychart-1.0.0.tgz <repo>  # Push to OCI registry (see OCI Registry page)
