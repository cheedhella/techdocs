1. What is a Helm Repository?
  • It is a artifact server(like Docker Registry, maven repository) which hosts a collection of charts/packages;
  • You can use it manage(store, get, list, update, remove) charts;
  • It is also used to share charts with others;
  • Helm doesn't come with any repositories added, during installation;
  • Artifact Hub -> helm repo add artifact-hub https://artifacthub.github.io/helm-charts # By far, the biggest helm repository;
  • Nginx -> helm repo add nginx-stable https://helm.nginx.com/stable
  • Bitnami -> helm repo add bitnami https://charts.bitnami.com/bitnami
2. How to add a repository?
  • helm repo add <name> <url> # Add a repository
  • It adds the repository to your local helm CLI configuration(~/.config/helm/repositories.yaml);
  • It doesn't download any charts from the repository;
  •  
    apiVersion: ""
    generated: "2026-02-28T10:12:34.567Z"
    repositories:
      - name: bitnami
        url: https://charts.bitnami.com/bitnami
        cache: bitnami-index.yaml
      - name: prometheus-community
        url: https://prometheus-community.github.io/helm-charts
        cache: prometheus-community-index.yaml
3. How to list repositories?
helm repo list
4. How to update a repository?
  • helm repo update <name> # Update a repository
  • helm repo update # Update all repositories
  • It fetches latest index.yaml for the specified repository and updates cache(~/.cache/helm/repository/, which is used by search);
    • index.yaml - It is registry of the repository, it tells helm what charts exist, which versions are available, and where to download them;
    • It is used by search to find charts;
  •

does helm install downloads index.yaml, if it can't find it? No, it doesn't download index.yaml, it only downloads the chart .tgz file; helm install does NOT automatically download index.yaml if it’s missing or outdated. If it is missing(helm repo update is not run), it will throw an error: Error: chart "nginx" matching not found in bitnami index;
  • helm repo add → stores repo URL
  • helm repo update → downloads index.yaml
  • helm search repo → searches inside index.yaml
  • helm install → reads index.yaml → downloads .tgz
Installing via Direct URL If you install like this: helm install myapp https://charts.bitnami.com/bitnami/nginx-15.2.3.tgz Then:
  • Helm does NOT need index.yaml
  • It directly downloads that .tgz
OCI Registry If using OCI (e.g., container registry): helm install myapp oci://registry-1.docker.io/bitnamicharts/nginx Helm does NOT use index.yaml at all. OCI uses registry APIs instead. What is Repository? It is a artifact server which hosts a collection of charts/packages; It allows developers to share their charts with other other developers; You might be thinking that there is a predefined single repository containing every single software package in the world; Unfortunately, that's not the case; If you want a software package, you need find a repository containing it; Helm doesn't come with any repositories added, during installation; Artifact Hub -> helm repo add artifact-hub https://artifacthub.github.io/helm-charts # By far, the biggest helm repository; Nginx -> helm repo add nginx-stable https://helm.nginx.com/stable Bitnami -> helm repo add bitnami https://charts.bitnami.com/bitnami -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- helm repo add <name> <url> # Add repository; It downloads index.yaml of specified repository into local cache directory; HELM_REPOSITORY_CACHE env variable specifies the cache directory; helm repo list # List all configured repositories; helm repo update <name> # It fetches latest index.yaml for the specified repository and updates cache(which is used by search); helm repo update # It fetches latest index.yaml for all repositories added and updates cache; helm repo remove <name> # Delete the repository; helm repo index <dir> # Every repository must have a valid index file; # It reads given directory/repository and generates index file with all the charts found; # It is useful when you are setting up your own repository; -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- helm search repo <keyword> # It scans through all repositories configured in the system and prints latest stable version of charts found in them; # helm search repo nginx -> Returns latest stable version of each chart whose name matches 'nginx' # helm search repo nginx --devel -> Returns latest version(could be stable/alpha/beta/release candidate etc) of each chart whose name matches 'nginx' # helm search repo nginx --versions -> Returns all versions(could be stable/alpha/beta/release candidate etc) of each chart whose name matches 'nginx' # helm search repo nginx --version ^1.0.0 -> Returns all stable charts whose name matche nginx and major version of 1 -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- Repository - It is a simple http server, from which we can download the charts;
