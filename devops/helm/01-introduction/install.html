Installing Helm

1. Installing Helm

Option A — Package Managers (Recommended)

# macOS
brew install helm

# RHEL / CentOS / Fedora (dnf or yum)
sudo dnf install helm

# Debian / Ubuntu
sudo apt-get install helm

If Helm isn't in your default repos, add the official Helm repository first:

# RHEL / CentOS / Fedora
curl https://baltocdn.com/helm/signing.asc | gpg --dearmor | sudo tee /usr/share/keyrings/helm.gpg > /dev/null
sudo dnf config-manager --add-repo https://baltocdn.com/helm/stable/rpm/
sudo rpm --import https://baltocdn.com/helm/signing.asc
sudo dnf install helm

# Debian / Ubuntu
curl https://baltocdn.com/helm/signing.asc | gpg --dearmor | sudo tee /usr/share/keyrings/helm.gpg > /dev/null
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/helm.gpg] https://baltocdn.com/helm/stable/debian/ all main" \
  | sudo tee /etc/apt/sources.list.d/helm-stable-debian.list
sudo apt-get update
sudo apt-get install helm

Option B — One-line Install Script (Linux / macOS)

curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
  • Detects your OS and architecture automatically;
  • Downloads the latest Helm binary;
  • Installs it to /usr/local/bin/helm;

Option C — Manual Binary Download

# Download from https://github.com/helm/helm/releases (example: Linux AMD64)
wget https://get.helm.sh/helm-v3.14.0-linux-amd64.tar.gz
tar -zxvf helm-v3.14.0-linux-amd64.tar.gz
sudo mv linux-amd64/helm /usr/local/bin/helm

Verify:

# Check Helm version
helm version
# version.BuildInfo{Version:"v3.14.0", GitCommit:"...", GitTreeState:"clean", GoVersion:"go1.21.5"}

# Check cluster connectivity
helm list
# NAME    NAMESPACE    REVISION    UPDATED    STATUS    CHART    APP VERSION
3. Test Your Installation

Step 1 — Helm binary is working:

helm version
# Should print version info; if "command not found", check your PATH

Step 2 — Cluster is reachable:

# Confirm kubectl can reach the cluster first
kubectl cluster-info
kubectl get nodes

# Helm uses the same kubeconfig — if kubectl works, Helm will too
helm list
# Empty output is fine; an error means the cluster is unreachable

Step 3 — Correct context and namespace:

# Verify you're targeting the right cluster (critical in production)
kubectl config current-context

# Check which namespace Helm will deploy to
kubectl config view --minify -o jsonpath='{.contexts[0].context.namespace}'
# Empty means "default" namespace

Step 4 — RBAC permissions are sufficient:

# Can you create deployments? (what Helm needs to install charts)
kubectl auth can-i create deployments
kubectl auth can-i create services
kubectl auth can-i create secrets

# All should return "yes"; if not, your role/rolebinding needs updating

Step 5 — Repositories are accessible:

# Add a repo and update index
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update

# Search to confirm it works
helm search repo bitnami/nginx

Step 6 — End-to-end dry run (safe for production):

# Render templates without deploying — verifies the full pipeline
helm install test-nginx bitnami/nginx --dry-run --debug

# If this succeeds, Helm can: reach the repo, pull the chart,
# render templates, and validate against the cluster API

Step 7 — Full install/uninstall cycle (non-production only):

# Deploy a test release
helm install test-nginx bitnami/nginx --namespace default

# Verify resources are created
helm list
kubectl get pods -l app.kubernetes.io/instance=test-nginx

# Clean up
helm uninstall test-nginx
3. Installing Helm in CI/CD

Jenkins:

stage('Install Helm') {
    steps {
        sh 'curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash'
        sh 'helm version'
    }
}
4. Initial Configuration

Add Popular Chart Repositories:

# Add Bitnami repository (most popular)
helm repo add bitnami https://charts.bitnami.com/bitnami

# Add Stable repository
helm repo add stable https://charts.helm.sh/stable

# Update repository index
helm repo update

# List repositories
helm repo list

# Search for charts
helm search repo nginx
5. Helm Plugins (Optional)

Extend Helm functionality with plugins:

# Install helm-diff (compare releases)
helm plugin install https://github.com/databus23/helm-diff

# Install helm-secrets (manage secrets)
helm plugin install https://github.com/jkroepke/helm-secrets

# List installed plugins
helm plugin list

# Use a plugin
helm diff upgrade myapp ./chart
