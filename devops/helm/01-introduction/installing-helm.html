Installing Helm

1. Prerequisites
  • A Kubernetes cluster (local or remote);
  • kubectl installed and configured;
  • Access to the cluster with appropriate RBAC permissions;
2. Installation Methods

📦 Using Package Managers (Recommended)

macOS (Homebrew):

brew install helm

Linux (Snap):

sudo snap install helm --classic

Windows (Chocolatey):

choco install kubernetes-helm

Windows (Scoop):

scoop install helm
3. Installation via Script (All Platforms)

Linux/macOS:

curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

This script will:

  • Detect your OS and architecture;
  • Download the latest Helm binary;
  • Install it to /usr/local/bin/helm;
4. Manual Installation (Binary Download)

Step 1: Download from GitHub Releases

# Example for Linux AMD64
wget https://get.helm.sh/helm-v3.14.0-linux-amd64.tar.gz
tar -zxvf helm-v3.14.0-linux-amd64.tar.gz
sudo mv linux-amd64/helm /usr/local/bin/helm

Step 2: Verify installation

helm version
5. Verify Installation
# Check Helm version
helm version

# Expected output:
version.BuildInfo{Version:"v3.14.0", GitCommit:"...", GitTreeState:"clean", GoVersion:"go1.21.5"}

# Check if Helm can connect to your cluster
helm list

# If no releases yet, you'll see:
NAME    NAMESPACE       REVISION        UPDATED STATUS  CHART   APP VERSION
6. Initial Configuration

Add Popular Chart Repositories:

# Add Bitnami repository (most popular)
helm repo add bitnami https://charts.bitnami.com/bitnami

# Add Stable repository
helm repo add stable https://charts.helm.sh/stable

# Update repository index
helm repo update

# List repositories
helm repo list

# Search for charts
helm search repo nginx
7. Test Your Installation

Create a test chart:

# Create a new chart
helm create mychart

# View the chart structure
tree mychart

# Install the chart
helm install test-release ./mychart

# Check the release
helm list

# View deployed resources
kubectl get all -l app.kubernetes.io/instance=test-release

# Uninstall
helm uninstall test-release
8. Upgrading Helm

Using package managers:

# macOS
brew upgrade helm

# Linux (Snap)
sudo snap refresh helm

# Windows (Chocolatey)
choco upgrade kubernetes-helm

Manual upgrade:

# Download new version and replace binary
wget https://get.helm.sh/helm-v3.15.0-linux-amd64.tar.gz
tar -zxvf helm-v3.15.0-linux-amd64.tar.gz
sudo mv linux-amd64/helm /usr/local/bin/helm

# Verify new version
helm version
9. Installing Helm in CI/CD

GitHub Actions:

- name: Install Helm
  uses: azure/setup-helm@v3
  with:
    version: 'v3.14.0'

GitLab CI:

before_script:
  - curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash
  - helm version

Jenkins:

stage('Install Helm') {
    steps {
        sh 'curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash'
        sh 'helm version'
    }
}
10. Troubleshooting Installation

Issue: helm: command not found

  • Ensure /usr/local/bin is in your PATH;
  • Try: export PATH=$PATH:/usr/local/bin;
  • Add to ~/.bashrc or ~/.zshrc for persistence;

Issue: Kubernetes cluster unreachable

  • Verify kubectl works: kubectl get nodes;
  • Check kubeconfig: kubectl config view;
  • Helm uses the same config as kubectl;

Issue: Permission denied

  • Use sudo when moving to /usr/local/bin;
  • Or install to user directory: ~/bin/helm;
11. Helm Plugins (Optional)

Extend Helm functionality with plugins:

# Install helm-diff (compare releases)
helm plugin install https://github.com/databus23/helm-diff

# Install helm-secrets (manage secrets)
helm plugin install https://github.com/jkroepke/helm-secrets

# List installed plugins
helm plugin list

# Use a plugin
helm diff upgrade myapp ./chart
