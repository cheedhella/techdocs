Control Structures (if, with, range)

1. Overview

Helm uses Go template language control structures to add logic to templates:

  • if/else: Conditional rendering of content;
  • with: Scope control and nil checking;
  • range: Iteration over lists and maps;
2. if/else Statements

Basic if:

{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ .Release.Name }}-ingress
{{- end }}

if/else:

apiVersion: v1
kind: Service
spec:
  type: {{ if .Values.service.type }}{{ .Values.service.type }}{{ else }}ClusterIP{{ end }}

if/else if/else:

env:
- name: ENVIRONMENT
  value: {{ if eq .Values.environment "production" }}"prod"{{ else if eq .Values.environment "staging" }}"stage"{{ else }}"dev"{{ end }}

Negation with not:

{{- if not .Values.autoscaling.enabled }}
replicas: {{ .Values.replicaCount }}
{{- end }}

4. with Statement

The with statement changes scope and checks for nil/empty values:

{{- with .Values.database }}
env:
- name: DB_HOST
  value: {{ .host }}
- name: DB_PORT
  value: {{ .port | quote }}
- name: DB_NAME
  value: {{ .name }}
{{- end }}

With else:

{{- with .Values.database }}
# Database configured
host: {{ .host }}
{{- else }}
# Using default database
host: localhost
{{- end }}

Important: Inside with, . refers to the scoped value, not the root. Use $ to access root:

{{- with .Values.database }}
env:
- name: DB_HOST
  value: {{ .host }}
- name: RELEASE_NAME
  value: {{ $.Release.Name }}  # $ accesses root scope
{{- end }}
5. range - Iterating Over Lists

values.yaml:

environments:
  - dev
  - staging
  - production

Template:

{{- range .Values.environments }}
- name: {{ . }}
{{- end }}

# Output:
- name: dev
- name: staging
- name: production

With index and value:

{{- range $index, $env := .Values.environments }}
- name: env-{{ $index }}
  value: {{ $env }}
{{- end }}
6. range - Iterating Over Maps

values.yaml:

env:
  DATABASE_URL: postgres://db:5432/mydb
  REDIS_URL: redis://redis:6379
  API_KEY: secret123

Template:

env:
{{- range $key, $value := .Values.env }}
- name: {{ $key }}
  value: {{ $value | quote }}
{{- end }}

# Output:
env:
- name: DATABASE_URL
  value: "postgres://db:5432/mydb"
- name: REDIS_URL
  value: "redis://redis:6379"
- name: API_KEY
  value: "secret123"
7. Complex Example: Conditional Ingress
{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ .Release.Name }}-ingress
  {{- with .Values.ingress.annotations }}
  annotations:
    {{- range $key, $value := . }}
    {{ $key }}: {{ $value | quote }}
    {{- end }}
  {{- end }}
spec:
  {{- if .Values.ingress.className }}
  ingressClassName: {{ .Values.ingress.className }}
  {{- end }}
  rules:
  {{- range .Values.ingress.hosts }}
  - host: {{ .host | quote }}
    http:
      paths:
      {{- range .paths }}
      - path: {{ .path }}
        pathType: {{ .pathType }}
        backend:
          service:
            name: {{ $.Release.Name }}-service
            port:
              number: {{ $.Values.service.port }}
      {{- end }}
  {{- end }}
  {{- if .Values.ingress.tls }}
  tls:
  {{- range .Values.ingress.tls }}
  - hosts:
    {{- range .hosts }}
    - {{ . | quote }}
    {{- end }}
    secretName: {{ .secretName }}
  {{- end }}
  {{- end }}
{{- end }}
8. Whitespace Control

Use {{- and -}} to control whitespace:

# Without whitespace control:
{{ if .Values.enabled }}
enabled: true
{{ end }}

# Output has extra blank lines

# With whitespace control:
{{- if .Values.enabled }}
enabled: true
{{- end }}

# Output is compact
9. Combining Control Structures
{{- if .Values.resources }}
resources:
  {{- if .Values.resources.limits }}
  limits:
    {{- with .Values.resources.limits }}
    {{- if .cpu }}
    cpu: {{ .cpu }}
    {{- end }}
    {{- if .memory }}
    memory: {{ .memory }}
    {{- end }}
    {{- end }}
  {{- end }}
  {{- if .Values.resources.requests }}
  requests:
    {{- with .Values.resources.requests }}
    {{- if .cpu }}
    cpu: {{ .cpu }}
    {{- end }}
    {{- if .memory }}
    memory: {{ .memory }}
    {{- end }}
    {{- end }}
  {{- end }}
{{- end }}
10. Best Practices
  • Use whitespace control: Keep output clean with {{- and -}};
  • Check for nil values: Use with or if before accessing nested values;
  • Use $ for root scope: Inside with or range, use $ to access root;
  • Keep logic simple: Complex logic should be in helpers, not templates;
  • Indent properly: Match Kubernetes YAML indentation;
