Uninstalling Releases

1. Basic Uninstallation
# Uninstall a release
helm uninstall myapp

# Uninstall from specific namespace
helm uninstall myapp --namespace production

# Short form
helm uninstall myapp -n production
2. What Gets Deleted?
  • All Kubernetes resources created by the release (Pods, Services, Deployments, etc.);
  • Release history (Secrets containing release metadata);
  • Hooks (unless they have deletion policies);

What does NOT get deleted:

  • PersistentVolumeClaims (by default, to prevent data loss);
  • Custom Resource Definitions (CRDs);
  • Resources with "helm.sh/resource-policy": "keep" annotation;
3. Uninstall Options
Option Description
--keep-history Keep release history for rollback
--dry-run Simulate uninstallation
--no-hooks Skip running uninstall hooks
--timeout Time to wait for deletion (default: 5m)
--wait Wait for all resources to be deleted
4. Keeping Release History
# Uninstall but keep history (allows reinstall with same name)
helm uninstall myapp --keep-history

# View uninstalled releases
helm list --uninstalled

# Rollback an uninstalled release (reinstalls it)
helm rollback myapp 3
5. Dry Run Uninstall
# See what would be deleted without actually deleting
helm uninstall myapp --dry-run

# Output shows:
# - Release name
# - Resources that would be deleted
# - Any hooks that would run
6. Preserving Resources

Use resource-policy annotation to keep specific resources:

# In your template (e.g., pvc.yaml)
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: myapp-data
  annotations:
    "helm.sh/resource-policy": "keep"
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 10Gi

This PVC will NOT be deleted when the release is uninstalled.

7. Uninstalling Multiple Releases
# Uninstall multiple releases
helm uninstall app1 app2 app3

# Uninstall all releases in a namespace (be careful!)
helm list -n staging --short | xargs -L1 helm uninstall -n staging

# Uninstall releases matching pattern
helm list --filter '^test-' --short | xargs -L1 helm uninstall
8. Cleaning Up After Uninstall
# Check for remaining resources
kubectl get all -l app.kubernetes.io/instance=myapp

# Delete PVCs if needed
kubectl get pvc -l app.kubernetes.io/instance=myapp
kubectl delete pvc myapp-data

# Check for remaining secrets
kubectl get secrets -l app.kubernetes.io/instance=myapp

# Check for remaining configmaps
kubectl get configmaps -l app.kubernetes.io/instance=myapp
9. Uninstall Hooks

Hooks can run during uninstallation:

apiVersion: batch/v1
kind: Job
metadata:
  name: myapp-cleanup
  annotations:
    "helm.sh/hook": pre-delete
    "helm.sh/hook-weight": "0"
    "helm.sh/hook-delete-policy": hook-succeeded
spec:
  template:
    spec:
      containers:
      - name: cleanup
        image: busybox
        command: ['sh', '-c', 'echo Cleaning up...']
      restartPolicy: Never
10. Troubleshooting Uninstallation

Issue: Uninstall hangs

# Check for finalizers blocking deletion
kubectl get all -n <namespace> -o json | jq '.items[] | select(.metadata.finalizers != null) | {kind: .kind, name: .metadata.name, finalizers: .metadata.finalizers}'

# Remove finalizers if necessary (careful!)
kubectl patch <resource> <name> -p '{"metadata":{"finalizers":[]}}' --type=merge

Issue: Resources remain after uninstall

# Find resources by label
kubectl get all -l app.kubernetes.io/instance=myapp -A

# Manually delete if needed
kubectl delete all -l app.kubernetes.io/instance=myapp -n <namespace>

Issue: Cannot reinstall with same name

# If release history exists
helm list --uninstalled

# Delete release history
helm delete myapp --purge  # Helm v2
# Or in Helm v3, uninstall without --keep-history removes history
11. Best Practices
  • Dry run first: Always use --dry-run in production;
  • Backup data: Export PVC data before uninstalling;
  • Use resource-policy: Annotate important resources to keep them;
  • Check dependencies: Ensure no other apps depend on this release;
  • Verify cleanup: Check for remaining resources after uninstall;
  • Document process: Keep runbooks for uninstalling complex applications;
