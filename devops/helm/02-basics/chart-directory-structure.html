Chart Directory Structure

1. Complete Chart Structure
mychart/
├── Chart.yaml              # Chart metadata
├── Chart.lock              # Dependency lock file (auto-generated)
├── values.yaml             # Default configuration values
├── values.schema.json      # JSON schema for values validation (optional)
├── README.md               # Chart documentation
├── LICENSE                 # Chart license
├── .helmignore            # Files to ignore when packaging
├── charts/                 # Dependent charts directory
│   └── mysql-9.3.4.tgz    # Downloaded dependency
├── crds/                   # Custom Resource Definitions
│   └── mycrd.yaml
└── templates/              # Kubernetes manifest templates
    ├── NOTES.txt          # Post-install notes
    ├── _helpers.tpl       # Template helpers
    ├── deployment.yaml
    ├── service.yaml
    ├── ingress.yaml
    ├── configmap.yaml
    ├── secret.yaml
    ├── serviceaccount.yaml
    ├── hpa.yaml
    └── tests/             # Test files
        └── test-connection.yaml
2. Chart.yaml - Chart Metadata

The main descriptor file for a chart:

apiVersion: v2                    # Chart API version (v2 for Helm 3)
name: myapp                       # Chart name
version: 1.0.0                    # Chart version (SemVer)
appVersion: "2.1.0"              # Version of the app being deployed
description: A Helm chart for my application
type: application                 # application or library
keywords:
  - web
  - backend
home: https://myapp.example.com
sources:
  - https://github.com/myorg/myapp
maintainers:
  - name: John Doe
    email: john@example.com
icon: https://example.com/icon.png
deprecated: false                 # Mark chart as deprecated
kubeVersion: ">=1.20.0"          # Compatible Kubernetes versions
dependencies:                     # Chart dependencies
  - name: mysql
    version: "9.3.4"
    repository: https://charts.bitnami.com/bitnami
3. values.yaml - Default Configuration

Defines default values for templates:

replicaCount: 2

image:
  repository: nginx
  tag: "1.21"
  pullPolicy: IfNotPresent

service:
  type: ClusterIP
  port: 80

ingress:
  enabled: false
  className: nginx
  hosts:
    - host: myapp.example.com
      paths:
        - path: /
          pathType: Prefix

resources:
  limits:
    cpu: 500m
    memory: 512Mi
  requests:
    cpu: 250m
    memory: 256Mi

autoscaling:
  enabled: false
  minReplicas: 2
  maxReplicas: 10
  targetCPUUtilizationPercentage: 80
4. templates/ Directory

Purpose: Contains Kubernetes manifest templates that are rendered with values;

Common template files:

  • deployment.yaml - Deployment configuration;
  • service.yaml - Service configuration;
  • ingress.yaml - Ingress rules;
  • configmap.yaml - Configuration data;
  • secret.yaml - Sensitive data;
  • serviceaccount.yaml - Service account;
  • hpa.yaml - Horizontal Pod Autoscaler;
  • _helpers.tpl - Template helper functions;
  • NOTES.txt - Post-installation notes;
5. _helpers.tpl - Template Helpers

Defines reusable template snippets:

{{/*
Expand the name of the chart.
*/}}
{{- define "mychart.name" -}}
{{- default .Chart.Name .Values.nameOverride | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Create a default fully qualified app name.
*/}}
{{- define "mychart.fullname" -}}
{{- if .Values.fullnameOverride }}
{{- .Values.fullnameOverride | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- $name := default .Chart.Name .Values.nameOverride }}
{{- printf "%s-%s" .Release.Name $name | trunc 63 | trimSuffix "-" }}
{{- end }}
{{- end }}

{{/*
Common labels
*/}}
{{- define "mychart.labels" -}}
helm.sh/chart: {{ .Chart.Name }}-{{ .Chart.Version }}
app.kubernetes.io/name: {{ include "mychart.name" . }}
app.kubernetes.io/instance: {{ .Release.Name }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
{{- end }}
6. NOTES.txt - Post-Install Instructions

Displayed after installation/upgrade:

Thank you for installing {{ .Chart.Name }}!

Your release is named {{ .Release.Name }}.

To access your application:

{{- if .Values.ingress.enabled }}
  http://{{ index .Values.ingress.hosts 0 "host" }}
{{- else }}
  export POD_NAME=$(kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "mychart.name" . }}" -o jsonpath="{.items[0].metadata.name}")
  kubectl port-forward $POD_NAME 8080:80
  echo "Visit http://127.0.0.1:8080"
{{- end }}

For more information, visit: https://github.com/myorg/myapp
7. charts/ Directory - Dependencies
  • Contains dependent charts (subcharts);
  • Can be manually placed or downloaded via helm dependency update;
  • Each dependency is a .tgz file or unpacked directory;
charts/
├── mysql-9.3.4.tgz
└── redis-17.3.7.tgz
8. crds/ Directory - Custom Resource Definitions
  • Contains CRD YAML files;
  • CRDs are installed before any other resources;
  • CRDs are never upgraded or deleted by Helm;
  • Must be managed manually if changes are needed;
crds/
└── myresource-crd.yaml
9. .helmignore - Exclude Files

Specifies files to exclude when packaging:

# Development files
.git/
.gitignore
.DS_Store

# CI/CD
.gitlab-ci.yml
.github/

# Documentation
docs/
*.md
!README.md

# Test files
test/
*.test.yaml

# Temporary files
*.tmp
*.bak
*~
10. Chart.lock - Dependency Lock File

Auto-generated when running helm dependency update:

dependencies:
- name: mysql
  repository: https://charts.bitnami.com/bitnami
  version: 9.3.4
- name: redis
  repository: https://charts.bitnami.com/bitnami
  version: 17.3.7
digest: sha256:abc123...
  • Locks dependency versions for reproducible builds;
  • Should be committed to version control;
11. templates/tests/ - Chart Tests

Contains test pods that validate the installation:

apiVersion: v1
kind: Pod
metadata:
  name: "{{ include "mychart.fullname" . }}-test-connection"
  annotations:
    "helm.sh/hook": test
spec:
  containers:
    - name: wget
      image: busybox
      command: ['wget']
      args: ['{{ include "mychart.fullname" . }}:{{ .Values.service.port }}']
  restartPolicy: Never

Run tests with: helm test <release-name>

helm create mychart
