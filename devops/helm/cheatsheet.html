Helm CLI Quick Reference

1. Release Management
CommandDescription
helm install <name> <chart>Install a chart as a new release
helm install <name> <chart> -n <ns> --create-namespaceInstall into a specific namespace, create it if missing
helm install <name> <chart> -f values.yamlInstall with a custom values file
helm install <name> <chart> --set key=valInstall with inline value overrides
helm install <name> <chart> --dry-run --debugSimulate an install without deploying (preview rendered YAML)
helm upgrade <name> <chart>Upgrade an existing release to a new chart version or values
helm upgrade --install <name> <chart>Upgrade if exists, install if not (idempotent — great for CI/CD)
helm upgrade <name> <chart> --reuse-valuesUpgrade keeping previously set values
helm rollback <name> <revision>Roll back a release to a specific revision
helm uninstall <name>Delete a release and all its resources
helm uninstall <name> --keep-historyDelete resources but keep release history for auditing
2. Inspecting Releases
CommandDescription
helm listList all releases in the current namespace
helm list --all-namespacesList releases across all namespaces
helm list --filter <regex>Filter releases by name pattern
helm status <name>Show status of a release (deployed resources, notes)
helm history <name>Show revision history of a release
helm get values <name>Show user-supplied values for a release
helm get values <name> --allShow all values (defaults + overrides) for a release
helm get values <name> --revision <n>Show values from a specific revision
helm get manifest <name>Show the rendered Kubernetes YAML for a release
helm get notes <name>Show post-install notes for a release
helm get all <name>Show all information (values, manifest, notes, hooks)
3. Chart Repositories
CommandDescription
helm repo add <name> <url>Add a repository
helm repo updateRefresh local cache of all repository indexes
helm repo listList configured repositories
helm repo remove <name>Remove a repository
helm search repo <keyword>Search charts across all added repos
helm search repo <keyword> --versionsShow all available versions of matching charts
helm search hub <keyword>Search Artifact Hub (public chart registry)
4. Chart Development
CommandDescription
helm create <name>Scaffold a new chart directory with boilerplate files
helm template <name> <chart>Render templates locally without connecting to a cluster
helm template <name> <chart> -f values.yamlRender templates with custom values
helm lint <chart>Check a chart for issues and best-practice violations
helm package <chart>Package a chart directory into a .tgz archive
helm show chart <chart>Display the Chart.yaml metadata
helm show values <chart>Display the default values.yaml of a chart
helm show readme <chart>Display the chart's README
helm show all <chart>Display all chart info (chart + values + readme)
5. Dependencies
CommandDescription
helm dependency list <chart>List dependencies declared in Chart.yaml
helm dependency update <chart>Download and update dependencies into charts/
helm dependency build <chart>Rebuild charts/ from Chart.lock
6. Plugins
CommandDescription
helm plugin listList installed plugins
helm plugin install <url>Install a plugin from a URL or path
helm plugin update <name>Update an installed plugin
helm plugin uninstall <name>Remove a plugin

Popular plugins:

PluginWhat it does
helm-diffPreview changes before helm upgrade
helm-secretsEncrypt/decrypt values files (SOPS integration)
helm-unittestUnit testing for chart templates
helm-s3Use S3 buckets as chart repositories
7. OCI Registries
CommandDescription
helm registry login <host>Authenticate to an OCI registry
helm registry logout <host>Log out from an OCI registry
helm push <chart.tgz> oci://<registry>Push a packaged chart to an OCI registry
helm pull oci://<registry>/<chart> --version <v>Download a chart from an OCI registry
helm install <name> oci://<registry>/<chart>Install directly from an OCI registry
8. Cluster & Environment
Command / FlagDescription
helm envShow Helm environment variables and paths
helm versionShow Helm client version
--kubeconfig <path>Use a specific kubeconfig file
--kube-context <name>Target a specific kubeconfig context
-n <namespace>Target a specific namespace
--debugEnable verbose output for troubleshooting
9. Testing & Debugging
CommandDescription
helm install <name> <chart> --dry-runRender and validate against cluster without deploying
helm template <name> <chart>Render locally (no cluster needed)
helm lint <chart>Static analysis for chart errors and warnings
helm test <name>Run test pods defined in the chart's templates/tests/
helm get manifest <name>See exactly what YAML was applied to the cluster
helm diff upgrade <name> <chart>Preview what will change on upgrade (requires helm-diff plugin)
