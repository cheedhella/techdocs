Why minikube?
	K8s cluster can have 1 or more master nodes and 1 or more worker nodes;
	Master node will have API Server + Scheduler + Control Manager + etcd;
	Worker node will have a set of Pods;
	Each Node(Master or Worker) can be a separate physical machine or virtual machine(such as VirtualBox);
	So, you need to provision lot of infrastructure to setup a k8s cluster; 
	What if you want to set it up on your local? Answer is Minikube;

What is minikube?
	Minikube is a open source tool, which is used to run a single-node k8s cluster, inside a VM(created using a hypervisor such as VirtualBox) on your laptop(can be windows/linux/mac) - both master and worker processes run in that single VM;
	To deploy applications in minikube, you don't need to install docker in it, as minikube VM comes with docker pre-installed;

What is addon?
	It is used to enable features like dashboard, ingress, registry credentials etc;
	You can use addons that are already available or you can customize addons by modifying the associated YAML file;

minikube addons list 						# To list all available addons and to check which addon is enabled/disabled;
minikube addons enable <ADDON_NAME> 		# To enable an add-on;
minikube addons disable <ADDON_NAME> 		# To disable an add-on;

	- minikube start --memory 4096  # This will allocate 4Gb of RAM to minikube

API Server
	- entry point to the cluster; 
	- Clients can use multiple ways to interact with API server - using UI, API, kubectl;


minikube - create/delete the single node k8s cluster;
kubectl - configure the cluster;

start in debug mode -> --v=7 --alsologtostderr 


Kubectl 
	Download -> curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
	Install -> sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl
	Test -> kubectl version --client --output=yaml

Minikube 
	Download -> curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-darwin-amd64
	Install -> sudo install minikube-darwin-amd64 /usr/local/bin/minikube
	Start cluster -> minikube start 
	Interact with cluster 
		UI -> minikube dashboard
		cli -> kubectl get nodes 
	Stop cluster -> minikube stop
	Delete cluster -> minikue delete -all
