kubectl get nodes -o wide                                  # List all nodes in the cluster; Status: Ready, Not Ready, Unreachable; Roles: master, worker; Version: k8s version running on the node;
kubectl describe node <node-name>                          # Detailed information(condition etc) about a node;
kubectl label node key=value                               # Add label to a node  
kubectl get nodes -l environment=production                # Get nodes with given label 
kubectl get nodes --show-labels=true                       # Show labels of nodes 

Node Condition
    Ready   ->  True - Node is healthy and ready to accept pods; False - Node is not healthy and not accepting pods; 
                Unknown - If the node controller has not heard from the node in the last 50 seconds; By default, node controller polls the health of nodes for every 5 seconds;
    DiskPressure -> True, if the disk capacity is low;
    MemoryPressure -> True, if the node memory is low;
    PIDPressure -> True, if there are too many processes on the node;
    NetworkUnavailable -> True, if the network for the node is not correctly configured;
