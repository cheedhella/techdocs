What is kubeadm?
    kubeadm is a tool provided by k8s to setup the k8s cluster quickly;

    > sudo kubeadm init 
        - Initiates key components like API server, controller manager, scheduler and etcd on master node/control plane;
    > sudo kubeadm join <master-ip>:<port> --token <token> --discovery-token-ca-cert-hash sha256:<hash>
        - Used to join the worker nodes to the cluster;
    
AddOn Components 
    CNI plugin 

Ports to unblock:
    Master Node Ports: 2379,6443(API Server),10250(kubelet),10251(Scheduler),10252(Controller)
    Worker Node Ports: 10250, 30000–32767
    Default port range for NodePort Services: 30000–32767
