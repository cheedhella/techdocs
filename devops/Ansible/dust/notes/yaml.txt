YAML stands for Yet Another Markup Language.

Ansible uses YAML syntax to express Ansible playbooks. 
Because compared to other data formats such as XML and JSON, it is very easy for people to understand, read, and write.

Each YAML file optionally starts with "---" and ends with "...".


YAML is a simple language that consists of key-value pairs. While not mandatory, --- marks the beginning of a YAML program, and ... marks the end.


Key-value pair
    Key: A unique identifier for a data item
    Value: The identifiable data or pointer to the location of the data.
    Eg: name: angela mark
    Note: There should be space between the colon(:) and the value.



Eg: It defines the name, address, and gender of a fictionary person (John Doe) in the john variable.
---
john: #variable declared here
  #data defined in following lines:
  name: john doe
  address: new york city
  gender: male
...

Representing a list in YAML
    Each list element must be written on a new line with the same indentation starting with "-" and a space;


Eg #2: YAML also allows the creation of lists. Lists can be created with the - symbol inside variables to define elements.
---
cities: #list declaration

  - newYorkCity: #list element declared here
    #element data defined here:
    name: new york city 
    state: new york

  - losAngeles: #list element declared here
    #element data defined here:
    name: los angeles
    state: california

  - philadelphia: #list element declared here
    #element data defined here:
    name: philadelphia
    state: pennsylvania
...


---  
Angela:

Eg3: In conclusion, to include newline while displaying multiple lines, YAML uses "|", and also ">" to subdue new lines. 
     Because of this, we can read and edit large lines. In both cases, the indent will be ignored.

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Python 3.9.5
      uses: actions/setup-python@v2
      with:
        python-version: 3.7
    - name: Install dependencies
      run:  |  
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    - name: Coverage report
      run:  |
        pip3 install coverage
        coverage run mysite_rebrand/manage.py test
        coverage report

      run:  >
        pip3 install coverage
        coverage run mysite_rebrand/manage.py test
        coverage report
