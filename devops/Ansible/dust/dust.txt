Yaml for deployment into client machine: This has to be run on ansible master
[root@sa666779-rh8vm1 ansible-base]# cat rootusertest.yml
---
- name: Copy springboot applications and start as services
  hosts: all
  become: true
  vars:
    java_package_details: java-17-openjdk
    install_dir: /opt/TS
    application_jar: spring-boot-example-0.0.1-SNAPSHOT-exec.jar
    service_file: springboot.service
  tasks:
  - name: install java
    yum:
      name: "{{ java_package_details }}"
      state: latest
  - name: Create Install Directory in Remote machine
    file:
      path: "{{ install_dir }}"
      state: directory
  - name: Copy springbootapplication to client machine
    copy:
      src: "{{ application_jar  }}"
      dest: "{{ install_dir }}"
  - name: Copy springboot service file to etc folder
    copy:
      src: "{{ service_file }}"
      dest: /etc/systemd/system
  - name: Just force systemd to reread configs (2.4 and above)
    systemd:
      daemon_reload: yes
  - name: Start SpringBoot Application
    service:
      name: springboot
      enabled: yes
      state: started



Needed supporting files:
1) sprinboot application exe or jar.
2) Service configuration file.



Service config file:
[root@sa666779-rh8vm1 ansible-base]# cat springboot.service
[Unit]
Description=Springboot port 8090
After=syslog.target
[Service]
User=root
PermissionsStartOnly=true
ExecStart=/usr/bin/java -jar /opt/TS/spring-boot-example-0.0.1-SNAPSHOT-exec.jar
SuccessExitStatus=143
TimeoutStopSec=10
Restart=on-failure
RestartSec=5
RuntimeDirectoryMode=755

[Install]
WantedBy=multi-user.target





Command to run the ansible playbook with client details mentioned as part of "hosts" file.
--> ansible-playbook -i hosts rootusertest.yml

Could successfully Copy, Deploy and Start Sprintboot application as a service. Hence closing the PoC story.
