Setup Ansible Server or Control Node
    - Install Ansible 
        -- Linux 
            > sudo apt install ansible 
            > ansible --version
        -- Windows
    - Setup SSH Keys -> Ansible uses SSH to connect to remote hosts/nodes and execute commands; Repeat this process for each managed node;
        -- Linux 
            > pwd                   
                /root/.ssh
            > ssh-keygen                        # Generates ~/.ssh/id_rsa (private key), ~/.ssh/id_rsa.pub (public key);
            > cat id_rsa.pub                    # Copy public key!
            > ssh-copy-id root@10.252.21.155    # Copy public key of controlled node to all managed nodes!
            > ssh 10.252.21.155                 # Once public key has been copied to managed host/node, you should be able to connect to it without entering a password;
