Docker Commands

1. System & Info
CommandDescription
docker versionShow Docker client & daemon version
docker infoDisplay system-wide info (storage driver, registry, resources)
docker system dfShow disk usage by images, containers, volumes & build cache
docker system pruneRemove all stopped containers, unused networks, dangling images & build cache
docker system prune -aSame as above but also removes unused images
2. Images
CommandDescription
docker imagesList all locally cached images
docker image lsSame as docker images
docker image ls --filter dangling=trueList dangling (untagged) images
docker pull <image>[:tag]Download an image from a registry (defaults to Docker Hub & latest tag)
docker build -t <name>:<tag> .Build an image from the Dockerfile in the current directory
docker build --no-cache -t <name>:<tag> .Build image without using layer cache
docker build -f <Dockerfile> -t <name>:<tag> .Build using a non-default Dockerfile name
docker tag <src>:<tag> <target>:<tag>Create an additional tag for an existing image
docker image inspect <image>Show detailed metadata (layers, env vars, ports, etc.)
docker history <image>Show build history / layer commands of an image
docker search <keyword>Search Docker Hub for images
docker manifest inspect <image>Inspect a manifest list (multi-arch support check)
docker rmi <image>Remove a local image
docker rmi -f $(docker images -aq)Force-remove ALL local images
docker image pruneRemove all dangling images
docker image prune -aRemove all dangling & unused images
docker save -o <file.tar> <image>Export an image to a tar archive
docker load -i <file.tar>Import an image from a tar archive
3. Containers — Lifecycle
CommandDescription
docker run <image>Pull (if needed) & create + start a new container
docker run -d <image>Run container in detached (background) mode
docker run -it <image> /bin/bashRun interactively with a shell session
docker run --rm <image>Auto-remove container when it exits
docker run --name <name> <image>Assign a custom name to the container
docker run -p <hostPort>:<containerPort> <image>Publish a container port to the host
docker run -v <hostPath>:<containerPath> <image>Bind-mount a host directory into the container
docker run -e KEY=VALUE <image>Set an environment variable inside the container
docker run --env-file <file> <image>Load environment variables from a file
docker run --cpu=.5 --memory=512m <image>Limit CPU & memory resources for the container
docker start <container>Start a stopped container
docker stop <container>Gracefully stop a running container (SIGTERM → 10 s → SIGKILL)
docker kill <container>Forcefully stop a running container (SIGKILL)
docker restart <container>Stop then start a container
docker pause <container>Suspend all processes in a container (SIGSTOP)
docker unpause <container>Resume a paused container
docker rm <container>Remove a stopped container
docker rm -f <container>Force-remove a running container
docker container pruneRemove all stopped containers
docker rename <old> <new>Rename a container
4. Containers — Inspect & Debug
CommandDescription
docker psList running containers
docker ps -aList all containers (running + stopped)
docker ps -qList only container IDs
docker ps --filter status=exitedList only stopped/exited containers
docker inspect <container>Show full low-level JSON details of a container
docker logs <container>Fetch stdout/stderr logs of a container
docker logs -f <container>Follow (tail) live log output
docker logs --tail 50 <container>Show last 50 log lines
docker logs -t -f --tail 10 <container>Follow last 10 lines with timestamps
docker exec -it <container> /bin/bashOpen an interactive shell in a running container
docker exec <container> <cmd>Run a single command in a running container
docker exec --workdir /app <container> <cmd>Run a command in a specific working directory
docker exec -e KEY=VAL <container> envPass extra env vars to an exec session
docker top <container>Display running processes inside a container
docker statsLive stream of CPU / memory / network / I/O for all containers
docker stats <container>Live resource stats for a specific container
docker port <container>List port mappings for a container
docker diff <container>Show filesystem changes since container started
docker cp <container>:<src> <dest>Copy files from a container to the host
docker cp <src> <container>:<dest>Copy files from the host into a container
docker attach <container>Attach terminal to a running container's STDIN/STDOUT (Ctrl+P Q to detach)
docker commit <container> <image>:<tag>Create a new image from a container's current state
docker export -o <file.tar> <container>Export a container's filesystem as a tar archive
5. Registry
CommandDescription
docker loginLog in to Docker Hub
docker login -u <user> -p <token> <registry>Log in to a private registry
docker logoutLog out from a registry
docker push <user>/<repo>:<tag>Push a tagged image to a registry
docker pull <user>/<repo>:<tag>Pull an image from a registry
docker search <term> --filter "is-official=true"Search Docker Hub for official images only
docker search <term> --filter "stars=50"Search images with 50+ stars
6. Volumes
CommandDescription
docker volume lsList all volumes
docker volume create <name>Create a named volume
docker volume inspect <name>Show details of a volume
docker volume rm <name>Remove a volume
docker volume pruneRemove all unused volumes
docker run -v <vol>:<path> <image>Mount a named volume into a container
docker run -v <hostPath>:<containerPath> <image>Bind-mount a host directory into a container
7. Networking
CommandDescription
docker network lsList all networks
docker network create <name>Create a new bridge network
docker network inspect <name>Show details of a network (subnet, connected containers)
docker network connect <net> <container>Connect a running container to a network
docker network disconnect <net> <container>Disconnect a container from a network
docker network rm <name>Remove a network
docker network pruneRemove all unused networks
docker run --network <name> <image>Connect a new container to a specific network
8. Context
CommandDescription
docker context lsList all configured Docker contexts (* = active)
docker context use <name>Switch to a different Docker context
docker context create <name> --docker host=tcp://<host>:2375Create a new remote TCP context
docker context create <name> --docker host=ssh://<host>Create a new remote SSH context
docker context rm <name>Remove a context
9. Docker Compose
CommandDescription
docker compose upCreate and start all services defined in docker-compose.yml
docker compose up -dStart services in detached mode
docker compose up --buildRebuild images before starting services
docker compose downStop and remove containers, networks
docker compose down -vAlso remove named volumes
docker compose psList containers managed by Compose
docker compose logs -fFollow logs from all services
docker compose exec <service> /bin/bashOpen a shell in a running service container
docker compose buildBuild or rebuild service images
docker compose pullPull latest images for all services
docker compose stopStop services without removing containers
docker compose restartRestart all services
