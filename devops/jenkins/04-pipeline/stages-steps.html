Stages and Steps

1. Stages
  • Logical divisions of the pipeline (Build, Test, Deploy);
  • Visualized as columns in the Jenkins Stage View;
  • Each stage contains one or more steps;
2. Steps
  • The actual commands that execute within a stage;
StepDescription
shExecute a shell command (Linux/macOS)
batExecute a batch command (Windows)
echoPrint a message
checkoutCheck out source code from SCM
dirChange to a directory
archiveArtifactsSave build artifacts
junitPublish JUnit test results
stash / unstashShare files between stages/nodes
inputWait for human approval
timeoutSet a time limit for a block
3. Example with Multiple Stages
pipeline {
    agent any
    stages {
        stage('Checkout') {
            steps {
                git branch: 'main', url: 'https://github.com/user/repo.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean package -DskipTests'
            }
        }
        stage('Test') {
            steps {
                sh 'mvn test'
                junit '**/target/surefire-reports/*.xml'
            }
        }
        stage('Archive') {
            steps {
                archiveArtifacts artifacts: 'target/*.jar'
            }
        }
    }
}
