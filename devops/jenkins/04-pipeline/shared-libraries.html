Shared Libraries

1. What are Shared Libraries?
  • Reusable Groovy code stored in a separate Git repository;
  • Avoid duplicating pipeline logic across Jenkinsfiles;
  • Define common functions, stages, and utilities once;
2. Library Structure
shared-library-repo/
  vars/
    buildApp.groovy       # Global functions (called as steps)
    deployApp.groovy
  src/
    org/mycompany/        # Groovy classes
      Utils.groovy
  resources/
    config.json           # Static resources
3. Defining a Shared Step
// vars/buildApp.groovy
def call(String buildTool = 'maven') {
    if (buildTool == 'maven') {
        sh 'mvn clean package'
    } else if (buildTool == 'gradle') {
        sh 'gradle build'
    }
}
4. Using in a Jenkinsfile
@Library('my-shared-lib') _

pipeline {
    agent any
    stages {
        stage('Build') {
            steps {
                buildApp('maven')
            }
        }
        stage('Deploy') {
            steps {
                deployApp('staging')
            }
        }
    }
}
5. Configuration
  • Configure in Manage Jenkins > System > Global Pipeline Libraries;
  • Set the library name, Git repo URL, and default branch;
