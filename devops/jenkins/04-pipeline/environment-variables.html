Environment Variables

1. Built-in Environment Variables
VariableDescription
BUILD_NUMBERCurrent build number
BUILD_URLURL of the current build
JOB_NAMEName of the job
WORKSPACEAbsolute path to the workspace
BRANCH_NAMEBranch being built (multibranch)
GIT_COMMITGit commit SHA
// View all env vars
sh 'printenv | sort'
2. Custom Environment Variables
pipeline {
    agent any
    environment {
        APP_NAME = 'my-app'
        VERSION = '1.0.0'
        DEPLOY_ENV = 'staging'
    }
    stages {
        stage('Build') {
            steps {
                echo "Building ${APP_NAME} v${VERSION}"
            }
        }
    }
}
3. Credentials as Environment Variables
environment {
    DOCKER_CREDS = credentials('docker-hub-creds')
    // Creates: DOCKER_CREDS_USR and DOCKER_CREDS_PSW
}
steps {
    sh 'docker login -u $DOCKER_CREDS_USR -p $DOCKER_CREDS_PSW'
}
4. Stage-Level Environment
stage('Deploy') {
    environment {
        DEPLOY_TARGET = 'production'
    }
    steps {
        echo "Deploying to ${DEPLOY_TARGET}"
    }
}
