Post Conditions

1. What are Post Conditions?
  • Actions that run after the pipeline or stage completes;
  • Used for cleanup, notifications, artifact publishing;
2. Post Condition Blocks
BlockWhen It Runs
alwaysAlways runs, regardless of result
successOnly when pipeline succeeds
failureOnly when pipeline fails
unstableWhen marked unstable (e.g., test failures)
changedWhen result differs from previous build
cleanupRuns after all other post conditions
3. Example
pipeline {
    agent any
    stages {
        stage('Build') {
            steps { sh 'mvn clean package' }
        }
    }
    post {
        always {
            junit '**/target/surefire-reports/*.xml'
            archiveArtifacts artifacts: 'target/*.jar', allowEmptyArchive: true
        }
        success {
            echo 'Build succeeded!'
            slackSend color: 'good', message: "Build #${BUILD_NUMBER} passed"
        }
        failure {
            echo 'Build failed!'
            slackSend color: 'danger', message: "Build #${BUILD_NUMBER} failed"
        }
        cleanup {
            cleanWs()
        }
    }
}
