Declarative vs Scripted Pipeline

1. Declarative Pipeline
  • Structured, opinionated syntax with a predefined structure;
  • Easier to read and write; recommended for most use cases;
  • Starts with pipeline { };
pipeline {
    agent any
    stages {
        stage('Build') {
            steps {
                sh 'make build'
            }
        }
    }
}
2. Scripted Pipeline
  • Full Groovy programming language; maximum flexibility;
  • More complex, less structured;
  • Starts with node { };
node {
    stage('Build') {
        sh 'make build'
    }
    stage('Test') {
        try {
            sh 'make test'
        } catch (e) {
            currentBuild.result = 'UNSTABLE'
        }
    }
}
