Pipeline as Code

1. What is Pipeline as Code?
  • Defining your CI/CD pipeline in a file (Jenkinsfile) stored in version control;
  • The pipeline definition lives alongside your application code;
  • Changes to the pipeline go through the same review process as code changes;
2. Benefits
  • Version controlled: Full history of pipeline changes in Git;
  • Code review: Pipeline changes go through pull requests;
  • Reproducible: Same pipeline runs on any Jenkins instance;
  • Single source of truth: Code and pipeline live together;
  • Branch-specific: Each branch can have its own pipeline;
3. How It Works
  • Create a file named Jenkinsfile in the root of your repository;
  • Configure the Jenkins job to use "Pipeline script from SCM";
  • Jenkins checks out the code and reads the Jenkinsfile;
  • The pipeline executes as defined in the file;
