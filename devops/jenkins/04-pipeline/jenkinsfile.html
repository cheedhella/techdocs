Jenkinsfile

1. What is a Jenkinsfile?
  • A text file named Jenkinsfile that defines the pipeline;
  • Placed in the root of the repository;
  • Uses Groovy-based DSL (Domain Specific Language);
2. Basic Jenkinsfile
pipeline {
    agent any
    stages {
        stage('Build') {
            steps {
                echo 'Building...'
            }
        }
        stage('Test') {
            steps {
                echo 'Testing...'
            }
        }
        stage('Deploy') {
            steps {
                echo 'Deploying...'
            }
        }
    }
}
3. Key Sections
SectionPurpose
pipelineRoot block for declarative pipeline
agentWhere to run (any, label, docker, kubernetes)
stagesContainer for all stages
stageA named phase (Build, Test, Deploy)
stepsActual commands to run within a stage
postActions after pipeline completes
environmentSet environment variables
parametersUser input parameters
