What is CD (Continuous Delivery vs Deployment)?

1. Continuous Delivery
  • An extension of CI where code is always in a deployable state;
  • After automated tests pass, the artifact is ready for production but deployment requires manual approval;
  • Think of it as: we can deploy at any time, but a human decides when;
2. Continuous Deployment
  • Goes one step further: every change that passes all tests is automatically deployed to production;
  • No manual gates. The pipeline handles everything;
  • Requires extremely high confidence in automated tests;
