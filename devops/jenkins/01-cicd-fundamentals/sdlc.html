Software Development Lifecycle (SDLC)

1. What is SDLC?
  • A structured process for planning, creating, testing, and deploying software;
  • Provides a framework that defines tasks at each phase of development;
  • CI/CD automates the later stages of the SDLC;
2. SDLC Phases
PhaseDescriptionCI/CD Role
PlanningDefine requirements, scope, timeline-
DesignArchitecture, UI/UX, database design-
DevelopmentWrite code, commit to version controlTriggers CI
TestingUnit, integration, E2E testsAutomated by CI
DeploymentRelease to productionAutomated by CD
MaintenanceBug fixes, updates, monitoringContinuous loop
3. SDLC Models
  • Waterfall: Sequential phases. Finish one before starting the next. Rigid, slow feedback;
  • Agile: Iterative sprints (2-4 weeks). Fast feedback, adaptive planning;
  • DevOps: Extends Agile. Bridges development and operations with automation, CI/CD, and monitoring;
4. Where Jenkins Fits
  • Developers push code to Git;
  • Jenkins picks up the change (CI);
  • Builds, tests, quality checks run automatically;
  • Artifact is packaged (Docker image, JAR);
  • Deployed to environments (CD);
