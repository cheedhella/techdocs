Build Tools Overview (Maven, Gradle, npm)

1. What are Build Tools?
  • Software that automates compiling code, running tests, and packaging artifacts;
  • Jenkins calls these tools during the build stage of your pipeline;
2. Maven (Java)
  • Most popular build tool for Java. Uses pom.xml;
mvn clean install
mvn test
mvn package
3. Gradle (Java/Kotlin/Android)
  • Modern build tool using Groovy or Kotlin DSL. Faster than Maven;
gradle build
gradle test
gradle clean build
4. npm (Node.js)
npm install
npm test
npm run build
5. Using Build Tools in Jenkins
pipeline {
    agent any
    tools {
        maven 'Maven-3.9'
        jdk 'JDK-17'
    }
    stages {
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }
    }
}
