Dynamic Agent Pods

1. How It Works
  • Build starts: Jenkins creates a Pod in K8s;
  • Pod runs JNLP agent + build containers;
  • Build ends: Pod auto-deleted;
2. Benefits
  • Cost efficient: No idle agents;
  • Scalable: K8s handles scheduling;
  • Clean: Fresh environment per build;
  • Flexible: Different pod templates per job;
3. Pod Template
  • Defines containers in the agent Pod;
  • Use container("name") to target a specific container;
