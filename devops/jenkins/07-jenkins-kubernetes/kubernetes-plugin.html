Jenkins Kubernetes Plugin

1. What?
  • Dynamically provisions agents as K8s Pods;
  • Pods created on demand, destroyed after build;
  • Scales with build load;
2. Setup
  • Install Kubernetes plugin;
  • Configure in Manage Jenkins > Clouds;
  • Provide: K8s URL, namespace, credentials;
3. Pipeline
pipeline {
    agent {
        kubernetes {
            yaml """
apiVersion: v1
kind: Pod
spec:
  containers:
  - name: maven
    image: maven:3.9
    command: ["sleep","99999"]
"""
        }
    }
    stages {
        stage("Build") {
            steps { container("maven") { sh "mvn package" } }
        }
    }
}
