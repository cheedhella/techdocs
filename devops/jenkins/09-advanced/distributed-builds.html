Distributed Builds

1. Why?
  • Scale build capacity with more agents;
  • Run builds on different OS/architectures;
  • Keep controller free from build workloads;
2. Connection Methods
MethodDescription
SSHController connects to agent
JNLPAgent connects back to controller
WebSocketFirewall-friendly outbound
3. Adding an Agent
  • Manage Jenkins > Nodes > New Node;
  • Set: name, remote root, labels, launch method;
4. Labels
pipeline {
    agent { label "linux && docker" }
    stages { ... }
}
