Parallel Stages

1. What?
  • Run multiple stages simultaneously to reduce pipeline time;
  • Great for independent tasks: different test suites, multi-platform testing;
2. Example
pipeline {
    agent any
    stages {
        stage("Test") {
            parallel {
                stage("Unit Tests") {
                    steps { sh "mvn test -Dtest=UnitTests" }
                }
                stage("Integration Tests") {
                    steps { sh "mvn test -Dtest=IntegrationTests" }
                }
                stage("Lint") {
                    steps { sh "mvn checkstyle:check" }
                }
            }
        }
    }
}
3. failFast
stage("Test") {
    failFast true
    parallel { ... }
}

Aborts all parallel branches if one fails.
