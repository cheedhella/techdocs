Blue Ocean UI

1. What?
  • A modern UI for Jenkins focused on pipeline visualization;
  • Graphical view of stages and parallel branches;
  • Built-in pipeline editor;
  • Native Git integration;
2. Features
  • Visualization: Graphical stages and parallel branches;
  • Editor: Create pipelines visually;
  • Dashboard: Personalized view of relevant pipelines;
  • PR views: Easy multi-branch navigation;
3. Install
  • Install Blue Ocean plugin;
  • Access at http://jenkins-url/blue;
