GitHub / GitLab Integration

1. GitHub Integration
  • Install GitHub and GitHub Branch Source plugins;
  • Create a Personal Access Token in GitHub with repo and admin:repo_hook scopes;
  • Add the token as a credential in Jenkins;
2. GitLab Integration
  • Install the GitLab plugin;
  • Create an API token in GitLab;
  • Configure the GitLab connection in Jenkins system settings;
3. SCM in Pipeline
pipeline {
    agent any
    stages {
        stage('Checkout') {
            steps {
                git branch: 'main',
                    credentialsId: 'github-token',
                    url: 'https://github.com/user/repo.git'
            }
        }
    }
}
