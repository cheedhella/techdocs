Webhooks

1. What are Webhooks?
  • HTTP callbacks that notify Jenkins when events happen in your Git platform;
  • Replaces polling with instant notifications;
2. GitHub Webhook Setup
  • Go to GitHub repo Settings > Webhooks > Add webhook;
  • Payload URL: http://your-jenkins/github-webhook/;
  • Content type: application/json;
3. GitLab Webhook Setup
  • Go to GitLab project Settings > Webhooks;
  • URL: http://your-jenkins/project/job-name;
  • Select trigger events: Push, Merge Request;
