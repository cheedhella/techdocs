SonarQube (Code Quality)

1. What is SonarQube?
  • An open-source platform for code quality and security analysis;
  • Detects bugs, code smells, vulnerabilities, and coverage gaps;
2. Pipeline Integration
stage('SonarQube Analysis') {
    steps {
        withSonarQubeEnv('SonarQube-Server') {
            sh 'mvn sonar:sonar'
        }
    }
}
stage('Quality Gate') {
    steps {
        timeout(time: 5, unit: 'MINUTES') {
            waitForQualityGate abortPipeline: true
        }
    }
}
