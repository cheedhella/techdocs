Slack / Email Notifications

1. Slack Notifications
post {
    success {
        slackSend(color: 'good', channel: '#builds',
            message: "SUCCESS: ${JOB_NAME} #${BUILD_NUMBER}")
    }
    failure {
        slackSend(color: 'danger', channel: '#builds',
            message: "FAILED: ${JOB_NAME} #${BUILD_NUMBER}")
    }
}
2. Email Notifications
post {
    failure {
        emailext(
            subject: "FAILED: ${JOB_NAME} #${BUILD_NUMBER}",
            body: "Check: ${BUILD_URL}",
            to: 'team@example.com'
        )
    }
}

Configure SMTP in Manage Jenkins > System > E-mail Notification.
