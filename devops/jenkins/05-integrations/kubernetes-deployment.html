Kubernetes Deployment

1. Deploying to Kubernetes from Jenkins
  • Use kubectl commands in pipeline steps;
  • Store kubeconfig as a Jenkins credential;
2. Example Pipeline
stage('Deploy to K8s') {
    steps {
        withCredentials([file(credentialsId: 'kubeconfig', variable: 'KUBECONFIG')]) {
            sh 'kubectl set image deployment/myapp myapp=registry/myapp:${BUILD_NUMBER}'
            sh 'kubectl rollout status deployment/myapp'
        }
    }
}
3. Using Helm
stage('Deploy with Helm') {
    steps {
        sh "helm upgrade --install myapp ./chart --set image.tag=${BUILD_NUMBER}"
    }
}
