Docker-in-Docker vs Docker Socket

1. Socket Mount (Recommended)
  • Mount host socket: simpler, faster, shared cache;
docker run -v /var/run/docker.sock:/var/run/docker.sock jenkins/jenkins
2. DinD
  • Separate daemon, needs --privileged;
docker run --privileged docker:dind
3. Comparison
FeatureSocketDinD
SetupSimpleComplex
SpeedFastSlower
IsolationSharedFull
