Freestyle Jobs

1. What is a Freestyle Job?
  • The simplest type of Jenkins job, configured entirely through the UI;
  • Good for simple tasks: run a script, build a project, trigger another job;
  • Limited flexibility compared to Pipeline jobs;
  • Configuration is stored in Jenkins, not in your source code repo;
2. Creating a Freestyle Job
  • Click New Item > Enter name > Select Freestyle project;
  • Configure: Source Code Management (Git URL), Build Triggers, Build Steps, Post-build Actions;
3. Common Build Steps
StepDescription
Execute shellRun shell commands (Linux/macOS)
Execute Windows batchRun batch commands (Windows)
Invoke MavenRun Maven goals
Invoke GradleRun Gradle tasks
4. When NOT to Use Freestyle
  • Complex multi-stage pipelines;
  • When you need Pipeline as Code (Jenkinsfile in Git);
  • When you need parallel execution, conditions, or shared libraries;
  • Prefer Pipeline jobs for anything beyond simple builds;
