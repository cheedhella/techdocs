Folder Structure

1. What are Folders?
  • Folders organize Jenkins jobs into a hierarchical structure;
  • Similar to directories on a filesystem;
  • Each folder can have its own credentials, views, and permissions;
2. Benefits
  • Organization: Group related jobs (by team, project, environment);
  • Access control: Set permissions at the folder level;
  • Scoped credentials: Credentials visible only within the folder;
  • Clean dashboard: Reduce clutter on the main page;
3. Typical Structure
Jenkins
  +-- team-frontend/
  |     +-- webapp-main
  |     +-- webapp-staging
  +-- team-backend/
  |     +-- api-service
  |     +-- auth-service
  +-- shared-infra/
        +-- deploy-k8s
        +-- database-migrations
4. Creating Folders
  • Requires the Folders plugin (usually pre-installed);
  • Click New Item > Enter name > Select Folder;
