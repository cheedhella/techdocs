Build Triggers (Poll SCM, Webhook, Cron)

1. Types of Build Triggers
TriggerDescription
Poll SCMJenkins periodically checks Git for changes
WebhookGit pushes notify Jenkins immediately (preferred)
Build periodically (Cron)Run on a schedule regardless of changes
Upstream jobTrigger after another job completes
ManualClick "Build Now" in the UI
2. Poll SCM
// Jenkinsfile
triggers {
    pollSCM('H/5 * * * *')  // Check every 5 minutes
}
  • Simple but inefficient: Jenkins checks even when nothing changed;
  • Use webhooks instead when possible;
3. Webhooks (Recommended)
  • Git platform (GitHub/GitLab) sends an HTTP POST to Jenkins when code is pushed;
  • Instant feedback with no polling overhead;
  • Configure in your Git repo settings: http://jenkins-url/github-webhook/;
4. Cron Syntax
// Cron format: MINUTE HOUR DOM MONTH DOW
triggers {
    cron('H 2 * * *')       // Daily at ~2 AM
    cron('H/15 * * * *')    // Every 15 minutes
    cron('H H(0-3) * * 1')  // Monday between midnight and 3 AM
}
// H = hash-based spread to avoid all jobs running at once
