Pipeline Jobs

1. What is a Pipeline Job?
  • A Jenkins job defined as code in a Jenkinsfile;
  • Supports complex workflows: stages, parallel execution, conditions, error handling;
  • Version-controlled alongside your application code;
  • The recommended way to define CI/CD in Jenkins;
2. Creating a Pipeline Job
  • Click New Item > Enter name > Select Pipeline;
  • Choose pipeline source: Pipeline script (inline) or Pipeline script from SCM (Jenkinsfile in Git);
3. Basic Pipeline Example
pipeline {
    agent any
    stages {
        stage('Build') {
            steps {
                echo 'Building...'
                sh 'mvn clean package'
            }
        }
        stage('Test') {
            steps {
                echo 'Testing...'
                sh 'mvn test'
            }
        }
        stage('Deploy') {
            steps {
                echo 'Deploying...'
            }
        }
    }
}
