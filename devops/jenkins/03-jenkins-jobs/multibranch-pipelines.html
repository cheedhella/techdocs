Multi-branch Pipelines

1. What is a Multi-branch Pipeline?
  • Automatically discovers branches in a Git repository and creates a pipeline for each;
  • Each branch with a Jenkinsfile gets its own pipeline;
  • Branches without a Jenkinsfile are ignored;
  • Pull Requests can also trigger builds;
2. How It Works
  • Jenkins scans the repo periodically (or via webhook);
  • Finds branches with a Jenkinsfile;
  • Creates a sub-job for each branch: my-project/main, my-project/feature-x;
  • When a branch is deleted, its pipeline is automatically removed;
3. Creating a Multi-branch Pipeline
  • Click New Item > Select Multibranch Pipeline;
  • Add Branch Source: GitHub, GitLab, or Git;
  • Configure credentials and repository URL;
  • Set scan triggers (periodic or webhook);
4. Use Cases
  • Feature branch workflows: each branch gets CI automatically;
  • PR validation: test PRs before merging;
  • Release branches: different pipeline behavior per branch;
