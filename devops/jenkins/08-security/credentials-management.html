Credentials Management

1. What?
  • Securely stored secrets: passwords, tokens, SSH keys, certificates;
  • Managed in Manage Jenkins > Credentials;
  • Scoped: Global, System, or Folder-level;
2. Types
TypeUse Case
Username/PasswordGit, Docker registries
Secret textAPI tokens
SSH keyGit SSH, server access
Secret filekubeconfig, certs
3. In Pipeline
environment {
    CREDS = credentials("my-creds-id")
    // CREDS_USR and CREDS_PSW available
}

withCredentials([file(credentialsId: "kubeconfig", variable: "KUBECONFIG")]) {
    sh "kubectl get pods"
}
