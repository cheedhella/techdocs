User Management

1. Authentication
  • Jenkins own database: Built-in user management;
  • LDAP: Integrate with Active Directory;
  • SAML/OAuth: SSO with Okta, Azure AD;
2. Creating Users
  • Manage Jenkins > Users > Create User;
  • Provide username, password, full name, email;
3. Security Realm
  • Configure in Manage Jenkins > Security;
  • Options: Jenkins DB, LDAP, Unix user/group;
