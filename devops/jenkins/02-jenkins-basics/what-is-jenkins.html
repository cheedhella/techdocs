What is Jenkins?

1. What is Jenkins?
  • Jenkins is an open-source automation server used to build, test, and deploy software;
  • Written in Java, it is the most widely used CI/CD tool in the world;
  • Highly extensible with over 1,800 plugins;
  • Free, self-hosted, and community-driven;
2. Key Features
  • Pipeline as Code: Define CI/CD pipelines in a Jenkinsfile stored in your repo;
  • Distributed Builds: Scale builds across multiple agents/nodes;
  • Plugin Ecosystem: Integrate with virtually any tool (Docker, K8s, Git, Slack, etc.);
  • Extensible: Write custom plugins, shared libraries, and DSLs;
  • Platform Agnostic: Runs on Linux, macOS, Windows, Docker, Kubernetes;
