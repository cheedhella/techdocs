Installing Jenkins (Local, Docker, Kubernetes)

1. Prerequisites
  • Java 17+ (Jenkins requires a JDK);
  • Minimum 256MB RAM (recommend 1GB+);
  • 10GB+ disk space;
2. Local Installation (WAR file)
# Download Jenkins WAR
wget https://get.jenkins.io/war-stable/latest/jenkins.war

# Run Jenkins
java -jar jenkins.war --httpPort=8080

# Access at http://localhost:8080
# Initial admin password: cat ~/.jenkins/secrets/initialAdminPassword
3. Docker Installation
# Run Jenkins in Docker
docker run -d \
  --name jenkins \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  jenkins/jenkins:lts

# Get initial password
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
4. Kubernetes Installation (Helm)
helm repo add jenkins https://charts.jenkins.io
helm install jenkins jenkins/jenkins \
  --namespace jenkins \
  --create-namespace \
  --set controller.serviceType=LoadBalancer
5. Post-Installation
  • Enter the initial admin password;
  • Install suggested plugins (or select manually);
  • Create the first admin user;
  • Configure the Jenkins URL;
