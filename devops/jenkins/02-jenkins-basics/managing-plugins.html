Managing Plugins

1. What are Plugins?
  • Jenkins core is minimal. Plugins extend functionality;
  • Over 1,800 plugins available for: SCM, build tools, notifications, cloud providers, security;
2. Managing Plugins
  • Go to Manage Jenkins > Plugins;
  • Available: Browse and install new plugins;
  • Installed: View, update, or uninstall existing plugins;
  • Updates: Check for plugin updates;
3. Essential Plugins
PluginPurpose
PipelineCore pipeline functionality (Jenkinsfile)
GitGit SCM integration
Docker PipelineUse Docker in pipelines
KubernetesDynamic K8s agents

Role-based AuthorizationRBAC for Jenkins
