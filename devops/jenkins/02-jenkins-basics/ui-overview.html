Jenkins UI Overview

1. Dashboard
  • The home page showing all jobs, their status, and recent builds;
  • Weather icons: Sun (all recent builds passed), Cloud (some failures), Storm (mostly failing);
  • Build status: Blue (success), Red (failure), Yellow (unstable), Grey (not built);
2. Key Sections
SectionPurpose
New ItemCreate new jobs/pipelines
PeopleView users and their activity
Build HistoryTimeline of all builds across jobs
Manage JenkinsSystem config, plugins, security, tools
CredentialsManage stored credentials (passwords, SSH keys, tokens)
3. Job Page
  • Build Now: Trigger a manual build;
  • Configure: Edit job settings;
  • Build History: List of past builds with status;
  • Console Output: Real-time logs for a specific build;
  • Pipeline Steps: Visual representation of stages (Pipeline jobs);
