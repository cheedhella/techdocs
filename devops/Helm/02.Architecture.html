Helm V2:
    - It has 2 components: Helm CLI, Tiller;
    - Tiller runs inside your k8s cluster and manages the lifecycle of k8s objects;
    - Helm CLI talks to the tiller to install/upgrade/remove k8s objects;

Helm V3: 
    - Tiller was removed in Helm V3;
    - Helm CLI interacts directly with k8s API server;
