What is Helm?
    If you want to run your application on k8s cluster, you need to define so many objects such as deployment, configmap, secrets, etc in YAML files;
    K8s API server takes those YAML files and creates objects as desired;
    As the project grows, the number of YAML files also increases and it becomes hard to maintain; 
    This is where(though not the only place) Helm comes to the rescue!
    
    It is a k8s package manager - In other words, it bundles a set of k8s resource files into a single package that can be easily(with just 1 command) deployed on any k8s cluster;

What are the other benefits of Helm?
	- Parameterized YAML files 
		-- You can parameterize k8s resource files, which can be reused across many applications, thus reducing maintanance burden;
		-- This makes it easy to deploy the same application with different configurations in different environments such as development, staging, and production;
	- Reduces complexity of installaing an application 
		-- You can install/upgrade/uninstall any application using a single command;
	- Keep track of history 
		-- You can rollback to any state at any point in time;
	- Out-of-box charts are available for many applications
		-- Artifact Hub has free to use charts for many applications, so there is no need to build solutions from scratch;
