Template Action 
    - {{ }} is called a Template Action;
    - Anything between flower brackets {{ }} is called a Action element; 
    - It helps in retrieve data from other sources;
    - Template engine replaces anything inside flower brackets with it's value;
    - Anything outside {{ }} is returned as is;
------------------------------------------------------------------------------------------------------------------------------------------------------
Template function
    It is used to format text, manipulate arrays and objects, perform calculations etc;
    Helm provides over 60 functions;
    Syntax: function arg1 arg2...
    Eg: quote .Values.favorite.drink

Pipeline
    Pipeline is powerful tool for chaining multiple functions together to create a powerful workflow;
    It redirects the output of one function to the input of the next function;
    Eg: {{ cat .Chart.Name "Container" | snakecase | lower }}  // fetch chart name | append 'Container' | snakecase | lowercase; Ouput: mychart_container
------------------------------------------------------------------------------------------------------------------------------------------------------
default 
    - If the input is not defined, it returns a default value;
    - Definition of undefined depends on type:
        -- number: 0
        -- string: ''
        -- Lists: []
        -- Dicts: {}
        -- Boolean: false 
        -- null

    - Eg: drink: {{ .Values.favorite.drink | default "tea" | quote }}
    - Eg: default 'tea' .Values.favorite.drink      # If .Values.favorite.drink is not defined, it defaults to tea;
------------------------------------------------------------------------------------------------------------------------------------------------------
Controlling whitespaces 
    {{- .Chart.name }}  -> Leading white space is ignored during rendering;
    {{ .Chart.name -}}  -> Trailing white space is ignored during rendering;
    - Eg:
            name1: "hello  {{- .Chart.name  }}  kalyan"         -> "hello  kalyan"
            name2: "hello  {{  .Chart.name -}}    kalyan"       -> "hello    kalyan"
            name3: "hello  {{- .Chart.name -}}  kalyan"         -> "hellokalyan"
------------------------------------------------------------------------------------------------------------------------------------------------------
    indent
        - It indents every line in a given string to the specified indent width(defaults 4 spaces); 
        Eg: indent: {{ indent 4 .Values.myVal }}

    nindent
        - It is same as indent, but prepends the output with a newline;

    toYaml 
        - Used to convert an array or object to indented YAML string;
        Eg: 
            // values.yaml 
            items: ['first', 'second']

            example: {{- .Values.items | toYaml | nindent 2}}

            // Output:
            example:
              - first 
              - second
