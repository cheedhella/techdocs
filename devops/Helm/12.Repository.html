What is Repository?
    It is a artifact server which hosts a collection of charts/packages;
    It allows developers to share their charts with other other developers;

    You might be thinking that there is a predefined single repository containing every single software package in the world; 
	Unfortunately, that's not the case; If you want a software package, you need find a repository containing it;

    Helm doesn't come with any repositories added, during installation;

    Artifact Hub -> helm repo add artifact-hub https://artifacthub.github.io/helm-charts    # By far, the biggest helm repository;
    Nginx        -> helm repo add nginx-stable https://helm.nginx.com/stable
    Bitnami      -> helm repo add bitnami https://charts.bitnami.com/bitnami
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------
helm repo add <name> <url>                # Add repository; It downloads index.yaml of specified repository into local cache directory; HELM_REPOSITORY_CACHE env variable specifies the cache directory;   
helm repo list                            # List all configured repositories;
helm repo update <name>                   # It fetches latest index.yaml for the specified repository and updates cache(which is used by search); 
helm repo update                          # It fetches latest index.yaml for all repositories added and updates cache;
helm repo remove <name>                   # Delete the repository;

helm repo index <dir>                     # Every repository must have a valid index file; 
                                          # It reads given directory/repository and generates index file with all the charts found;
                                          # It is useful when you are setting up your own repository;
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------
helm search repo <keyword>                # It scans through all repositories configured in the system and prints latest stable version of charts found in them;
                                          # helm search repo nginx                      -> Returns latest stable version of each chart whose name matches 'nginx'
                                          # helm search repo nginx --devel              -> Returns latest version(could be stable/alpha/beta/release candidate etc) of each chart whose name matches 'nginx'
                                          # helm search repo nginx --versions           -> Returns all versions(could be stable/alpha/beta/release candidate etc) of each chart whose name matches 'nginx'
                                          # helm search repo nginx --version ^1.0.0     -> Returns all stable charts whose name matche nginx and major version of 1
