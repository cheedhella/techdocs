What is init container?

  • A Pod can have one or more containers; It can also have 0 or more init containers;
  • init container is used to perform one time/shortlived tasks, before actually bringing up the actual containers;
  • For eg, you could use init container to install some software, to fetch credentials from a remote location and make it available to the main container, setting up the file system permissions etc;
  • All init containers are executed sequentially, one after another; Once all of them complete, actual containers are started;
  • If, for any reason, one of the init container fails, actual container won't get started or fails;
