  • in the Kubernetes perspective, an Ambassador pattern implements a proxy to the external world
  • For eg, If you build an application that needs to connect with a database server, the server configuration, etc, changes with the environment;

Why Adapter Pattern is needed?

  • The adapter pattern helps you standardise something heterogeneous in nature;
  • For example, you’re running multiple applications within separate containers, but every application has a different way of outputting log files.
  • Now, you have a centralised logging system that accepts logs in a particular format only. What can you do in such a situation? Well, you can either change the source code of each application to output a standard log format or use an adapter to standardise the logs before sending it to your central server. That’s where the adapter pattern comes in.
