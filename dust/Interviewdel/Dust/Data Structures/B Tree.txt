B Tree - generalization of BST in that a node can have more than 2 children.
	used for indexing large blocks of data in case of databases.

A B-Tree of order m is a tree with the following properties:

	1. For each node(except root and leaf), ceil(m/2) <= degree(node) <= m
	   Root node can have either 0 or atleast 2 children.

	2. Number of keys in each non-leaf node is one less than the number of it's children.
	   node - min/max. no. of keys?????
	   min. no. of keys for root node is 1, min. no. of childs is 2.

	3. Format of each node is:
		P0  K1  P1  K2 ....... Km-1, Pm-1
		
	   struct btnode {
		int count;             // count of active keys in the node
		int K[m];              // each node can hold a max. of m-1 keys, don't use K[0] 
		struct btnode *P[m];   // each node can have a max. of m children
	   };

	4. Inside a node, Ki < Ki+1, for all i such that 1 <=	i <= m-1

	5. All the key values in the subtree Pi are less than Ki+1, 0 <= i <= m-1
	
	6. All the key values in the subtree Pi are greater than Ki, 0 <= i <= m-1
