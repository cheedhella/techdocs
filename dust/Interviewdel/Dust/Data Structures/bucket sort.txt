Bucket Sort

// A is the array to be sorted, n is the no. of items in A
// b is the base of items in A
// NEXT-SORT is any sorting algorithm
// Assumption: elements of array are distributed uniformly among 
// all the buckets.
Bucket-sort(A, n)
   {
   take an array of b empty linked lists, name it B.
   for i=0 to n-1
	j = MSD(A[i]); // Most Significant Digit of A[i]
	insert A[i] into the jth linked list of B.
   
   // sort each linked list separately using any sorting alg
   for i=0 to b-1
	NEXT-SORT(B[i]); 
   
   printing the contents of all the lists B[0], B[1],..., B[b-1] 
   in order produces the sorted array.
   }

Note: Using Bucket-sort itself as the NEXT-SORT produces a relative of the radix sort(MSD Radix Sort).
