Calculate the Maximum Depth of a Binary Tree?
It is the number of nodes along the longest path from the root node down to the farthest leaf node; 
            
    public static int maxDepth(Node root) {
        if(root == null) {
            return 0;
        }
        if(root.left == null && root.right == null){
            return 1;
        }
        else{
            int l = maxDepth(root.left);
            int r = maxDepth(root.right);
            return Math.max(l, r) + 1;             
        }
    }
Complexity:
In order to compute depth, we end up visiting each node recursively, therefore the time complexity is T O(N);
Space complexity is O(n), the space cost incurred on the stack size because of recursion calls;
