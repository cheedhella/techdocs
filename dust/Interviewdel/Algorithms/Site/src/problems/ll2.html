Check if a Single Linked List is Palindrome or not?
Method 1: Using a Stack;
  • Traverse the list from head to tail and push every visited node to Stack;
  • Traverse the list again. For each visiting node, pop a node from the stack and compare them;
    If all nodes matched, then return true, else false;
Complexity: It takes O(N) time and requires O(N) space for stack;
Method 2: without using a Stack;
  • Get the middle element of the list;
  • Reverse the 2nd half of the list;
  • Compare if both halves are same; If same, it is a palindrome;
  • To restore the original list, reverse the 2nd half of the list again;
Complexity: It takes O(N) time and requires O(1) space;
