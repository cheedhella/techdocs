What is Zookeeper?
	- It is part of Hadoop package;

	- It manages coordination b/w multiple distributed applications;
	- Maintaining configuration information: Sharign config info across all nodes;
	- Name the cluster of 1000s servers;
	- Providing distributed synchronization: Locals, Barriers, Queues;
	- Providing Group Services: Leader election;


	- Each and every node registers itself with Zookeeper; Zookeeper makes sure that every node knows about every other node;
	- Assign unique name to each node;
	- Leader election;
	

	It knows about all the nodes
