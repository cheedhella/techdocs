What is Load Balancer?

  • Load balancing is the process of distributing traffic among multiple instances of the same application;

Why is Load Balancer important?

  • To create a fault-tolerant system, we usually run multiple instances of each application;
  • Thus, whenever one service needs to communicate with another, it forwards the request to underlying load balancer;
  • TODO: How does the load balancer knows about all instances? existing one goes down, new one comes up? does it reaches eureka?

Load Balancing Algorithms

  • Round-robin: Choosing an instance in the same order each time;
  • Random selection: Choosing an instance randomly;
  • Least connections: Choosing the instance with the fewest current connections
  • Weighted metric: Using a weighted metric to choose the best instance (for example, CPU or memory usage)
  • IP hash: Using the hash of the client IP to map to an instance

Feign talks to the naming server(eureka), to get list of instances of a service and load balances the request; If you use Eureka and Feign, load balancing comes as free! This is called client-side load balancing, b/c it happens on the caller side; Feign has a dependency on spring-cloud-loadbalancer; Earlier version of spring use Ribbon as load balancer;
