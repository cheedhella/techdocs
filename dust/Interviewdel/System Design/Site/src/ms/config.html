What is API Gateway?

  • Config Server
  • spring-cloud-config-server
  • This story has the step by step instructions on how to create a config server using Spring Cloud Config for externalizing application configurations.
  • Config server can source the properties from 2 sources, a local file system (profile = native) and external source control, in our case it is github (profile = git) . There are other sources like bitbucket which are supported as well.
  • How to create profile?
  • Under the src/main/resources, lets add 2 application.yml files.
    application.yml — native profile application-git.yml — git profile
  • spring.cloud.config.server.git.uri=https://github.com/imdurgadas/config-repository.git
  • Spring boot provides lot of enormous flexibility in externalizing configuration properties via properties or yaml files. Using profile specific configuration files we can also provide different values for each of the environments like dev, prod i.e application.properties, application-dev.properties, application-prod.properties etc. But once the application is started we can not update the properties at runtime. If we change the properties we need to restart the application to use the updated configuration properties.
  • We could also have too many microservices and it’s important to have the ability to configure and manage the configuration properties of all the microservices from a centralized place.
  • @EnableConfigServer - It reads the config and exposes endpoints for other services; http://localhost:config-server-port/name-of-file/profile Eg: http://localhost:8888/limits-service/default


  • client - spring-cloud-starter-config
  • spring-cloud-starter-config is the library to let client apps connect to config server;
  • It reads config from src/main/resources/Bootstrap.yml
  • spring.cloud.config.uri — this is the fixed url of your config server.
  • spring.profiles.active=dev -> whichever config you want to load; vs spring.cloud.config.profile=qa;
  • @ConfigurationProperties("my-limits-service") - my-limits-service is the prefix of properties to read; if the service is not running, it will fallback to any defaults mentioned in it's application.properties;
