What is Service Registry?

  • It is a kind of database containing list of all services running and their metadata(IP, Port etc);
  • Every Naming Server maintains a Registry;

What is Naming Server?

  • Each instance of a microservice that we start, registers itself with the naming server;
  • In other words, if you want to see what all services are running along with their metadata, you can access Naming Server to check that information;

A pretty common way of solving the service discovery problem is putting a load balancer aka reverse proxy (e.g. Nginx or HAProxy) in front of the group of instances constituting a single service
