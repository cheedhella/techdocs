What is DNS?

  • It is a naming service that maps human-friendly domain names(like https://www.educative.io) to machine-friendly IP address(104.18.2.119);

Why DNS is needed?

  • It is easier for humans to remember domain names, rather than IP addresses;

New Terms

  • DNS
    • It is important to understand DNS is not a single naming server; It is a hierarchy of huge number of naming servers;
    • The hierarchical structure allows DNS to be highly scalable with it's increasing query load;

  • Name Server
    • Each server contains a collection of Resource Records;
    • There are mainly 4 types of servers:
      • DNS Resolver - DNS Server of your ISP, mostly;
      • Root Server
      • Top-Level Domain Server - A .com TLD nameserver contains information about every website that ends with .com;
      • Authoritative Name Server

  • Resource Record
    • Each record contains type, name and value;
    • type could be: A, NS, CNAME, MX etc;
    • name and value change depending upon the type of the RR;

    • A -> maps hostname to IP address; name -> hostname; value -> IP address;
    • CNAME -> maps alias to hostname; name -> canonical name; value -> hostname;
    • MX -> Specifies the mail server for accepting messages; Mail Exchange Record;
    • NS -> Specifies the nameserver to contact for your domain; Name Server Record;

  • Zone

  • Caching
    • DNS uses caching at different layers to reduce request latency for the user;

How do you get IP address for a new domain and what happens when you register?

  • Procuring IP address entirely a different thing!
  • You could register your IP address and domain with any DNS registar(like GoDaddy that offers both DNS registration and hosting);
  • They have authoritative name servers, which stores the mapping;

  • How does TLD server knows that GoDaddy's authoritative name server contains mapping for www.example.com?

How does your browser finds IP address of www.google.com, when you type it in the address bar and press enter?

  • Browser Cache
    • Browser first looks at it's cache;
    • Browser caches the IP address of the domains that we have visited recently, with a TTL(Time to live);

  • If the record is not found in Browser cache, next, it checks the ISP's DNS server;
    • How does browser know ISP's DNS server?
      • Either you network interface card is statically configured OR it obtains the information dynamically, using another protocol called DHCP;
      • Dynamic Host Configuration Protocol (DHCP) is a protocol for automatically assigning IP addresses and other configurations to devices when they connect to a network;

  • If ISP's DNS server can't find the record in it's cache, it check with the root DNS server?
    • What is root naming server?
      • There are 13 DNS root servers, each of which is named with the letters A to M; They all have a IPv4 address and most have an IPv6 address;
      • Managing the root servers is ICANN's responsibility (Internet Corporation for Assigned Names and Numbers);
      • All root servers contains an identical copy of the root zone file - there is complicated process for any updates to it;
      • The file itself only contains a size of roughly 2 MB; However, it contains all the names and IP addresses of all the top-level domain name servers;

      How does ISP know about root server?
      • Root servers mostly have a pre-defined IP, but that could change rarely;
      • In the rare case, if the IP of a root server changes, there are other root servers which could serve the request, until ISP updates root hints file from ns.internic.net;
