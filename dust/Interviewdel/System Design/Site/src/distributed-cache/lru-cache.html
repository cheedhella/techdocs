How to design a LRU cache with a single node?

  • What is LRU Cache?
    • A Cache with LRU as eviction policy;

  • Idea: Use a HashTable for quick data access, and use a Double Linked List to maintain LRU order, so that you can quickly identify data to be evicted;
  • What data structures come to your mind, when you design a cache?
    • Hash Table, we can put and get data in constant time;

  • How can we evict the data, in LRU fashion? Hashtable doesn't track the order of elements?
    • We need to use Double Linked List or Deque to maintain LRU order;

  • How it works?
    • If the key is present in HashMap, it's a cache hit; Else, it's a cache miss;

    • In case of cache hit,
      • Add a new element in front of the list;
      • Add a new entry in HashMap and refer to the head of the list;

    • In case of cache miss,
      • Remove the hit element and add it in front of the list;
      • Update HashMap with a new reference to the front of the list;

    • Both operations take O(1) time;
